# 产品→课标映射

## 概述

本文档建立加速进化 Booster 系列产品与国家课程标准的映射关系，帮助学校和教育机构理解产品如何支持课标教学。

## 映射总览

| 产品 | 适用学段 | 对应课标 | 课标覆盖度 |
|------|---------|---------|-----------|
| Booster T1 | L1-L2 | 信息科技(3-9年级)、科学(3-9年级) | 高 |
| Booster T2 | L2-L4 | 信息科技/技术(7-12年级)、通用技术(10-12年级) | 高 |
| Booster T3 | L4-Research | 通用技术(10-12年级)、大学专业课程 | 中高 |

## 详细映射

### Booster T1 × 信息科技课程标准

#### 第二学段（3-4年级）

| 课标内容 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 使用在线平台和工具 | 图形化编程环境 | 拖拽式编程控制机器人 |
| 数据的简单处理 | 传感器数据可视化 | 读取并展示温度/距离数据 |
| 简单算法描述 | 流程图生成 | 用流程图描述机器人行走路径 |

#### 第三学段（5-6年级）

| 课标内容 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 过程与控制 | 顺序/循环/事件编程 | 机器人巡线、避障任务 |
| 身边的算法 | 内置示例算法 | 颜色识别、路径跟随算法 |
| 数据与编码 | 传感器API | 采集和编码传感器数据 |

#### 第四学段（7-9年级）

| 课标内容 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 互联网与创新 | WiFi/蓝牙通信 | 多机器人通信实验 |
| 人工智能基础 | 视觉模块、AI示例 | 图像识别、自主决策 |
| 算法与编程 | Python SDK | Python 编程控制机器人 |

### Booster T2 × 高中课程标准

#### 信息科技（高中）

| 课标内容 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 数据与数据结构 | 传感器数据流 | 实时数据采集和处理 |
| 算法与程序实现 | Python/C++ SDK | 路径规划算法实现 |
| 人工智能初步 | GYM 强化学习环境 | 机器学习模型训练 |
| 三维设计与创意 | 3D 模型文件 | 机器人结构设计 |

#### 通用技术（高中）

| 课标内容 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 技术与设计 | 模块化结构 | 机器人系统分析与设计 |
| 电子控制技术 | 传感器/执行器接口 | 电子控制系统实验 |
| 机器人设计与制作 | 完整机器人平台 | 机器人项目开发 |

### Booster T3 × 大学/科研

| 应用方向 | 产品功能支持 | 教学场景 |
|---------|------------|---------|
| 机器人工程 | ROS2 全功能 | 机器人系统开发课程 |
| 人工智能 | 强化学习环境 | AI 算法研究与验证 |
| 控制工程 | 底层控制接口 | 运动控制算法研究 |
| 机械电子 | 硬件原理图/3D模型 | 机电一体化课程 |

## 采购决策支撑

### 学校类型匹配

| 学校类型 | 推荐产品 | 匹配理由 |
|---------|---------|---------|
| 小学（4-6年级） | Booster T1 | 匹配信息科技课标，图形化编程入门 |
| 初中（7-9年级） | Booster T1/T2 | 覆盖信息科技+AI教育要求 |
| 高中 | Booster T2 | 覆盖信息/通用技术课标 |
| 特色校/国际校 | Booster T2/T3 | 提供更高水平的课程支撑 |
| 大学/科研 | Booster T3 | 支持专业教学和研究 |

### 课标合规性说明

加速进化 Booster 系列产品已对照以下课程标准进行适配验证：

- [x] 义务教育信息科技课程标准（2022年版）
- [x] 普通高中信息技术课程标准（2017年版2020年修订）
- [x] 普通高中通用技术课程标准（2017年版2020年修订）
- [x] 义务教育科学课程标准（2022年版）
