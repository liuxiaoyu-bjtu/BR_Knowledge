# 理论→产品映射

## 概述

本文档建立教育理论与 Booster 产品功能之间的映射关系，展示产品设计如何体现和支撑教育理论。

## 映射总览

| 教育理论 | 产品设计体现 | Booster 功能支撑 |
|---------|------------|-----------------|
| 建构主义 | 学生主动构建知识 | 开放SDK、可编程接口 |
| 做中学 | 动手实践学习 | 真实硬件、即时反馈 |
| 具身认知 | 身体参与认知 | 人形结构、物理交互 |
| PBL项目式学习 | 项目驱动学习 | 赛事任务、项目模板 |

## 详细映射

### 建构主义 → 产品功能

| 建构主义原则 | 产品设计策略 | 具体功能 |
|------------|------------|---------|
| 知识主动构建 | 提供探索式学习环境 | 开放 Python/C++ SDK |
| 认知发展阶段 | 分学段产品设计 | T1(入门)→T2(进阶)→T3(专业) |
| 同化与顺应 | 渐进式学习支持 | 图形化→Python→ROS2→C++ |
| 社会互动 | 协作学习支持 | 多机器人通信、社区平台 |
| 情境学习 | 真实场景模拟 | 赛事场地套件、任务场景 |

**产品举证**：
- T1 的图形化编程界面降低了认知门槛，让小学阶段学生能够在已有经验基础上构建新知识
- T2/T3 的 ROS2 接口让高中生和大学生能够在已有编程基础上构建机器人系统知识

### 做中学 → 产品功能

| 做中学原则 | 产品设计策略 | 具体功能 |
|----------|------------|---------|
| 动手实践 | 真实硬件操作 | 可组装、可调试的硬件 |
| 真实问题 | 赛事任务驱动 | RoboCup 标准任务 |
| 反思循环 | 调试支持 | 日志系统、数据可视化 |
| 经验连续 | 进阶路径 | L1→L4 产品线衔接 |

**产品举证**：
- 机器人的即时物理反馈让每次编程修改的效果立即可见
- 调试日志和数据可视化工具支持学生的反思性学习
- T1→T2→T3 的产品线确保了学习经验的连续性

### 具身认知 → 产品功能

| 具身认知原则 | 产品设计策略 | 具体功能 |
|------------|------------|---------|
| 身体参与认知 | 人形机器人结构 | 双足行走、多关节运动 |
| 环境嵌入 | 物理世界交互 | 传感器-环境-执行器闭环 |
| 感知-行动耦合 | 实时感知-控制 | 摄像头+IMU+力传感器 |
| 具象化思维 | 行为可视化 | 机器人动作直观展示算法 |

**产品举证**：
- 人形结构（双足、双臂、头部）模拟人类身体，强化具身认知体验
- 多传感器系统（视觉、IMU、力觉）确保完整的感知-行动耦合
- 学生可以通过观察机器人的物理运动直观理解抽象算法

### PBL项目式学习 → 产品功能

| PBL原则 | 产品设计策略 | 具体功能 |
|---------|------------|---------|
| 挑战性问题 | 赛事任务设计 | RoboCup 足球赛任务 |
| 持续探究 | 项目周期支持 | 可保存/恢复的项目状态 |
| 真实性 | 真实场景 | 标准赛事场地、规则 |
| 学生选择 | 多方案支持 | 开放API、多种算法选择 |
| 公开展示 | 成果展示 | 赛事平台、社区分享 |

**产品举证**：
- 标准化的赛事场地和规则确保项目的真实性
- 开放API允许多种技术方案，支持学生的自主选择
- 赛事平台和社区功能支持成果的公开展示

### K1 通识课 → 产品功能映射

K1 四阶通识课是上述教育理论在 Booster 产品上的**具体落地路径**，逐阶提升对产品能力的调用深度：

| 通识阶 | 主要产品/平台支撑 | 能力调用深度 | 对应理论 |
|--------|-----------------|------------|---------|
| L1 机器人启蒙 | K1 实体 + Booster Studio APP（示教 Agent、图形化编程） | 体验与操控 | 具身认知·做中学 |
| L2 机器人应用 | K1 + Booster Studio（变量/条件/循环、视觉/语音模块） | 功能组织与任务设计 | PBL·做中学 |
| L3 机器人系统 | K1 + BoosterOS SDK（Python 代码控制、话题/回调） | 内部模块与系统集成 | 建构主义·做中学 |
| L4 机器人工程 | K1 + ROS2 + YOLO + 状态机/行为树 | 工程化智能闭环 | 建构主义·PBL |
| 清华工训 | K1 + BeyondMimic + MuJoCo + Rerun | 仿真→真机全链路 | 建构主义·PBL |

> 课程库原始素材与逐阶分析见 [K1 通识课体系](../../02-embodied-ai-edu/03-curriculum/k1-通识课/README.md)。
