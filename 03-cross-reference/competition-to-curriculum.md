# 赛事→课程映射

## 概述

本文档建立机器人赛事与具身智能教育课程之间的映射关系，帮助学校和教师了解参加不同赛事需要学习哪些课程。

## 映射总览

```
赛事 ←→ 课程映射关系

赛事层级          对应学段          核心课程线              辅助课程线
─────────────────────────────────────────────────────────────────
国际赛事 (RoboCup)  → L4     → AI课程线 + 机器人课程线  → 编程课程线
国家赛事           → L3-L4  → 机器人课程线 + AI课程线   → 编程课程线
省级赛事           → L2-L3  → 编程课程线 + 机器人课程线  → AI课程线
市级赛事           → L2     → 编程课程线 + 机器人课程线  → —
校级赛事           → L1-L2  → 编程课程线               → 机器人课程线
```

## 赛事→课程详细映射

### RoboCup 国际赛事

| 赛事项目 | 核心技术要求 | 必修课程 | 选修课程 |
|---------|------------|---------|---------|
| 人形机器人足球 | 运动控制、视觉、策略 | 运动控制进阶、计算机视觉入门、强化学习入门 | 路径规划与导航 |
| 救援仿真 | 路径规划、多智能体 | 路径规划与导航、Python进阶 | 机器学习入门 |
| @Home | 人机交互、SLAM | 自主导航、ROS2进阶 | 大模型+机器人 |

**推荐学习路径**：
```
Python启航 → Python进阶 → 计算机视觉入门 → 运动控制进阶
    → 路径规划与导航 → ROS2入门 → 强化学习入门 → 参赛
```

### K1 通识课 L4 足球任务 → RoboCup 直通车

L4 机器人工程以「自主追球与执行踢球动作」为终端项目，**本身就是 RoboCup 人形机器人足球的备赛课纲**，可直接对接赛事：

| L4 课次 | 课程主题 | 对应 RoboCup 能力 | 赛事技术点 |
|--------|---------|-----------------|-----------|
| 第11-12课 | 足球检测 / 头部跟随 | 视觉感知 | YOLO 目标检测、像素偏差控制 |
| 第13课 | 稳态跟随与丢失处理 | 鲁棒控制 | FSM(TRACK/FIND/SCAN)、异常恢复 |
| 第14课 | 机器人坐标系变换 | 空间定位 | 像素→机器人坐标、单目几何 |
| 第15课 | 追球与踢球决策 ⚠️ | 策略执行 | 策略接口、追球-踢球连续链路 |
| 清华工训 | 视觉踢球(VisualKick) | 端到端踢球 | VisualKick + `/kick_ball` |

> ⚠️ L4 第15课教案待补齐。完整课纲与逐课映射见 [L4 机器人工程](../../02-embodied-ai-edu/03-curriculum/k1-通识课/L4-机器人工程.md) 与 [清华工训中心课程](../../02-embodied-ai-edu/03-curriculum/k1-通识课/清华工训中心课程.md)。
