## 🏗️ 知识库架构：双核三层

```
                     ┌──────────────────────────┐
                     │   L0  知识地图导航层       │
                     │  仪表盘 · 速查 · 术语表    │
                     └────────────┬─────────────┘
                                  │
          ┌───────────────────────┼───────────────────────┐
          │                       │                       │
   ┌──────▼──────┐     ┌──────────▼──────────┐     ┌──────▼──────┐
   │ 公司知识库    │◄────┤  交叉引用与映射层     ├────►│ 具身智能教育 │
   │ Core A       │     │  Cross-Reference    │     │ 体系库 Core B│
   └──────┬───────┘     └──────────┬──────────┘     └──────┬──────┘
          │                       │                       │
          │             ┌─────────▼─────────┐             │
          └─────────────┤  L2 共享资源层     ├─────────────┘
                        │  模板 · 工具 · 媒体 │
                        └───────────────────┘
```

- **Core A（公司知识库）**：面向客户项目，8 大模块涵盖产品、方案、案例、销售支持
- **Core B（具身智能教育体系库）**：独立专业体系，6 大模块覆盖理论、标准、课程、实施、评估、政策
- **交叉引用层**：双核之间的映射关系，实现知识互通
