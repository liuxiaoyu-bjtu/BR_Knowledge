## 一、机器人连接与管理

### 多类型机器人连接

- **Booster 真机机器人**：K1、T1（T2 本月上线）
- **自定义机器人**：支持自定义配置
- **虚拟机器人**：基于 Docker 容器创建

### 连接方式

- **局域网扫描连接**：自动扫描局域网中的机器人
- **SSH 远程连接**：支持 Remote-SSH 连接机器人本体
- **多板连接支持**：支持连接机器人多个计算板（运动板、感知板等）

## 三、仿真能力

### 3.1 核心仿真

- **虚拟机器人创建**：基于 Docker 创建虚拟机器人
- **3D 仿真环境**：实时 3D 仿真画面，高保真物理引擎
- **仿真跟随视角**：跟随机器人视角的仿真画面
- **传感器仿真**：摄像头、IMU、力传感器

### 3.2 3V3 足球仿真赛

- 多机器人协同
- 足球比赛规则
- 对战功能
- 支持选择对战 Agent

### 3.3 硬件支持

- K1 机器人完整支持
- T1 机器人完整支持
- 传感器数据读取：图像、IMU、里程计、关节数据等
- 运动控制：速度控制、关节控制、模式切换

### 3.4 虚实结合

仿真中验证通过的程序，可无缝切换到真机运行。学生经历"仿真开发→真机验证"的完整工程流程。

```python
# 仿真模式
robot = BoosterRobot()
# 真机模式（自动发现，无需改代码）
robot = BoosterRobot()
```

## 五、云桌面

> 本周内上线（2026年7月底）

- **云端高性能电脑**：用加速豆租用云端性能更好的电脑
- **预装 Linux 系统**：开箱即用的开发环境
- **配置可选**：多种硬件配置可选
- **按使用量计费**：消耗加速豆
- **价值**：学生无需安装任何软件即可开始开发

## 六、AI 助手

集成在 Studio 中的智能编程助手（详见 [product-ecosystem.md](product-ecosystem.md) §AI 助手）：

## 九、教学价值

### 9.1 降低硬件门槛

- 学生可在无实体机器人的情况下进行编程学习
- 一个班级可共享少量真机 + 每人一个仿真环境
- 云端仿真 + 云桌面进一步消除本地配置需求

### 9.2 提高教学效率

- 仿真中可加速、暂停、回放，便于教学演示
- 不怕学生操作失误损坏设备
- 支持批量部署和统一管理

### 9.3 完整工程闭环

```
创建项目 → 编写代码 → 仿真测试 → 真机验证 → Agent 部署
```

学生经历从原型到部署的完整工程流程，培养工程思维和调试能力。
