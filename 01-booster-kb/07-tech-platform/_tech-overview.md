## 二、核心组件详解

### 2.1 BoosterOS SDK（Python）

**定位**：连接机器人、读取数据、下发指令的 Python SDK。

**核心能力**：
- 统一接口操作 K1/T1 真机和 Booster Studio 虚拟仿真
- 运动控制、传感器读取、模式切换
- 安装方式：`pip install boosteros`

### 2.2 ROS2 SDK

**定位**：基于 ROS2 标准的机器人开发接口。

**核心能力**：
- 兼容标准 ROS2 生态（节点/话题/服务）
- 支持 C++ 和 Python 开发
- 提供机器人专用消息和服务类型

### 2.3 Booster Studio

**定位**：一体化 Agent 开发平台。

**核心能力**：
- 虚拟仿真环境（无需真机即可开发测试）
- 真机连接与数据可视化
- 项目管理与代码编辑
- 支持 Windows / Ubuntu / macOS

### 2.4 Booster GYM

**定位**：强化学习训练框架。

**核心能力**：
- 基于 Gymnasium 接口的强化学习环境
- 足球运动控制模型训练
- 开源地址：github.com/BoosterRobotics/booster_gym

### 2.5 Booster Train

**定位**：基于 NVIDIA Isaac Lab 的大规模并行训练框架。

**核心能力**：
- Isaac Lab 集成，支持 GPU 并行仿真
- 大规模强化学习训练
- Sim2Real 策略导出

### 2.6 Booster Deploy

**定位**：Sim2Real 部署工具链。

**核心能力**：
- 仿真策略到真机的无缝迁移
- 域随机化与系统辨识
- 部署验证与监控

### 2.7 豆包大模型集成

**定位**：K1 标配的大模型交互能力。

**核心能力**：
- 自然语言对话
- 多模态感知（视觉+语音）
- K1 购买即享半年免费使用

## 三、技术路线图

| 阶段 | 重点 |
|------|------|
| 当前 | SDK 完善、Booster Studio 上线、RoboCup Demo 开源 |
| 短期 | Booster GYM 正式版、Booster Train 公测 |
| 中期 | Booster Deploy 工具链、云端训练平台 |
| 长期 | 开发者社区、应用市场 |

## 四、平台优势

1. **全栈自研**：从硬件到 SDK 到训练框架全部自主研发，深度优化
2. **虚实结合**：一套代码同时支持仿真和真机，降低开发门槛
3. **开源开放**：核心框架开源，构建开发者生态
4. **冠军技术**：RoboCup 世界冠军技术积淀
5. **大模型原生**：深度集成大模型能力，定义新一代机器人交互
