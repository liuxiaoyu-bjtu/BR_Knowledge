# Motion Creator — 动作编辑器

> **定位**：Motion Creator（动作工坊）是Booster Studio中的动作创作工具。当前视频路线经过人体骨架提取、imretarget重定向和Booster Train强化学习训练，产出动作策略，可按产品提供的方式部署到匹配机型；不能将最终产物笼统写成普通可回放轨迹。
>
> **状态**: ✅ 已上线（2026年8月 P0，0729 Demo Day 演示）

---

## 一、核心能力

### 动作生成流程

```
真人视频 → 人体骨架动作 → imretarget重定向参考动作 → Booster Train强化学习训练 → 动作策略 → 经确认的部署运行
```

- **全身运控动作训练**：支持全身关节的动作学习
- **真人动作视频输入**：用普通摄像头录制即可
- **骨架提取与重定向**：先估计人体运动，再适配目标机器人结构；参考动作与可运行策略分别形成。
- **训练结束条件**：最大训练时长或训练终止标准满足任一即结束（用户2026-10-26说明）；数值由平台配置，训练结束不能直接说明效果合格。
- **部署支持**：虚拟机器人部署 + 真机部署

### 计费方式

按使用量消耗**加速豆**，详见[产品生态体系](product-ecosystem.md#六加速豆体系)。PRD约定创建时按预计消耗扣除；提取/重定向失败返还，中途手动删除不返还；训练阶段失败是否返还仍有评审遗留口径，以当前规则为准。

### 当前视频要求（用户2026-10-26补充）

- MP4/MOV，不低于720P、30帧/秒；单人全身清楚出镜。
- 避免肢体交叉遮挡和物体遮挡；保持身体稳定。
- 不设计跳跃、踮脚、单腿支撑，避免大幅弯腰、后仰及快速动作。

动作详情是否展示各阶段中间结果，以当前界面为准；PRD完成页展示的可能是策略运行录制，不能将观看预览记为一次部署运行。

## 二、与Booster Train及轨迹回放的关系

动作工坊将视频输入到提取、重定向和训练流程。按用户当前实现说明，训练部分使用Booster Train；参考动作规定模仿目标，强化学习负责优化策略。学生可通过产品使用训练流程，不需要先安装训练工程或编写算法。

| 对象 | 数据或产物 | 执行方式与区别 |
| --- | --- | --- |
| 示教录制 | `.btraj`，含关节随时间变化的记录 | 正式SDK用`execute_trajectory()`回放；这一步不训练新策略 |
| 动作工坊重定向结果 | 适配目标机型的参考动作 | 用于后续训练；不能与最终策略混称 |
| 动作工坊训练结果 | 动作策略，部署资源设计包含策略、轨迹及参数 | 按产品部署方式验证；新导出/SDK方案仍测试中，不能当作`.btraj`调用 |

BeyondMimic相关研究路线与Booster Train工程介绍见[Booster Train](booster-train.md)。不能仅凭动作名称、视频外观或SDK入口，判定所有动作的训练算法与内部结构相同。

## 三、应用场景

| 场景 | 说明 |
|---|---|
| **舞蹈动作创作** | 学生拍一段舞蹈视频 → 机器人学会跳 |
| **体育动作教学** | 示范动作 → 机器人复现 → 对比分析 |
| **表演动作设计** | 快速原型机器人表演动作 |
| **动作过程分析** | 对照原视频、可见中间结果与策略表现，记录差异；是否支持导出以产品为准 |
| **高职动作实践** | 骨架提取→重定向→训练→结果分析，按条件部署；X课程U6-L3采用该路线 |

## 四、未来规划

- **动捕文件重定向**：从专业动捕设备文件直接生成动作
- **动作编辑功能**：关键帧编辑、动作混合、时间轴调整
- **动作分享到技能库**：将创作的动作发布到技能库，形成 UGC 生态
