# Motion Creator — 动作编辑器

> **定位**: Motion Creator 是动作创作工具，支持将真人动作录像转化为机器人动作，并部署到虚拟机器人或真机上运行。是 BeyondMimic 训练链路的上游「数据生产」工具。
>
> **状态**: 🔄 开发中（2026年8月 P0）

---

## 一、核心能力

### 动作生成流程

```
真人动作视频 → AI 动作提取 → 机器人动作生成 → 虚拟/真机部署
```

- **全身运控动作训练**：支持全身关节的动作学习
- **真人动作视频输入**：用普通摄像头录制即可
- **AI 动作提取**：自动从视频中提取人体关键点并映射到机器人关节
- **部署支持**：虚拟机器人部署 + 真机部署

### 计费方式

按使用量消耗**加速豆**（详见 [产品生态体系 §加速豆](product-ecosystem.md#六加速豆体系)）。

---

## 二、与 BeyondMimic 的关系

| 维度 | Motion Creator | BeyondMimic |
|---|---|---|
| **输入** | 真人动作视频（RGB 摄像头） | 示教 CSV 数据（零力矩拖拽） |
| **输出** | 机器人关节轨迹 | 训练后的运动策略模型 |
| **技术路线** | 视频动捕 → 重定向 | 模仿学习（IL + RL） |
| **产物** | 可回放的轨迹文件 | TorchScript 模型（有泛化能力） |
| **GPU 需求** | 云端处理，用户无感 | 训练需 NVIDIA GPU |
| **教学定位** | 动作创意表达（入门级） | 动作学习工程链路（进阶） |

Motion Creator 降低了动作创作的门槛——不需要零力矩拖拽、不需要理解关节空间，用手机拍一段视频就能生成机器人动作。这使得动作创作可以进入 K12 创意课和入门体验课。

---

## 三、应用场景

| 场景 | 说明 |
|---|---|
| **舞蹈动作创作** | 学生拍一段舞蹈视频 → 机器人学会跳 |
| **体育动作教学** | 示范动作 → 机器人复现 → 对比分析 |
| **表演动作设计** | 快速原型机器人表演动作 |
| **动作数据集制作** | 批量生成训练数据（为 BeyondMimic 提供 NPZ） |
| **高职动捕课程** | 动捕→重定向→部署的完整链路教学 |

---

## 四、未来规划

- **动捕文件重定向**：从专业动捕设备文件直接生成动作
- **动作编辑功能**：关键帧编辑、动作混合、时间轴调整
- **动作分享到技能库**：将创作的动作发布到技能库，形成 UGC 生态
