## 一、Booster App（移动端控制平台）

> **定位**: 面向最终用户的移动端控制平台，提供机器人的便捷操控、状态监控、智能互动等功能。

### 1.1 基础控制与状态管理

| 功能 | 说明 |
|---|---|
| **配网** | 蓝牙配网 + Wi-Fi 联网配置 |
| **实时监控** | 实时查看机器人所见画面（视频流）、运行状态、电量 |
| **模式切换** | 阻尼/准备/行走模式快捷切换 |
| **虚拟摇杆** | 前后平移、原地旋转、头部转动控制 |

### 1.2 智能互动与动作调用

- **预设动作库**：内置大量预设动作，跟随系统升级免费解锁，一键执行
- **Agent 切换**：快速切换不同功能 Agent（舞林高手、足球大师、HiChat 等）
- **自定义动作**：用户可创建自定义动作，动作按钮自定义

### 1.3 进阶功能

- **日志上传**：便于技术支持排查问题
- **手眼标定**：视觉校准功能
- **注册登录**：账号体系
- **双语设置**：中英文切换

### 1.4 在研功能（2026年8月）

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | **App 技能库** | 动作独立于 Agent 存储；机器人本地 + 云端技能库；官方/自定义分组；技能可添加到多个 Agent |
| P0 | **兼容 T2** | T2 机器人支持及专属功能适配 |
| P0 | **运营分发加速豆** | 后台管理加速豆分发 |
| P1 | **PC 版资源库及作品编辑器** | 桌面端资源管理和作品编辑（类似灵创） |
| P1 | **在线购买加速豆** | 支付功能、套餐选择 |
| P1 | **eSIM 支持** | 查看流量、切换连接方式、蜂窝网络 |
| P1 | **移动端作品编辑器** | 动作与作品分离、创作工具 |

### 1.5 未来规划（P2）

- 文档中心 AI 问答
- 技能社区（UGC 分享）
- 声音管理（音乐/音量调节）
- 视频流开关（节省带宽）
- 示教优化（入口外露、一键切换、关节阻力调整）
- 动作按钮交互优化（点击反馈、倒计时）
- 机器人本地动作库（离线可用）

## 三、AI 助手

> **定位**: 集成在 Booster Studio 中的智能编程助手，提供代码生成、调试、问答等 AI 辅助能力。

### 已有功能

- **AI 对话**：自然语言问答
- **代码生成**：根据描述生成代码
- **多文件编辑**：支持多文件项目
- **多模型支持**：
  - 国内主流模型（Kimi-K3、Qwen3.8Max 等）
  - 用户添加自定义模型

### 在研功能

| 优先级 | 功能 |
|---|---|
| P0（8月） | AI 助手支持配置 MCP（Model Context Protocol），自定义工具调用 |
| P0（8月） | 解决明显交互体验问题 |
| P0（8月） | AI 助手更名（品牌升级） |

### 未来规划

- **Agent 日志自动改代码**：自动调试、错误修复、代码优化
- **AI 辅助课程学习**：学习路径推荐、知识点讲解、习题解答

## 五、技能库 / 动作资源库

> **定位**: 独立于 Agent 的动作资源管理系统，实现动作的复用、共享、跨设备同步，构建动作资源生态。

### 5.1 核心概念

| 概念 | 说明 |
|---|---|
| **技能（Skill）** | 可复用的机器人动作资源 |
| **专属技能** | 只能在当前 Agent 中使用的技能 |
| **通用技能** | 可以在多个 Agent 中复用的技能 |
| **机器人技能库** | 存储在机器人本地的技能 |
| **云端技能库** | 绑定账号的云端技能，跨设备同步 |

### 5.2 已有功能

- Agent 动作面板（Agent 内的动作管理）
- 预置动作（官方预装）
- 自定义动作（用户创建）

### 5.3 在研功能（8月 P0）

**App 技能库**：
- 「机器人设置」中增加「技能库」入口
- 两个 Tab：当前机器人 / 我的云端
- 官方 / 自定义分组
- 技能创建、编辑、删除
- 复制到云端 / 从云端同步
- 从技能库添加到 Agent

### 5.4 未来规划

| 状态 | 功能 |
|---|---|
| P1 | 动作与作品分离（动作=基础单元，作品=组合+场景+逻辑） |
| P1 | 作品编辑器 |
| P2 | Studio 支持技能库 & 技能社区 |
| P2 | 技能社区——UGC 技能分享、点赞/评论/收藏、创作者激励 |

## 六、加速豆体系

> **定位**: Booster 平台的统一虚拟货币，用于购买云端算力、高级功能、增值服务等。

### 6.1 消费场景

| 场景 | 说明 |
|---|---|
| 云桌面租用 | 按配置和使用时长计费 |
| 云端仿真 | 云端运行虚拟机器人 |
| Motion Creator | 动作生成按次计费 |
| AI 助手高级功能 | 高级模型调用 |
| 技能库高级内容 | 付费技能 |
| 其他增值服务 | — |

### 6.2 在研功能（8月）

| 优先级 | 功能 |
|---|---|
| P0 | 完善消费监控 + 封号机制（详细消费明细、异常检测、违规封号） |
| P0 | 运营分发加速豆（后台管理、活动赠送、批量发放） |
| P1 | 在线购买加速豆（支付功能、套餐选择、充值记录） |

## 七、用户与账号体系

### 已有功能
