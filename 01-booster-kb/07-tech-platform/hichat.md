# HiChat — 语音对话 Agent

> **定位**: HiChat 是基于大语言模型的语音对话 Agent，让机器人具备自然语言交互能力，支持人设定制、多轮对话等功能。是 Booster 机器人的「AI 人格」系统。

---

## 一、基础对话能力

### 语音交互闭环

```
ASR（语音识别）→ LLM（理解+生成）→ TTS（语音合成）
```

- **语音识别（ASR）**：将用户语音转为文本
- **语音合成（TTS）**：将 AI 回复文本转为语音
- **自然语言理解**：理解用户意图并生成合理回复

### 多轮对话

- **上下文理解**：记住对话历史，理解指代和省略
- **连续对话**：无需每次唤醒
- **对话记忆**：会话内保持上下文

### 灯语反馈系统

机器人通过 LED 灯语实时反馈对话状态：

| 灯语 | 状态 | 含义 |
|---|---|---|
| 🔵 蓝色闪烁 | 正在听 | 麦克风收音中 |
| 🟡 黄色闪烁 | 正在思考 | AI 处理中 |
| ⚪ 白色闪烁 | 正在说话 | 扬声器播放中 |
| 🔴 红色持续 | 无网络 | 网络连接异常 |

灯语设计使得用户在人机对话中始终知道「机器人在干什么」——这是具身智能区别于纯软件 chatbot 的关键体验差异。

## 二、人设系统

### 默认人设

预置标准对话风格，具备基础问答能力。

### 自定义人设

可配置角色设定，实现个性化对话风格。**3 分钟即可创建专属 AI 角色**。

通过 `ChatConfig(system_prompt=...)` 配置（详见 [BoosterOS SDK §Speech](booster-sdk.md#31-speech--语音能力)）：

```python
from boosteros.brain import Speech
from boosteros.brain.speech import ChatConfig

speech = Speech(robot)
config = ChatConfig(
    system_prompt="你是一个热情专业的足球解说员...",
    voice="zh_female_1",
    volume=0.8,
)
speech.chat(config=config)
```

### 音量控制

支持自然语言调节音量：
- 「大一点」「小一点」— 模糊调节
- 「调整到 50%」— 精确调节

## 三、在研功能（v1.2 性能优化）

### 对话体验优化

| 优化项 | 说明 |
|---|---|
| **断句优化** | 等语义完整后再回复；支持带停顿的长句；多轮对话纠错 |
| **打断功能** | 默认人设支持打断；自定义人设可配置打断；解决自问自答问题 |
| **延迟降低** | 约 10% 性能提升 |
| **应用切换提速** | 已上线 |

### 网络优化

- **网络状态提示**：网络差时主动播报"网络不稳定，请稍后再试"
- **智能提醒**：3 分钟触发一次，避免频繁打扰
- **离线灯语**：无网络时红色灯语提示

## 四、未来规划

- **更多人设模板**：教育、娱乐、服务等场景化人设
- **技能调用**：对话中调用机器人技能（如「跳个舞」→ 触发舞蹈动作）
- **视觉对话**：结合视觉能力的多模态对话（看到什么聊什么）
- **多语言支持**：国际化扩展

## 五、教学应用

HiChat 在教学中是「AI 大模型应用」的最佳实践载体：

| 教学场景 | HiChat 角色 | 学习目标 |
|---|---|---|
| AI 启蒙 | 让学生体验与机器人自然对话 | 理解大模型基本概念 |
| Agent 人设设计 | 学生设计 system_prompt，对比不同人设 | 理解「人设即产品」 |
| 语音交互闭环 | 分析 ASR→LLM→TTS 链路 | 理解多模态 Agent 架构 |
| 综合项目 | 将 HiChat 集成到足球/迎宾项目中 | 系统集成能力 |
