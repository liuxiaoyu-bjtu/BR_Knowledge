# Booster T1 详细规格

## 核心定位

Booster T1 是**专为开发者打造**的旗舰科研平台，以"轻巧灵活、皮实耐摔"为核心设计理念。面向高校实验室、科研机构与开发者，支持前沿算法研究与竞赛。

## 三版本

| 版本 | 定位 |
|------|------|
| 基础版 | 标准科研配置，23自由度 |
| 标准版 | 增强配置，适合多场景科研 |
| 定制版 | 可扩展至41自由度，支持灵巧手 |

## 通用参数

### 物理规格

| 参数 | 数值 |
|------|------|
| 身高 | 约 1.2m |
| 重量 | 约 30kg |
| 基础自由度 | 23（单腿6、腰部1、单臂4、头部2） |
| 定制版自由度 | 最高可扩展至 41（含灵巧手） |
| 关节峰值扭矩 | 130N·m |
| 续航（行走） | 2h |
| 续航（站立） | 4h |
| 电池 | 10.5Ah |

### 计算平台

| 参数 | 规格 |
