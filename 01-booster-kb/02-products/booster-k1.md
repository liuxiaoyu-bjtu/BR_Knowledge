# Booster K1 详细规格

## 核心定位

Booster K1 是加速进化公司推出的**具身开发入门级平台**，起售价 **¥39,900**。面向 K-12 教育、中高职实训及赛事训练场景，提供三档配置满足不同预算与算力需求。

## 三版本对比

| 参数 | 极客版 | 教育版 | 专业版 |
|------|--------|--------|--------|
| 算力 | 48TOPS | 117TOPS | 200TOPS |
| 电池 | 2Ah | 5Ah | 5Ah |
| 续航（行走） | 20min（1.1m/s） | 1h10min（1.1m/s） | 1h10min（1.1m/s） |
| Wi-Fi | 支持 | Wi-Fi 6 | Wi-Fi 6 |
| 质保 | 3个月 | 1年 | 1年 |

## AI 能力

标配**豆包大模型**（含半年免费使用），支持：

- 自然语言交互
- 视觉识别与理解
- 任务规划与执行

## 预置 Agent

K1 出厂预置多款 Agent，覆盖教学演示与趣味互动场景：

| Agent 名称 | 功能说明 |
|------------|---------|
| Default Agent | 挥手、握手、爬起等基础交互动作 |
| Soccer Agent | 盯球、追球等足球竞赛行为 |
| Hi Chat | 中英文对话交互 |
| 轻松示教 | 动作示教与复现 |
| 舞蹈大师 | 舞蹈动作编排与表演 |
| 舞狮 | 舞狮动作演示 |

## 教育场景适配

Booster K1 适用于以下教育场景：

- **K-12 全学段**：小学科学启蒙、初中信息技术、高中人工智能课程
- **赛事训练**：RoboCup、全国青少年机器人竞赛等
- **社团活动**：机器人社团日常活动与成果展示
