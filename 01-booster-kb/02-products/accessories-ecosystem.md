# 配件生态

## 软件平台

### Booster Studio

一站式机器人管理与开发桌面应用，支持：

- 机器人连接与状态监控
- 动作编辑器与示教编程
- Agent 管理与切换
- 固件升级与诊断

### BoosterOS SDK

底层操作系统 SDK，提供：

- 关节控制 API
- 传感器数据流接口
- 运动规划库
- 电源与热管理接口

### ROS2 SDK

基于 ROS2 的标准开发工具包：

- 标准 ROS2 节点与话题
- SLAM 与导航集成
- 仿真环境支持（Gazebo/Ignition）
- RViz 可视化支持

### Booster GYM

强化学习训练环境：

- 基于 Isaac Gym / Isaac Sim 的仿真环境
- 预置训练任务（行走、转向、避障等）
- Sim-to-Real 迁移工具链
- 自定义任务扩展接口

## 赛事场地包

为 RoboCup 等机器人竞赛提供的标准场地套件：

| 组件 | 说明 |
|------|------|
| 标准足球场地 | 符合 RoboCup Humanoid League 规格 |
| 球门 | 标准尺寸球门 |
| 比赛用球 | 官方规格足球 |
| 场地标线 | 标准场地标线贴纸 |
| 便携收纳箱 | 场地组件收纳与运输 |

## 选配建议

| 使用场景 | 推荐配件 |
|---------|---------|
| 课堂教学（1-2台） | Booster Studio + 备用电池包 |
| 课堂教学（4台以上） | Booster Studio + 备用电池包 ×2 + 充电底座 |
| 竞赛训练 | ROS2 SDK + Booster GYM + 赛事场地包 |
| 科研开发 | BoosterOS SDK + ROS2 SDK + Booster GYM + 全套调试工具 |
| 教师培训 | Booster Studio + 备用电池包 |
