# 客户案例撰写模板

本模板供内部团队撰写新客户案例时参考使用，确保案例文档结构统一、内容完整。

## 模板结构

### 1. 案例背景

> 简要描述客户/合作方的基本情况，以及合作发起的背景与动因。

- 客户名称与类型（学校/科技馆/科研机构/企业）
- 客户所在地区与基本情况
- 合作发起的背景与需求
- 合作的初始时间与阶段

### 2. 实施方案

> 描述具体的实施路径、技术方案与关键举措。

- 使用的产品与平台（T1/K1/其他）
- 部署规模（设备数量、覆盖范围）
- 实施阶段与时间线
- 关键举措与创新点
- 培训与支持措施

### 3. 实施成果

> 量化与质化相结合地描述合作成果。

- 量化指标（覆盖学校数、参与人数、比赛成绩等）
- 质化成果（用户反馈、教学效果、媒体曝光等）
- 典型案例/亮点事件

### 4. 客户评价

> 收录客户方关键人物的评价与反馈。

- 评价人姓名、职务
- 评价内容（原话引用或概括）

### 5. 案例启示

> 提炼可复制的经验与关键洞察。

- 成功因素分析
- 可复制经验提炼
- 注意事项与改进建议
- 后续合作展望

---

## 使用说明

1. 新建案例文件命名为 `case-{标识}.md`
2. 复制本模板内容，逐项填写
3. 填写完成后将 status 改为 `completed`
4. 更新 `_index.md` 中的案例索引

---

## 案例状态标识

| 状态 | 含义 |
|------|------|
| `draft` | 撰写中，尚未完成 |
| `completed` | 已完成，可对外使用 |
| `archived` | 已归档，不再作为活跃案例使用 |
