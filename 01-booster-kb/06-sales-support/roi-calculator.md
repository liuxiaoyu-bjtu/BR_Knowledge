# 投资回报计算框架

本框架帮助销售人员和客户量化人工智能教育方案的投资回报，从多维度呈现方案价值。

## 一、学生受益维度

### 1.1 直接受益人数

| 指标 | 计算方式 |
|------|----------|
| 每学期上课学生 | = 班级数 × 每班人数 |
| 每年覆盖学生 | = 每学期学生数 × 2 |
| 三年覆盖学生 | = 每年学生数 × 3 |
| 人均投入 | = 总投入 / 三年覆盖学生数 |

**示例**：假设方案投入 80 万元，每年覆盖 300 名学生
- 三年覆盖：900 名学生
- 人均投入：80 万 / 900 ≈ 889 元/人
- 对比：校外 AI 编程班 5000-15000 元/人/年

### 1.2 能力培养量化

| 能力维度 | 培养方式 | 可衡量的成果 |
|----------|----------|-------------|
| 编程能力 | Python 课程体系 | 掌握 Python 基础语法和算法 |
| AI 素养 | 视觉/语音/大模型实践 | 理解 AI 基本原理并能应用 |
| 工程思维 | 项目制学习 | 独立完成一个机器人项目 |
| 竞赛能力 | 赛事培训和参赛 | 赛事获奖证书 |
| 升学助力 | 竞赛成绩 | 自主招生/综合评价加分 |

## 二、学校品牌提升

### 2.1 品牌价值维度

| 维度 | 价值描述 |
|------|----------|
| 特色学校申报 | 支撑"人工智能教育特色校""科技教育示范校"等申报 |
| 招生吸引力 | 家长择校时科技特色的加分项 |
| 社会关注度 | 媒体报道、教育系统内部参观学习 |
| 教师发展 | 教师课题研究、论文发表、职称评定支撑 |

### 2.2 示范效应量化

| 指标 | 预估价值 |
|------|----------|
| 区域参观交流 | 每年接待 XX 批次参观，提升学校知名度 |
| 媒体报道 | 预计获得 XX 次媒体曝光 |
| 课题/论文 | 支撑教师发表 XX 篇论文、申报 XX 个课题 |

## 三、赛事荣誉价值

### 3.1 赛事通路

```
校内选拔赛 → 区/县级赛 → 市级赛 → 省级赛 → 全国赛 → 国际赛（RoboCup等）
```

### 3.2 赛事荣誉价值

| 级别 | 荣誉 | 价值 |
|------|------|------|
| 校级 | 校内赛证书 | 综合素质评价加分 |
| 区/县级 | 区级获奖证书 | 中考综合评价加分（视地区政策） |
| 省/市级 | 省级获奖证书 | 自主招生/强基计划加分项 |
| 国家级 | 国家级获奖证书 | 强基计划重要参考、保送资格 |
| 国际级 | RoboCup 等国际赛事 | 留学申请重要加分项 |

## 四、ROI 综合计算模型

### 4.1 投入项

| 项目 | 金额 |
|------|------|
| 硬件设备 | A |
| 软件平台 | B |
| 课程资源 | C |
| 师资培训 | D |
| 赛事服务 | E |
| 三年维保 | F |
| **三年总投入** | **T = A+B+C+D+E+F** |

### 4.2 产出项（三年周期）

| 项目 | 价值 |
|------|------|
| 覆盖学生数 × 校外培训对比价 | G |
| 教师培训价值（替代外聘培训） | H |
| 赛事获奖价值 | I |
| 品牌提升价值（媒体曝光等） | J |
| 招生促进价值 | K |
| **三年总产出** | **O = G+H+I+J+K** |

### 4.3 ROI 计算

```
ROI = (O - T) / T × 100%
```

**典型场景**：
- 普通中学 T1 方案（20 万）：ROI 预估 200-400%
- 重点中学 K1 方案（100 万）：ROI 预估 150-300%
- 区域整体方案（500 万）：ROI 预估 300-500%

## 五、客户沟通话术

### 面向校长

> "校长，我们算一笔账。假设投入 80 万建 AI 实验室，三年覆盖 900 个学生。平均到每个学生不到 900 元，而校外 AI 编程班一年就要 1 万以上。更重要的是，实验室是学校的固定资产，课程和培训是持续增值的。加上竞赛获奖对招生的带动，这笔投入非常划算。"

### 面向教育局

> "领导，我们帮您算过。区域整体方案三年覆盖 5000 个学生，人均投入不到 1000 元。对比校外培训的市场价，相当于为每个家庭节省了上万元教育支出。而且这不仅是教育投入，更是区域教育现代化的政绩工程。"

## 六、辅助工具

建议制作标准化的 ROI 计算 Excel 模板，客户输入基本参数即可自动生成 ROI 分析报告。模板应包含：

- 参数输入区（学生数、班级数、方案类型）
- 自动计算区（覆盖学生、人均成本、ROI）
- 对比图表（与校外培训对比、与同类学校对比）
- 可打印报告
