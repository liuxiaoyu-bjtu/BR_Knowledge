# 标准演示流程

## 一、演示前准备

### 1.1 信息收集

- 客户类型（教育局/重点中学/普通中学/小学/机构）
- 参会人员（决策者/使用者/技术把关者）
- 关注重点（政策/品牌/课程/价格/竞赛）
- 竞品接触情况

### 1.2 设备检查清单

- [ ] K1/T1 机器人 × 2（至少 1 台备用）
- [ ] 电池充满，备用电池 × 2
- [ ] 笔记本电脑（演示 PPT + 编程环境）
- [ ] 遥控器/手柄
- [ ] 演示场地确认（平整、安全）
- [ ] 网络连接（如需云端功能）
- [ ] 演示道具（足球、障碍物等）

### 1.3 人员分工

| 角色 | 职责 |
|------|------|
| 主讲人 | PPT 讲解 + 整体控场 |
| 技术演示 | 机器人操作 + 编程演示 |
| 记录人 | 记录客户问题和关注点 |

## 二、演示环节设计（总时长 45-60 分钟）

### 环节一：开场破冰（3 分钟）

**目标**：建立信任，拉近距离

**要点**：
- 简短自我介绍和公司介绍
- 感谢客户时间
- 说明今天演示流程

**讲稿要点**：
> "感谢各位领导和老师抽出宝贵时间。今天我们的演示大概 45 分钟，先做一个简要介绍，然后请大家看机器人的实际演示，最后留时间交流。过程中有任何问题随时打断我。"

### 环节二：价值导入（5 分钟）

**目标**：建立认知，激发兴趣

**PPT 内容**：
1. 人工智能教育政策趋势（1 页）
2. 加速进化公司简介（1 页）
3. 核心产品能力（1 页）
4. 典型落地案例（1 页）

**讲稿要点**：
> "人工智能教育已经不是'要不要做'的问题，而是'怎么做'的问题。国家政策明确要求中小学开展 AI 教育。加速进化正是为这个需求而生——我们把人形机器人和 AI 教育结合起来，让学校可以快速落地。"

### 环节三：产品演示（15 分钟）

**目标**：眼见为实，制造惊喜

**演示顺序**：

1. **K1 运动演示**（5 分钟）
   - 行走、转弯、挥手
   - 足球踢球动作
   - 强调：这是真实的人形机器人运动控制

2. **K1 AI 交互演示**（5 分钟）
   - 语音对话（豆包大模型）
   - 视觉识别演示
   - 强调：大模型+机器人 = 真正的人工智能教育

3. **T1 教学演示**（5 分钟）
   - 编程控制演示
   - 传感器应用
   - 强调：从零基础到编程，一堂课就能上手

**讲稿要点**：
> "刚才大家看到 K1 行走、踢球，这背后是复杂的运动控制算法，也是我们 RoboCup 冠军技术的体现。再看它和人对话——这不是预先录制的，而是大模型实时理解后生成的动作和语音。"

### 环节四：课程展示（10 分钟）

**目标**：展示教学体系，打消"不会用"顾虑

**演示内容**：
1. 课程体系概览（PPT）
2. 教师用书和学生手册实物展示
3. Booster Studio 虚拟仿真平台演示
4. 编程案例实操（5 行代码让机器人动起来）

**讲稿要点**：
> "很多校长担心设备买回去不会用。我们的答案是'课程+培训+平台'三位一体。大家看这本教师用书——详细到每一句话怎么说。再看这个虚拟仿真平台——没有真机也能学编程。"

### 环节五：方案介绍（10 分钟）

**目标**：呈现完整方案，建立购买意向

**内容**：
1. 针对客户情况定制化的配置建议
2. 实施计划和培训安排
3. 服务承诺
4. 案例分享（最好是同区域/同类型学校）

**讲稿要点**：
> "根据贵校的情况，我们建议从 T1 教室方案起步，用一学期验证效果，下学期再考虑 K1 实验室建设。我们承诺培训到老师能独立上课为止。"

### 环节六：互动答疑（10 分钟）

**目标**：解答疑问，推进下一步

**要点**：
- 开放提问
- 记录关键问题
- 预约下一步行动（参观已落地学校/提交正式方案）

## 三、演示禁忌

1. **不讲技术参数** — 客户不关心有多少个自由度，关心能干什么
2. **不贬低竞品** — 只说自己的优势，不说别人的劣势
3. **不过度承诺** — 做不到的事情不要承诺
4. **不冷场尬聊** — 演示节奏要紧凑，遇到技术故障自然过渡
5. **不忽略任何人** — 注意观察每位参会者的反应，尤其是沉默的决策者

## 四、演示后跟进

| 时间节点 | 跟进动作 |
|----------|----------|
| 当天 | 发送感谢邮件 + 演示资料包 |
| 3 天内 | 电话/微信回访，了解反馈 |
| 1 周内 | 提交正式方案建议书 |
| 2 周内 | 邀请参观已落地学校 |
