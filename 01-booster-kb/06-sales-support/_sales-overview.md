# 销售支持体系总览

## 一、客户画像

### 1.1 教育局

| 维度 | 特征 |
|------|------|
| 决策链 | 局长/副局长 → 基教科/电教馆 → 装备中心 |
| 关注点 | 政策合规、区域覆盖、教育公平、示范效应 |
| 预算特点 | 专项资金/财政拨款，单笔金额大但周期长 |
| 决策周期 | 6-12 个月 |
| 典型产品 | K1 机器人、区域赛事方案、师训体系 |

### 1.2 重点中学（省重点/市重点）

| 维度 | 特征 |
|------|------|
| 决策链 | 校长 → 分管副校长 → 信息中心主任/教研组长 |
| 关注点 | 升学加分/自主招生、竞赛成绩、品牌效应 |
| 预算特点 | 学校自有经费+专项资金，50-200 万 |
| 决策周期 | 3-6 个月 |
| 典型产品 | K1+T1 混合方案、竞赛包、创新实验室 |

### 1.3 普通中学

| 维度 | 特征 |
|------|------|
| 决策链 | 校长 → 信息/科技教师 |
| 关注点 | 课程开设合规、性价比、师资培训 |
| 预算特点 | 有限，10-50 万 |
| 决策周期 | 1-3 个月 |
| 典型产品 | T1 机器人、标准课程包 |

### 1.4 小学

| 维度 | 特征 |
|------|------|
| 决策链 | 校长 → 科学/信息技术教师 |
| 关注点 | 趣味性、安全性、动手能力培养 |
| 预算特点 | 较小，5-20 万 |
| 决策周期 | 1-3 个月 |
| 典型产品 | T1 机器人、启蒙课程包 |

### 1.5 培训机构

| 维度 | 特征 |
|------|------|
| 决策链 | 创始人/教学总监 |
| 关注点 | 课程差异化、家长认可度、投资回报 |
| 预算特点 | 灵活，视规模而定 |
| 决策周期 | 1-2 个月 |
| 典型产品 | T1 机器人、课程授权、赛事合作 |

## 二、销售流程

```
初步接触 → 需求分析 → 方案演示 → 报价谈判 → 签约 → 交付实施
```

### 阶段一：初步接触（1-2 周）

- **渠道**：展会、行业会议、教育装备展、老客户转介绍、教育局推荐目录
- **目标**：建立联系，了解基本需求和预算范围
- **产出**：客户基本信息表、初步需求记录

### 阶段二：需求分析（1-2 周）

- **行动**：实地走访、与决策者/使用者分别沟通
- **分析维度**：
  - 学校定位与发展目标
  - 现有信息技术课程情况
  - 师资力量与培训需求
  - 预算来源与审批流程
  - 竞品接触情况
- **产出**：需求分析报告

### 阶段三：方案演示（1-3 周）

- **准备**：定制化方案 PPT、机器人实机演示、课程体验
- **参与人员**：技术工程师 + 销售经理
- **要点**：讲场景、讲价值、不讲参数
- **产出**：演示反馈记录、客户关注点清单

### 阶段四：报价谈判（1-4 周）

- **报价组成**：硬件 + 软件 + 课程 + 培训 + 赛事服务 + 维保
- **谈判策略**：先确认方案，再谈价格；拆分报价，灵活组合
- **产出**：正式报价单

### 阶段五：签约（1-2 周）

- **关键动作**：合同评审、技术协议、验收标准
- **注意**：明确交付时间、培训次数、售后服务条款
- **产出**：正式合同

### 阶段六：交付实施（4-8 周）

- **内容**：硬件交付 → 软件部署 → 教师培训 → 课程导入 → 验收
- **关键节点**：培训效果评估、首课观摩、学期总结
- **产出**：验收报告、培训记录
