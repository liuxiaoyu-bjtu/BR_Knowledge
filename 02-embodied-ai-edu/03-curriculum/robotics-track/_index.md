# 机器人课程线

## 概述

机器人课程线提供从基本操作到工程化开发的机器人技能进阶路径，聚焦于硬件操作、运动控制和系统集成能力培养。

## 进阶路径

```
L1 机器人初识 → L2 传感器世界 → L3 系统集成 → L4 工程化开发 → Research 运动控制前沿
```
