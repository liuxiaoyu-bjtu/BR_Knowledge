# 编程课程线

## 概述

编程课程线提供从图形化编程到 C++ 的完整编程能力进阶路径，是具身智能教育的基础课程线。所有其他课程线都依赖编程课程线提供的编程基础。

## 进阶路径

```
L1 图形化编程入门 → L2 Python 启航 → L3 Python 进阶/ROS2入门 → L4 ROS2进阶/C++
```
