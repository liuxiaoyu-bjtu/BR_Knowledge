# L1 机器人启蒙与具身表达

## 定位

L1 面向**机器人启蒙阶段（小学中高龄）**，重点建立学生对 K1 外部结构、身体功能、安全使用和具身表达方式的基础认知。课程通过**动作、语音、图形化编程和舞台作品**，引导学生理解机器人作为实体智能设备的表达方式与运行约束。

- **平台**：Booster K1（极客版/教育版）+ Booster Studio APP
- **形式**：通识课，课程资源含 PPT、教案、教师讲义
- **课时**：12 课次（大纲），含 2 次综合实践

## 核心能力目标

- 区分普通机器、工业机器人与人形机器人；理解人形机器人进入真实任务场景的背景
- 建立 K1「身体—感官—动作—语音」的具身表达基础认知
- 从"使用预设动作"过渡到"设计专属动作"，理解动作是具身表达的基本单位
- 初步建立顺序、循环、条件等计算思维结构

## 关键教具与平台

| 工具 | 作用 |
|------|------|
| K1 机器人 | 实体观察、操控、动作创造、语音输出 |
| Booster Studio APP | 连接、第一视角、示教 Agent、图形化编程 |
| 示教 Agent | 动作录制/回放、综合操控认证 |

## 教学特色

- **认知转译策略**：L1 大量采用"三层转译法"（具象→类比→抽象）处理仿生、具身智能等抽象概念（如用"看见水杯→想喝水→伸手拿"类比感知-决策-行动）。
- **项目制收束**：以"机器人情景剧"为终端项目，技术服务于主题表达，经历选题→创作→彩排→展演→复盘。
- **角色进阶叙事**：从"遥控师"→"编程师"→"动作设计师"，用角色转变维持学习动机。

## 项目成果与评估

- **终端项目**：机器人情景剧（动作 + 语音 + 图形化逻辑整合的舞台作品）
- **评估维度**：动作表达、语音配合、逻辑正确性、协作分工、展演与复盘表达

## 跨级衔接

- **前置**：无（启蒙入口）
- **→ L2**：L1 建立的"功能体验 + 图形化顺序/循环/条件"是 L2「任务型行为组织」的操作与思维基础；L2 将把单点技能放进"校园智能导览员"真实任务中。
