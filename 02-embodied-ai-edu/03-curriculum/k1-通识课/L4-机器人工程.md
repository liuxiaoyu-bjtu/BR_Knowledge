# L4 机器人工程与智能闭环

## 定位

L4 面向**机器人工程实践与智能闭环构建阶段（高中/大学入门）**，课程以**机器人足球任务**作为典型场景，系统覆盖目标检测、持续跟随、目标丢失处理、追球决策与动作执行等环节。

- **平台**：Booster K1（教育版）+ 开发环境（远程连接）+ ROS2 + BoosterOS SDK
- **形式**：通识课，16 课次（大纲），终端为可运行的"自主追球与执行踢球动作"系统
- **设计哲学**：从写脚本走向写工程——系统必须可组织、可复用、可部署；工程价值体现在结构复用与可迁移实现

## 核心能力目标

- 将 K1 理解为"具备行动能力的计算平台"，进入背后的软件环境与工具链
- 理解机器人模块通信（节点/话题/消息/服务），用工程接口思维替代函数调用思维
- 构建"感知→坐标→策略→动作"的完整智能闭环
- 设计异常行为（目标丢失处理），建立"不确定性是常态"的真实系统意识

## 关键教具与平台

| 工具 | 作用 |
|------|------|
| K1 教育版 + 远程开发环境 | 代码运行、功能包管理 |
| ROS2 | 节点/话题/服务、Launch、功能包 |
| YOLO 目标检测 | 足球检测、结构化结果（位置+置信度） |
| 状态机 / 策略 | TRACK/FIND/SCAN、VisualKick 踢球策略 |

## 教学特色

- **工程化跃迁**：L4 明确从"写脚本"转向"写工程"（功能包、Launch、可部署），强调结构复用与可迁移。
- **真实系统鲁棒性**：专门设计"目标丢失处理"等环节，让学生直面不确定性，建立异常处理意识。
- **最小闭环叠加**：从人脸检测挥手（最小感知-行动闭环）→ 头部跟随 → 稳态跟随 → 坐标系变换 → 踢球决策，逐级叠加成完整智能闭环。

## 项目成果与评估

- **终端项目**：自主追球与执行踢球动作任务（"感知→坐标→策略→动作"完整智能闭环）
- **评估维度**：检测稳定性、跟随鲁棒性、丢失恢复、踢球决策、工程复盘与迁移思考
- **赛事衔接**：直接对应 [RoboCup 足球](../../../03-cross-reference/competition-to-curriculum.md) 与人形机器人足球赛道

## 跨级衔接

- **← L3**：承接 L3 的代码控制、视觉闭环、状态机，升级为 ROS2 工程化与 YOLO 级感知。
- **→ 清华工训 / Research**：L4 足球任务是 [清华工训中心课程](./清华工训中心课程.md) 的核心主线（自主追球 + VisualKick 视觉踢球），并可延伸至强化学习、Sim-to-Real、VLA 等科研方向。
