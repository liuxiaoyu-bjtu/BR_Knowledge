# K1 通识课体系（落地课纲）

> 本区是 **Core B 课程体系规范矩阵**（见 [_curriculum-overview](../_curriculum-overview.md)）在「机器人课程线」上的**已交付落地实例**。它以加速进化 Booster K1 人形机器人为核心载体，是面向中小学（并延伸至大学工程训练）的递进式机器人系统认知与工程实践课纲。
>
> 原始素材（课程库说明、L1-L4 大纲与教案、清华工训中心课程）完整归档于 [05-internal-materials/course-outlines](../../../05-internal-materials/course-outlines)。

## 一、课程定位

以 **K1 人形具身智能机器人**为核心载体，面向中小学不同学段构建**递进式机器人系统认知与工程实践**课程路径。K1 作为高度集成的人形机器人产品，包含机械结构、传感器、执行器、控制系统、计算平台、通信机制、软件接口和任务逻辑等组成部分；课程以该真实系统为对象，引导学生在**观察、操作、编程、调试与项目实践**中理解智能系统的构成与运行机制。

认知路径遵循复杂系统学习规律：

```
外部结构认知 ──▶ 任务行为组织 ──▶ 内部模块理解 ──▶ 智能闭环系统工程化构建
   (L1)            (L2)            (L3)               (L4)
```

课程强调**真实设备、真实任务、真实反馈**——学生需处理空间、光线、声音、姿态、延迟、误差和环境变化等现实因素，建立面向真实世界的系统思维与工程意识。

## 二、核心能力目标（全体系通用）

| 能力 | 含义 |
|------|------|
| 复杂系统理解能力 | 认识真实智能产品中机械、感知、计算、通信、控制与执行模块的协同关系 |
| 感知行动组织能力 | 理解机器人如何从环境中获取信息，并将信息转化为可执行行为 |
| 自主行为构建能力 | 基于目标、规则、状态与反馈组织机器人连续行动 |
| 现实对象计算化能力 | 将声音、图像、位置、颜色、距离等现实对象转化为可计算、可判断、可调用的数据结构 |
| 工程调试与复盘能力 | 围绕任务目标开展测试、排查、优化和成果表达 |

## 三、四阶等级结构

| 等级 | 系统认知阶段 | 核心学习对象 | 能力发展目标 | 项目成果 | 学段映射 | 详细分析 |
|------|------------|------------|------------|---------|---------|---------|
| **L1** | 外部结构与具身表达 | 身体、感官、动作、语音、基础使用 | 从"机器人是什么"到"机器人如何通过身体表达" | 机器人情景剧 | 小学中高龄 | [L1 机器人启蒙](./L1-机器人启蒙.md) |
| **L2** | 任务分析与行为组织 | 场景、对象、流程、条件、变量、交互 | 从"控制功能"到"围绕任务组织机器人行为" | 校园智能导览员 | 初中 | [L2 机器人应用](./L2-机器人应用.md) |
| **L3** | 内部模块与系统集成 | 代码、语音、视觉、图像流、识别、状态机 | 从"机器人执行程序"到"多系统模块协同完成自主行动" | 二维码迷宫探索 | 高中 | [L3 机器人系统与项目实践](./L3-机器人系统与项目实践.md) |
| **L4** | 工程研发与智能闭环 | 通信、节点、服务、检测、坐标、策略、调试 | 从"完成项目"到"像工程师一样构建可迁移的智能任务系统" | 自主追球与执行踢球动作 | 高中/大学入门 | [L4 机器人工程](./L4-机器人工程.md) |

> **进阶延伸**：[清华工训中心具身智能课程](./清华工训中心课程.md) 是 L4 的大学/工程训练层级拔高版（18 章 5 部分，覆盖控制、动作生成、感知、策略行为、系统整合），可作为 L4 之后或特色校/高校合作的拓展课纲。

## 四、与 Core B 规范矩阵的映射

K1 通识课四阶是下方「四大领域 × 五学段」矩阵中**机器人课程线**的主干落地，并横向牵动编程线、AI 线与跨学科线：

| 通识阶 | 对应学段 | 机器人线落点 | 牵动编程线 | 牵动 AI 线 |
|--------|---------|------------|-----------|-----------|
| L1 | 小学高龄 | 机器人初识 / 基础运动控制 | 图形化编程入门（顺序·循环·事件） | AI 初体验（机器能看/听吗） |
| L2 | 初中 | 传感器世界 / 运动控制进阶 | Python 启航（变量·条件·函数） | 计算机视觉入门 / 简单决策 |
| L3 | 高中 | 系统集成 / 自主导航 | ROS2 入门（Topic·Service·Node） | 机器学习入门 / 状态机设计 |
| L4 | 大学入门 | 工程化开发 / 系统架构 | C++ 机器人编程 / ROS2 进阶 | 强化学习 / Sim-to-Real / VLA |
