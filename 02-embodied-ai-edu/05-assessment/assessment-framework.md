# 评估框架

## 概述

评估框架定义了具身智能教育的多维度评估体系。评估不仅关注最终的编程结果，更关注学生在"感知-决策-执行"全过程中的能力发展。

## 评估原则

1. **过程与结果并重**：既评估最终成果，也评估开发过程
2. **多维度评估**：覆盖五大核心素养的全面评估
3. **多元主体**：教师评估 + 同伴互评 + 自我评估
4. **证据驱动**：基于可观察、可记录的证据进行评估
5. **促进学习**：评估的目的是促进学习，而非简单排名

## 评估维度

### 五维评估模型

```
┌──────────────────────────────────────────────────────────────┐
│                      五维评估模型                              │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│ 知识理解  │ 技能应用  │ 系统思维  │ 工程素养  │ 协作与表达        │
├──────────┼──────────┼──────────┼──────────┼─────────────────┤
│ 概念掌握  │ 编程能力  │ 系统分析  │ 调试能力  │ 团队协作          │
│ 原理理解  │ 操作能力  │ 问题拆解  │ 优化能力  │ 沟通表达          │
│ 知识迁移  │ 创新能力  │ 方案设计  │ 文档规范  │ 项目展示          │
└──────────┴──────────┴──────────┴──────────┴─────────────────┘
```

### 维度详解

| 维度 | 权重 | 评估要点 | 评估方式 |
|------|------|---------|---------|
| 知识理解 | 20% | 概念掌握、原理理解、知识迁移 | 笔试/口试 |
| 技能应用 | 25% | 编程能力、操作能力、创新能力 | 实操作品 |
| 系统思维 | 20% | 系统分析、问题拆解、方案设计 | 项目报告 |
| 工程素养 | 25% | 调试能力、优化能力、文档规范 | 过程记录 |
| 协作与表达 | 10% | 团队协作、沟通表达、项目展示 | 展示评审 |

## 评估方法

### 过程性评估（60%）

| 评估项 | 说明 | 频率 | 占比 |
|--------|------|------|------|
| 课堂表现 | 出勤、参与度、课堂任务完成情况 | 每节课 | 10% |
| 编程练习 | 课后编程作业 | 每周 | 15% |
| 项目进展 | 阶段成果检查和反馈 | 每两周 | 15% |
| 调试日志 | 问题记录和解决过程 | 持续 | 10% |
| 团队贡献 | 组内互评 | 每月 | 10% |

### 终结性评估（40%）

| 评估项 | 说明 | 频率 | 占比 |
|--------|------|------|------|
| 项目成果 | 最终项目的完成度和质量 | 每学期 | 20% |
| 项目展示 | 成果汇报和答辩 | 每学期 | 10% |
| 知识测试 | 核心概念和原理测试 | 每学期 | 10% |

### 赛事评估（加分项）

| 评估项 | 说明 | 加分 |
|--------|------|------|
| 校级赛事 | 参与校级比赛 | +5% |
| 区/市级赛事 | 获得奖项 | +10% |
| 省级赛事 | 获得奖项 | +15% |
| 国家级/国际赛事 | 获得奖项 | +20% |

## 评估工具

### 评估量表（Rubric）

#### 编程能力评估量表

| 等级 | 标准 | 描述 |
|------|------|------|
| 优秀 (A) | 代码结构清晰、有注释、运行稳定、有创新 | 超出基本要求 |
| 良好 (B) | 代码可运行、逻辑正确、基本功能完成 | 达到要求 |
| 合格 (C) | 代码基本可运行、存在小问题 | 接近要求 |
| 待改进 (D) | 代码无法运行或功能严重缺失 | 未达要求 |

#### 项目评估量表

| 维度 | 优秀 (A) | 良好 (B) | 合格 (C) | 待改进 (D) |
|------|---------|---------|---------|-----------|
| 功能完整性 | 超出要求 | 全部完成 | 基本完成 | 大量缺失 |
| 代码质量 | 优秀 | 良好 | 可接受 | 较差 |
| 创新性 | 显著创新 | 有创新 | 常规方案 | 无创新 |
| 文档质量 | 规范详细 | 完整 | 基本完整 | 缺失 |
| 展示表达 | 清晰流畅 | 表达清楚 | 基本表达 | 表达困难 |

## 学段评估侧重

| 学段 | 评估侧重 | 评估形式 |
|------|---------|---------|
| L1 | 参与度和兴趣 | 观察记录、作品展示 |
| L2 | 基础技能和协作 | 任务完成、组内互评 |
| L3 | 系统能力和工程素养 | 项目报告、代码审查 |
| L4 | 创新和研究能力 | 论文/报告、答辩 |
