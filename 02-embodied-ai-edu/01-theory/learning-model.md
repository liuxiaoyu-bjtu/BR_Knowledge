# "感知-决策-执行"学习模型

## 概述

"感知-决策-执行"学习模型是具身智能教育的核心学习机制。它描述了学生如何通过与机器人的交互，在"感知→决策→执行→反馈→再感知"的循环中实现深度学习。

## 模型架构

```
┌──────────────────────────────────────────────────────────────┐
│              "感知-决策-执行"学习模型                           │
│                                                                │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐             │
│   │   感知    │ ──→ │   决策    │ ──→ │   执行    │             │
│   │ PERCEIVE  │     │ DECIDE   │     │   ACT    │             │
│   └──────────┘     └──────────┘     └──────────┘             │
│        ↑                                  │                   │
│        │                                  ↓                   │
│        │          ┌──────────┐     ┌──────────┐             │
│        └──────────│   反思    │ ←── │   观察    │             │
│                   │ REFLECT  │     │ OBSERVE  │             │
│                   └──────────┘     └──────────┘             │
│                                                                │
│         ← 机器人行为 →  ← 学生认知活动 →                       │
└──────────────────────────────────────────────────────────────┘
```

## 学习循环详解

### 第一层：机器人行为循环（机器视角）

```
感知（Perception）      决策（Decision）       执行（Action）
─────────────────    ─────────────────    ─────────────────
• 摄像头采集图像       • 图像处理与分析       • 电机驱动
• IMU 读取姿态        • 路径规划算法         • 关节运动
• 力传感器读数        • 行为策略选择         • 动作输出
• 距离传感器测距       • AI 模型推理          • 环境交互
```

### 第二层：学生认知循环（学习视角）

```
观察（Observe）        反思（Reflect）       调整（Adjust）
─────────────────    ─────────────────    ─────────────────
• 观察机器人行为        • 分析行为与预期的差距   • 修改代码/参数
• 记录关键数据          • 定位问题根因         • 调整算法策略
• 发现异常现象          • 形成改进假设         • 优化硬件配置
```

### 两层循环的耦合

机器人的行为循环和学生的认知循环不是独立的，而是紧密耦合的：

```
学生认知活动层
    ↓ 编程/配置
机器人行为层
    ↓ 运行
物理世界反馈
    ↓ 观察
学生认知活动层
    ↓ 反思
    ↓ 调整
机器人行为层（再次）
    ...
```

## 学习阶段模型

### 阶段一：感知阶段（Perceive Phase）

学生在感知阶段学习如何让机器人获取环境信息。

| 学习目标 | 活动设计 | 学习产出 |
|---------|---------|---------|
| 理解传感器原理 | 传感器数据读取实验 | 能够获取和可视化传感器数据 |
| 数据处理能力 | 数据滤波、特征提取练习 | 理解噪声和信号处理 |
| 多传感器融合 | 多传感器数据综合分析 | 建立环境感知的综合视图 |

**典型问题**：
- "摄像头看到了什么？"
- "IMU 数据告诉我机器人的姿态是什么？"
- "距离传感器检测到障碍物了吗？"

### 阶段二：决策阶段（Decide Phase）

学生在决策阶段学习如何基于感知信息做出决策。

| 学习目标 | 活动设计 | 学习产出 |
|---------|---------|---------|
| 规则决策 | if-else 条件判断编程 | 实现基于规则的行为 |
| 状态机决策 | 有限状态机设计 | 实现行为切换逻辑 |
| 算法决策 | 路径规划、策略选择 | 实现优化决策 |
| AI 决策 | 机器学习模型部署 | 实现基于学习的决策 |

**典型问题**：
- "看到红色应该做什么？"
- "如何在多个可能动作中选择最优的？"
- "如何让机器人在不同状态下切换行为？"

### 阶段三：执行阶段（Act Phase）

学生在执行阶段学习如何将决策转化为机器人的物理动作。

| 学习目标 | 活动设计 | 学习产出 |
|---------|---------|---------|
| 基本运动控制 | 前进、后退、转弯编程 | 掌握基础运动指令 |
| 复杂动作序列 | 动作编排和时序控制 | 实现多步骤动作序列 |
| 精确控制 | PID 控制参数调优 | 实现精确的运动控制 |
| 动态控制 | 实时反馈控制 | 实现闭环运动控制 |

**典型问题**：
- "如何让机器人精确走到指定位置？"
- "为什么机器人走不直？如何修正？"
- "如何让机器人在运动中保持平衡？"

### 阶段四：反馈阶段（Feedback Phase）

反馈阶段是学习循环的关键环节，学生通过观察执行结果来调整和优化。

| 反馈类型 | 来源 | 学习价值 |
|---------|------|---------|
| 视觉反馈 | 机器人运动轨迹 | 直观理解算法效果 |
| 数据反馈 | 传感器日志 | 定量分析性能 |
| 结果反馈 | 任务完成/失败 | 评估整体方案 |
| 对比反馈 | 与其他方案的比较 | 启发改进思路 |

## 学段学习模型适配

### L1（小学高龄）：直观循环

```
看到 → 操作 → 看到结果
（以直观观察和简单操作为主）
```

**特点**：感知-执行直接关联，决策逻辑简单
**工具**：图形化编程、遥控操作
**示例**：按下一个按钮→机器人前进→观察机器人走到哪里

### L2（初中）：条件循环

```
感知条件 → 条件判断 → 执行动作 → 观察结果 → 调整条件
（引入条件逻辑和简单循环）
```

**特点**：在感知和执行之间加入条件判断
**工具**：图形化+文本过渡编程
**示例**：检测到红色→左转→观察是否避开了障碍→调整颜色阈值

### L3（高中）：策略循环

```
多传感器感知 → 策略决策 → 复杂动作 → 数据分析 → 策略优化
（引入多传感器融合和策略优化）
```

**特点**：感知、决策、执行各环节复杂度大幅提升
**工具**：Python 编程、ROS2 入门
**示例**：视觉+IMU 融合→路径规划算法→自主导航→分析轨迹数据→优化路径

### L4（大学入门）：智能循环

```
环境感知 → AI决策 → 自主执行 → 系统评估 → 算法迭代
（引入 AI 和自主学习能力）
```

**特点**：决策环节引入机器学习和强化学习
**工具**：ROS2、GYM、PyTorch
**示例**：SLAM 建图→强化学习策略→自主任务执行→性能评估→算法迭代优化

## 学习模型的评估应用

| 评估维度 | 观察指标 | 评估方法 |
|---------|---------|---------|
| 感知能力 | 传感器使用正确率、数据理解深度 | 实验报告 |
| 决策能力 | 策略合理性、算法效率 | 代码审查+性能测试 |
| 执行能力 | 动作精度、任务完成度 | 现场测试 |
| 反馈能力 | 问题定位速度、优化效果 | 迭代记录 |

## 与教学法的关系

"感知-决策-执行"学习模型是教学法设计的底层机制：

| 教学法 | 学习模型侧重 |
|--------|------------|
| 以赛促学 | 强调执行和反馈环节，赛事结果作为反馈 |
| 任务驱动 | 每个任务对应一个完整的感知-决策-执行循环 |
| 项目式学习 | 多个循环的嵌套和迭代 |
| 协作学习 | 在反馈阶段引入同伴观察和评审 |
