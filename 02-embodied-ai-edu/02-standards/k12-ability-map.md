# K-12 全学段能力图谱

## 概述

K-12 全学段能力图谱定义了从小学高龄到大学入门的四个能力等级（L1-L4），每个等级对应特定的学段、认知水平和能力目标。该图谱是课程设计和教学评估的核心参照。

## 能力分级总览

```
┌─────────────────────────────────────────────────────────────────┐
│                    K-12 全学段能力进阶路径                          │
├──────────┬──────────────┬──────────────┬────────────────────────┤
│   L1     │     L2       │     L3       │         L4             │
│ 小学高龄  │    初中       │    高中       │    特色校/大学入门       │
```

## L1：小学高龄（4-6年级）

### 学段特征

- 认知阶段：具体运算阶段
- 思维特点：以具象思维为主，开始发展逻辑思维
- 学习特点：好奇心强，动手意愿高，注意力持续时间有限

### 能力目标

| 能力维度 | 具体目标 |
|---------|---------|
| 机器人认知 | 认识机器人的基本组成部分（传感器、执行器、控制器） |
| 编程能力 | 掌握图形化编程的基本概念（顺序、循环、事件） |
| 具身表达 | 通过编程让机器人执行简单的动作和表情 |
| 安全意识 | 了解机器人操作的基本安全规范 |
| 协作能力 | 能够与同伴合作完成简单任务 |

### 课程核心

- **编程**：图形化编程（Blockly/Scratch 风格）
- **操作**：遥控操作、简单动作编程
- **任务**：机器人舞蹈、简单巡线、颜色识别
- **赛事**：趣味赛、创意展示

### 典型学习活动

1. "让机器人走一个正方形"
2. "让机器人跟着黑线走"
3. "机器人舞蹈比赛"
4. "颜色识别大挑战"

---

## L2：初中（7-9年级）

### 学段特征

- 认知阶段：形式运算初期
- 思维特点：开始发展抽象思维和假设推理能力
- 学习特点：求知欲强，喜欢挑战，开始形成学科兴趣

### 能力目标

| 能力维度 | 具体目标 |
|---------|---------|
| 任务拆解 | 能够将复杂任务分解为可执行的子任务 |
| 编程能力 | 掌握条件判断、循环、变量、函数等编程概念 |
| 感知应用 | 能够使用多种传感器（视觉、距离、触觉）获取信息 |
| 调试能力 | 初步掌握系统化的问题排查方法 |
| 团队协作 | 能够进行角色分工和有效协作 |

### 课程核心

- **编程**：图形化→Python 过渡编程
- **感知**：多传感器数据读取和处理
- **任务**：条件避障、自主导航、目标跟踪
- **赛事**：挑战赛、校际联赛

### 典型学习活动

1. "自主避障迷宫挑战"
2. "视觉循线竞速赛"
3. "多传感器环境感知项目"
4. "机器人足球 1v1 对抗"

---

## L3：高中（10-12年级）

### 学段特征

- 认知阶段：形式运算阶段
- 思维特点：具备系统思维和抽象推理能力
- 学习特点：目标导向，关注升学价值，能够进行深度学习

### 能力目标

| 能力维度 | 具体目标 |
|---------|---------|
| Python编程 | 熟练掌握 Python 编程，理解面向对象和模块化设计 |
| 系统集成 | 能够整合硬件、软件、算法形成完整系统 |
| 自主行动 | 设计和实现机器人的自主决策和行为 |
| 算法理解 | 理解基础 AI 算法（路径规划、图像处理、状态机） |
| 工程文档 | 能够撰写规范的技术文档和项目报告 |

### 课程核心

- **编程**：Python 编程（面向对象、多线程）
- **算法**：路径规划、图像处理、状态机
- **系统**：ROS2 入门、系统架构设计
- **赛事**：RoboCup 青少年组、科技创新大赛

### 典型学习活动

1. "自主导航与 SLAM 入门"
2. "基于视觉的目标识别与跟踪"
3. "RoboCup 足球进攻策略开发"
4. "强化学习步态优化实验"

---

## L4：特色校/大学入门

### 学段特征

- 认知阶段：后形式思维
- 思维特点：能够进行复杂的系统性思考和独立研究
- 学习特点：自主学习能力强，关注前沿技术和学术价值

### 能力目标

| 能力维度 | 具体目标 |
|---------|---------|
| ROS2开发 | 熟练使用 ROS2 进行机器人应用开发 |
| 视觉闭环 | 实现基于视觉的闭环控制系统 |
| 工程化开发 | 掌握版本控制、测试、CI/CD 等工程化方法 |
| 强化学习 | 理解并使用强化学习算法训练机器人行为 |
| 学术研究 | 能够开展小型研究项目，撰写学术论文 |

### 课程核心

- **框架**：ROS2 深度应用、Gazebo 仿真
- **AI**：强化学习、Sim-to-Real 迁移
- **工程**：Git 版本控制、自动化测试、模块化架构
- **赛事**：RoboCup 成人组、学术论文

### 典型学习活动

1. "ROS2 机器人全栈开发项目"
2. "基于强化学习的步态生成"
3. "Sim-to-Real 迁移实验"
4. "RoboCup 完整参赛项目"

## 能力进阶矩阵

| 能力维度 | L1 | L2 | L3 | L4 |
|---------|----|----|----|----|
| 编程语言 | 图形化 | 图形化+Python | Python | Python/C++ |
| 机器人框架 | — | — | ROS2入门 | ROS2精通 |
| 传感器使用 | 1种 | 2-3种 | 多传感器融合 | 传感器选型 |
| 控制方式 | 遥控 | 半自主 | 自主 | 学习驱动 |
| 调试方法 | 试错 | 系统排查 | 数据驱动 | 自动化测试 |
| 项目规模 | 1-2课时 | 1-2周 | 1个月 | 一学期 |
| 赛事等级 | 校级 | 区/市级 | 省级/国家 | 国际级 |
| 推荐产品 | T1 | T1/T2 | T2 | T2/T3 |

## 跨学段衔接

```
L1 → L2 衔接重点：
• 从图形化过渡到文本编程
• 从遥控操作过渡到半自主
• 从单一传感器过渡到多传感器

L2 → L3 衔接重点：
• 从半自主过渡到自主决策
• 从任务执行过渡到系统设计
• 引入 AI 算法概念

L3 → L4 衔接重点：
• 从 Python 编程过渡到工程化开发
• 从基础算法过渡到强化学习
• 从竞赛参与过渡到学术研究
```

## 高职能力模型（参考）

> 以下内容来源于 [高职具身智能课程开发知识库与系统调研报告](../../05-internal-materials/vocational-planning/2026-07-29_高职具身智能课程开发知识库与系统调研报告.md)（AnyGen，2026-07-29），作为高职课程线的能力分层参考。正式纳入 B2 能力图谱需待高职课程框架设计完成后。

### 高职与 K12 的关键差异

| 维度 | K12 课程设计 | 高职课程设计 |
|------|------------|------------|
| 基本逻辑 | 学科课程标准、核心素养、学段目标 | 专业教学标准、岗位能力、典型工作任务、职业素养 |
| 内容来源 | 学科知识结构与学生发展规律 | 岗位任务、产业需求、技术迭代、职业证书、技能竞赛 |
| 课程组织 | 单学科课程为主，跨学科主题逐步增强 | 课程群、项目化课程、模块化课程、理实一体化、产教融合 |
| 学习结果 | 学科理解、核心素养、升学衔接 | 能完成真实/仿真工作任务，达到岗位初任能力 |
| 评价方式 | 纸笔测验、表现性评价、综合素质评价 | 过程评价、项目成果评价、实践技能考核、岗位任务评价、企业参与评价 |

### 高职六层能力模型

| 层级 | 学生应达到的能力 | 适合课程任务 |
|------|----------------|------------|
| L1 认知入门 | 认识具身智能、机器人系统组成、典型应用场景 | 拆解机器人、观察足球机器人工作流程 |
| L2 工具使用 | 会使用开发环境、仿真平台、数据工具、机器人 SDK | 环境配置、运行 Demo、读取传感器数据 |
| L3 单项技能 | 完成视觉识别、运动控制、语音交互、路径规划等单项任务 | 识别足球、控制机器人行走、避障 |
| L4 综合集成 | 把多个模块集成为完整应用 | 完成机器人找球、走向球、踢球、回位 |
| L5 工程交付 | 完成测试、部署、文档、演示、维护 | 形成可交付项目包、测试报告、演示答辩 |
| L6 创新拓展 | 面向竞赛或企业问题进行优化 | 多机器人协作策略、比赛策略优化、稳定性提升 |

### 高职课程能力边界

- ✅ 会配置、会调用、会集成、会调试、会部署、会评价
- ✅ 知道算法解决什么问题，能读懂模型输入输出
- ✅ 会采集和标注简单数据，会调用训练好的模型或平台工具
- ✅ 会用仿真平台完成测试，会部署到机器人并调试
- ❌ 不以独立推导深度学习算法为核心目标
- ❌ 不以从零构建底层机器人控制框架为课程目标
