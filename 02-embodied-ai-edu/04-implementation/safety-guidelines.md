# 安全操作规范

## 概述

安全是具身智能教育的第一准则。本规范覆盖设备安全、操作安全、场地安全和应急处理，确保教学活动在安全的环境中进行。

## 一、设备安全

### 机器人安全设计

| 安全特性 | 说明 |
|---------|------|
| 急停按钮 | 每台机器人配备物理急停按钮 |
| 过流保护 | 电机过载自动断电 |
| 温度监控 | 核心部件温度异常自动降频 |
| 跌落保护 | 检测到倾倒自动关闭电机 |
| 软件限位 | 关节角度软件限制 |

### 日常检查

| 检查项目 | 频率 | 责任人 |
|---------|------|--------|
| 外观检查（裂纹、松动） | 每次课前 | 教师 |
| 电池状态 | 每次课前 | 教师 |
| 连接线检查 | 每周 | 教师 |
| 传感器校准 | 每月 | 技术支持 |
| 固件更新 | 每学期 | 技术支持 |

## 二、操作安全

### 学生操作规范

1. **开机前检查**：确认机器人放置在安全位置，周围无障碍物
2. **测试时保持距离**：机器人运行时保持至少 0.5 米安全距离
3. **禁止触碰运动部件**：机器人运行时禁止触碰关节和运动部件
4. **紧急情况处理**：发现异常立即按下急停按钮
5. **一人操作**：同一时间只允许一人操作一台机器人

### 教师监督要求

| 场景 | 教师要求 |
|------|---------|
| 机器人开机运行 | 必须在场监督 |
| 学生首次操作 | 一对一指导 |
| 多人同时测试 | 控制同时运行的机器人数不超过 3 台 |
| 赛事/比赛 | 额外安排 1 名安全员 |

## 三、场地安全

### 场地要求

| 要求 | 标准 |
|------|------|
| 地面 | 平整、防滑，无杂物 |
| 空间 | 每台机器人至少 2m × 2m 操作空间 |
| 照明 | 充足均匀，避免强光直射传感器 |
| 通风 | 保持良好通风 |
| 电源 | 插座有接地保护，线路不裸露 |

## 四、应急处理

### 常见紧急情况

| 情况 | 表现 | 处理步骤 |
|------|------|---------|
| 机器人失控 | 不受控制地运动 | ①立即按急停 ②断开电源 ③检查原因 |
| 机器人摔倒 | 失去平衡倒地 | ①保持距离 ②确认停止后扶起 ③检查损坏 |
| 电池发热 | 电池异常发热 | ①断开电源 ②移至通风处 ③不要触碰 |
| 冒烟/异味 | 出现烟雾或异味 | ①立即断电 ②疏散学生 ③使用灭火器 |
| 夹伤/碰伤 | 学生被机器人碰伤 | ①停止操作 ②查看伤情 ③必要时就医 |

## 五、安全教育培训

### 学生安全第一课（必修）

| 内容 | 时间 | 形式 |
|------|------|------|
| 机器人安全操作规范 | 15min | 讲解+演示 |
| 急停按钮使用方法 | 5min | 实操练习 |
| 安全距离演示 | 10min | 演示+体验 |
| 应急处理流程 | 10min | 情景模拟 |
| 安全知识测试 | 10min | 笔试 |

### 教师安全培训

- 学期初：安全操作培训（2小时）
- 月度：安全检查和设备维护培训
- 赛前：赛事安全专项培训
