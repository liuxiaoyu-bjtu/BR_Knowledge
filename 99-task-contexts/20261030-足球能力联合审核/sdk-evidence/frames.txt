开发指南 BoosterOS Python SDK BoosterRobot 客户端文档 信息与状态获取接口 list_frames list_frames 接口签名： BoosterRobot . list_frames ( ) - > list [ str ] 功能： 获取当前可查询的坐标系名称。 参数： 无参数。 返回： list[str] 坐标系名称列表；未获取到坐标系数据时返回空列表。 异常： 无。 示例： from boosteros . robots . booster import BoosterRobot robot = BoosterRobot ( enable_tf_listener = True ) frames = robot . list_frames ( ) print ( frames ) # 输出示例：['head_color_optical_frame', 'head_pitch_link', 'head_point']
