SDK 概述
本文档介绍 PyPI 包 boosteros：一个面向 Booster 机器人应用开发的 Python SDK client。开发者可以通过该 SDK 连接 Booster 真实机器人或 Booster Studio 虚拟机器人，读取图像、IMU、关节、里程计等数据，并下发模式切换、速度控制、关节控制、动作、轨迹和音频播放等指令。

boosteros 的定位是机器人应用开发 SDK client 。当前已支持加速进化下的 2 款机器人，机型和运行要求见下表：

项目
当前说明

厂家
Booster（加速进化）

机型
Booster K1 / T1 / T2

运行环境
当前仅支持在 Booster 真实机器人环境或 Booster Studio 创建的虚拟机器人仿真环境中运行

Python
Python >=3.10

固件版本
Booster 机器人固件版本 >= v1.7

BoosterRobot 接口文档​

接口概览

构造与连接：创建 BoosterRobot 实例并连接机器人。

信息与状态获取：查看机器人信息、模式、步态、坐标系、关节和动作列表。

传感器与状态快照接口：读取图像、相机参数、IMU、里程计、关节、电池、跌倒状态和坐标变换。

传感器订阅接口：订阅图像、IMU、里程计、电池和跌倒状态更新。

运动控制接口：切换模式/步态，设置速度、上半身控制、关节控制、头部角度和里程计重置。

高级任务接口：管理异步任务，执行动作、起身、轨迹和音频播放。

音频管理器：设置系统音量、录音、音频流播放等。

示教管理器：录制和管理示教过程。

自动踢球管理器：启动、更新和停止自动踢球任务。

视觉与语音​

视觉与语音概览：了解 brain 可选能力的使用范围。

Speech：语音识别、对话和音色列表。

Detection：模型列表、模型加载、目标检测和结果绘制。

公共数据类型​

当你不确定某个接口返回对象包含哪些字段时，可以从这里查对应类型。

基础时间与头信息：Time、Duration、Header。

感知与状态数据：图像、检测结果、相机、IMU、里程计、坐标变换、电池、音频等。

关节相关数据：关节状态、关节状态集合和关节命令。

机器人元信息：机器人信息、关节限制、关节信息、动作信息、模式和步态名称。

任务与订阅：任务句柄、任务状态、订阅对象、音频播放流句柄等。

轨迹数据：轨迹元信息、关节轨迹点和轨迹数据。
