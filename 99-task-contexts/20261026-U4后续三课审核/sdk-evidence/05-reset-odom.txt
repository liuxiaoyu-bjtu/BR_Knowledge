reset_odom

reset_odom
接口签名：

BoosterRobot.reset_odom(x: float = 0.0, y: float = 0.0, theta: float = 0.0) -> None

功能：

将机器人里程计重置到指定位姿，默认重置到零位。

自 v1.2.0 起支持指定目标位姿参数。

参数：

参数名
类型
默认值
说明

x
float
0.0
目标位姿的 x 坐标，单位为米。

y
float
0.0
目标位姿的 y 坐标，单位为米。

theta
float
0.0
目标位姿的偏航角，单位为弧度。

返回：

None

异常：

RuntimeError: 机器人不在 walk 模式下。

示例：

from boosteros.robots.booster import BoosterRobot

robot = BoosterRobot()

robot.reset_odom()

robot.reset_odom(1.5, -2.0, 0.5)
