## 设计原则

1. **应用开发定位**：学生学的是「怎么用」而非「为什么」。所有实验围绕 SDK API 调用展开。
2. **做减法**：清华工训课中涉及算法原理的内容（单目几何、PPO 数学）一律不引入。
3. **安全第一**：每份含真机实验的教案必须包含安全提示。
4. **可操作性**：每份教案的实验任务必须能在 40 分钟内完成。
5. **参数可调**：实验设计留出参数调优空间，让学生有"调试"的工程体验。
