# 99 — 任务上下文存档

> 本目录存放各独立任务的**元信息**（上下文、提示词、状态日志、参考索引），不存放任务产出文档。产出文档按知识库规范整合到对应模块。

## 目录结构

```
99-task-contexts/
├── README.md                           ← 本文件
└── YYYYMMDD-任务名/                     ← 每个任务一个子文件夹
    ├── 00-任务上下文.md                  ← 背景、约束、已确认决策
    ├── 01-执行提示词.md                  ← 给子 Agent 的执行指令
    ├── 02-产出清单与状态日志.md           ← 已完成/待完成文档索引
    └── 03-关键参考文档索引.md             ← 告诉子 Agent 去哪里找资料
```

## 使用方式

1. **启动独立任务前**：创建 `YYYYMMDD-任务名/` 子文件夹，编写上下文+提示词
2. **任务执行中**：更新 `02-产出清单与状态日志.md`
3. **任务挂起/完成后**：状态日志标记为「挂起」或「已完成」
4. **唤醒挂起任务**：子 Agent 读取该文件夹即可接续工作

## 与其他目录的关系

| 目录 | 存放内容 |
|---|---|
| `99-task-contexts/` | 任务元信息（上下文、提示词、日志） |
| `05-internal-materials/` | 任务的**源文档和中间产物** |
| `01-booster-kb/`、`02-embodied-ai-edu/` 等 | 任务的**最终产出**（按知识库规范整合） |
