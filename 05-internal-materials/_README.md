## 🔄 资料与知识库的同步流程

```
内部资料上传 → markitdown 转换为 Markdown → 提取关键信息
    → 填充到对应知识库模块 → 标注引用来源 → 更新文档状态
```

## ⚠️ 注意事项

1. **保密性**：内部资料中的敏感信息（客户名称、报价细节等）在同步到知识库时需做脱敏处理
2. **版本管理**：同一文档的多个版本保留最新版本，历史版本归档
3. **命名规范**：严格按照上述命名规范，便于检索
4. **状态同步**：资料填充后，更新对应知识库文档的 `status` 和 `last_updated` 字段
