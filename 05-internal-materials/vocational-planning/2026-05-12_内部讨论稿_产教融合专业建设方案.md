# 建设背景

## 具身智能产业发展

当前，中国具身智能市场正迎来体系化跃升阶段，产业规模与全球影响力持续提升。2025 年，中国具身智能市场规模预计达 52\.95 亿元，占全球约 27%；人形机器人市场规模预计达 82\.39 亿元，占全球约 50%，强大的产业动能与市场规模优势，正稳固我国在全球机器人产业中的领先地位。

中国具身智能产业的快速增长，得益于多重核心动力的支撑：

1. **制造业基础雄厚**：我国制造业的全球优势为具身智能发展奠定了坚实产业土壤。2023 年，中国制造业增加值达到 32\.38 万亿元，已超过美、德、意、英制造业增加值之和，是日本制造业 GDP 总量的 5 倍以上。在传统制造向高端制造转型的战略背景下，具身智能作为底层支撑技术，正成为制造业升级的关键方向。

2. **政策导向明确**：2025 年《政府工作报告》明确提出，因地制宜发展新质生产力，建立未来产业投入增长机制，重点培育生物制造、量子科技、具身智能、6G 等未来产业，为具身智能产业发展提供了清晰的政策指引与战略支持。

3. **数据资源优势显著**：相较于海外高昂的用工成本，国内在数据采集规模化方面具备更强潜力。各地数据采集工厂的持续建设，为具身智能模型训练提供了稳定、海量的真实数据来源，数据积累已成为我国具身智能产业的核心资产与竞争优势。

4. **应用场景多元丰富**：我国庞大且多元的市场为具身智能提供了广阔的试验场。从工业制造到家庭服务，从医疗康养到教育娱乐，多样化的市场需求正加速技术迭代与产品优化，推动具身智能从实验室走向规模化落地应用。

## 产业应用背景

1. **工业制造场景：**在汽车工厂、电子制造等场景中，具身智能机器人正承担自动质检、零部件分拣与搬运等复杂任务。机器人可在生产线上灵活穿梭，完成高负载物料的快速搬运、高精度装配与质量检测，有效提升生产效率与自动化水平，成为制造业转型升级的核心支撑。

2. **医疗康养场景：**在老龄化加剧的背景下，具身智能在医疗康养领域展现出巨大潜力。外骨骼人形机器人可协助康复患者开展行走训练，通过 AI 算法分析患者状态，实时调整辅助策略并提供个性化康复方案；服务机器人则可提供服药提醒、跌倒监测、日常陪护等服务，助力提升养老与康复服务质量。

3. **家庭服务场景：**陪伴型机器人正逐步进入家庭场景，能够与儿童互动、开展趣味教学、提供生活辅助，还可通过 AI 识别家庭成员情绪，提供个性化陪伴服务，满足家庭场景中教育、陪伴与生活辅助的多元需求。

4. **零售服务场景：**在商业零售场景中，具身智能机器人可实现自主迎宾、顾客交互、商品抓取与递送等全流程服务，为顾客提供智能化、个性化的消费体验，助力零售行业提升服务效率与用户粘性。

5. **导览与展演场景：**在展会、展馆、科普教育基地等公共场景中，具身智能机器人可承担智能导览、互动讲解、特色展演等任务，通过预设程序与交互逻辑，为参观者提供定制化导览服务，完成特色动作表演与技术展示，成为品牌宣传、科普教育与场景展示的重要载体。

# 建设目标

## 人才培养

面向区域具身智能、智能装备、人形机器人、智能制造等新兴产业需求，立足职业院校技术技能人才培养定位，培养**德技并修、工学结合**的高素质技术技能人才。

通过人才培养计划制定，学生系统掌握**机器人本体装调、运动控制与编程、多模态数据工程、运维与故障排查**四大核心能力，能够胜任机器人装调、数据采集标注、设备运维、现场调试、展会导览与展演支持等岗位工作，具备工程实践能力、团队协作能力与可持续发展能力，为区域具身智能产业提供稳定、优质的一线技术技能人才支撑。

## 专业建设

对标具身智能产业技术发展与岗位能力要求，构建 **“核心课程\+实训平台\+师资队伍\+赛教融合”** 四位一体的专业建设体系。

- 建成**结构合理、层次递进、岗课赛证融通**的具身智能核心课程体系；

- 打造集**展示体验、基础实训、运动仿真、赛事训练、数据标注、装配运维、场景应用**于一体的现代化产教融合实训中心；

- 建设一支**懂技术、能教学、善实践**的专业化、双师型教师队伍；

- 形成**以赛促学、以赛促教、以赛促建**的教学创新模式，全面提升专业内涵建设水平与人才培养质量，将具身智能机器人技术专业建设成为区域内特色鲜明、优势突出、产业适配的标杆专业。

## 产业服务

立足区域产业需求，构建**自我造血、可持续运营**的具身智能产业服务体系，实现**教学效益、社会效益、经济效益**协同发展。

- 面向区域企业提供**设备装调、故障诊断、定期维保、系统升级**等技术服务；

- 面向行业与院校提供**机器人设备租赁、实训平台租售、翻新设备销售**等资源共享服务；

- 面向政府、协会、企业提供**展会导览、机器人展演、技术展示、科普交流**等场景化服务；

- 面向社会打造**具身智能研学基地与区域共享实训中心**，开展科普研学、技能培训、岗位实训与职业认证服务。

## 打造具身智能一流核心课程体系

\#（课程体系建设，后期可适配院校**课程建设、微专业建设**。）

### 校企合作打造具身智能课程体系

**1）《机器人工程》通识课程**

课程以人形机器人为核心平台，围绕“感知–决策–行动”的系统闭环展开，内容从机器人发展认知、硬件架构、开发环境配置、Python 与 API 调用、ROS2 通信机制，逐步进入图像话题订阅、人脸检测闭环、场景方案实现、足球视觉任务、头部跟随、走向足球、接近触球及成果展示，最终形成完整的项目实践与展示流程。课程总计 16 次课，每次 45–60 分钟，教学方式包含理论讲解、真机操作、小组讨论与项目展示。

**2）《具身智能机器人：控制·感知·强化学习实践》课程**

本课程以人形机器人为平台，面向具身智能时代背景，系统性讲授机器人控制系统、实时架构、ROS2 通信、步态控制（传统vs最新）、视觉感知（RGBD \+ YOLO）、强化学习动作训练、行为决策等关键技术，并通过密集的实践训练，让学生掌握机器人从 感知→控制→行为→任务的完整工程链路。

课程的最终目标是让学生完成一个真实的具身智能系统——实现机器人“自主追球 \+ 自己训练的踢球动作 \+ 自动完成踢球任务”。

学生将完成动作训练、视觉识别、控制融合、整体系统组装等全流程，获得顶级工程体验。

### 引入具身智能企业课程资源

为保障实验室的顺利落地与高效使用，Booster 人形机器人平台不仅提供硬件设备、软件平台，还配套完善的课程资源，方便教师直接使用或二次开发：

1. **课程大纲**：覆盖从基础实验到进阶项目的多层次教学方案，适配通识教学、专业实践与竞赛拓展，支持不同院系和教学场景的课程应用。

2. **课件 PPT**：与课程大纲配套的多媒体教学课件，包含图文讲解、流程示意与演示视频，便于教师课堂讲授。

3. **实验指导书**：详细说明实验目标、操作流程与注意事项，提供代码示例和结果验证方法，确保学生能够独立完成实验。

4. **SDK 与示例代码**：配套 Python/C\+\+ 接口调用示例，涵盖运动控制、视觉感知、ROS2 通信与行为逻辑，便于快速上手。

5. **教师手册**：为授课教师准备的教学建议、课堂管理提示与常见问题解答，降低课程实施难度。

6. **学生学案**：与课程进度匹配的学习任务单，用于知识点总结、实验记录与课后反思，强化学生的自主学习能力。

7. **配套软件（可选）**：Booster Studio 用于控制机器人的桌面仿真与智能训练开发平台。强调“所见即所得”的控制反馈方式，帮助学生从行为层面理解机器人系统。内置仿真开发的二次开发包、SDK等配套支撑。支持 Windows、Ubuntu 和 Mac 系统。

- **进阶培训**：面向有一定编程与科研基础的教师，重点讲解 ROS2 通信机制、行为树编排、多机协作及仿真—真机迁移方法。

- **高阶培训**：针对科研方向教师，培训内容包括端侧大模型部署、多模态交互、强化学习步态优化等前沿应用。

- **教学资源支持**：提供课程大纲、课件模板、实验手册与案例库，教师可直接应用或二次开发。

# 预期成果

## 人才培养质量区域领先，成为具身智能专业建设示范标杆

紧扣区域具身智能产业对一线技术技能人才的迫切需求，深化校企协同育人机制，构建 “岗课赛证融通” 的人才培养模式。以四大核心能力（机器人本体装调、运动控制与编程、多模态数据工程、运维与故障排查）为核心，优化人才培养方案与课程体系，确保教学内容与企业岗位需求无缝对接。通过引入企业真实项目、工程师驻校指导，学生将具备直接胜任机器人装调、数据标注、设备运维、现场展演调试等岗位的能力，有效缓解区域具身智能产业的技能人才缺口，打破企业 “用人最后一公里” 难题，岗位适应力与胜任力显著提升，形成可复制、可推广的人才培养范式。

## 专业内涵建设成效显著，建成高水平产教融合实训体系

基于具身智能产业发展需求与岗位能力分析，对传统课程进行升级改造，构建模块化、递进式的实践教学体系。通过打造集教学实训、仿真调试、数据处理、设备运维、场景展演于一体的现代化实训中心，全面支撑课程教学、技能竞赛与项目实训。同时，校企共建教学资源库、开发双元教材、打造精品课程，引入企业工程师与校内教师共同组成的双师团队，实现教学过程与生产过程的深度对接，显著提升具身智能专业的教学水平与内涵建设质量，建成区域具身智能专业建设的标杆样板。
