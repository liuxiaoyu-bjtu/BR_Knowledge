# K1足球全流程策划交付入口

建议先打开 [HTML浏览版](K1足球全流程_OSSDK策划案.html)，目录可跳转，图示可点击查看矢量原图。可编辑正文见[策划案Markdown](K1足球全流程_OSSDK策划案.md)。

| 文件 | 用途 |
| --- | --- |
| `k1_soccer.py` | 单个运行模块；状态机、选球、球位计算、OS SDK调用、退出和日志 |
| `teacher_profile.example.json` | 可选的配置文件示例，也可直接传入Calibration对象；默认不会允许运动 |
| `图示/01_主流程.*` | 标准符号绘制的寻球、接近与踢球主流程 |
| `图示/02_球位处理子流程.*` | 检测结果到当前身体米制球位的处理 |
| `图示/03_模块框架.*` | Notebook、附件、OS SDK和K1的关系 |
| `图示/04_状态转换.*` | 状态与转换条件 |

图示各含DOT源文件、SVG矢量图和PNG预览。Python模块只需单文件与已有SDK/NumPy环境；导入或直接运行不会连接机器人，调用app.start默认只观察。

2026-11-03补充：策划案第17节比较新旧策略、说明JSON可选性与SDK封装分工，保留开发者持续供数的仿真案例。k1_soccer.py为v0.1.1-draft，修正合法零坐标被拒绝的问题；仍按实际球位供数，不生成递减序列。
