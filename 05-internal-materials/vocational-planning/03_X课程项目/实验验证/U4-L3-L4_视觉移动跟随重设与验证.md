# U4-L3/L4 视觉移动跟随重设与验证

本轮按用户最新要求改写两课学生Notebook及实验代码。L3由静止来宾的两次接近对照改为移动目标视觉跟随，L4由按预设行进量接近改为视觉跟随与接待交接。两课均为P1修订稿，受影响内容待用户设计审阅和逐格真机验证；未登记确认①②或后续阶段通过。

## 1. 三课怎样承接

| 课 | 主线 | IMU、里程计的作用 | 学生需要保存的结果 |
| --- | --- | --- | --- |
| L2 | 测指定间距处的目标框高占比，达到实测阈值后停止前进 | 原有行走/速度比较用来理解位移估计与实际测量的差别 | 标定、独立核对、停止阈值与自主程序记录 |
| [L3 跟住来宾](../notebooks/U4-L3_跟住来宾.ipynb) | 目标缓慢移动；L1偏差调方向，L2框高阈值控制跟进与暂停；到近处仍继续观察，远离后可重新跟进 | 每轮另记录x/y/yaw及z轴角速度；不以预计路程或角速度差判定到位 | 跟进/暂停/再次跟进、退出原因及停稳后的位移/朝向 |
| [L4 接待来宾](../notebooks/U4-L4_接待来宾.ipynb) | 发现来宾、跟随、连续到位确认、致意前复核和一次致意 | 保留与L3同类运动记录，最后说明机器人自身怎样移动 | 函数返回、阻断、致意终态与现场表现，以及位移/朝向 |

本轮保留L2原文件全部内容，包括用户明确选择的第9格原文；没有将学生最后自主编程格替换为现成答案。阈值仍应来自L2同一目标、相近拍摄条件下的实测，不能照搬其他目标的值。1.2米看不全身体时，须先按L2调整目标或距离并重新标定。

## 2. 新稿的具体变化

- L3现为25格、10代码格。取消固定时长行走与里程计计划行进量的双运动对照，开闭环概念通过当前控制循环解释。加入静态分支、有限跟随和停稳后运动汇总。
- L4现为31格、13代码格。取消`NEAR_RATIO=0.35`与未知3米距离的绑定，取消`start_gap - target_gap`及odom x控制到位。等待阶段看到单一可用来宾即进入跟随；多目标、截断等情况拒用。
- L4通过函数返回组织步骤，连续3次满足框高与方向条件才交接；一次不满足即清零计数。3次是待本机调试的参数，不证明人体静止。
- 致意前保留现场停稳与动作空间确认，确认后重新取图。来宾远离、目标无效或方向不符时跳过致意；动作ID核对、有限等待和旧句柄检查与实际状态记录配套。
- 运动循环采用短步后零速度、再取图的方式，加入`try/finally`停止；IMU/odom的读取仍可能增加本次速度指令持续时间。阻塞接口、断网和强制结束内核不由Python结构保证可控，现场按钮处置仍需验证。
- 不再将IMU角速度差0.5当成安全或到位判定。依次读取的信息没有完成时间同步，也没有形成统一融合位置估计。

两课改动较大，旧执行结果不随新代码保留为有效输出；新格执行次数清空，输出为空。原两课及生成器保存在[本轮基线](../../../../99-task-contexts/20261029-U4视觉跟随重设/before/05-internal-materials/vocational-planning/03_X课程项目/)中，便于对照。

## 3. 位移、方向与距离的解释

每次运行在`walk`下清零里程计，保存实际起始读数，不反复清零追求恰好为零。停稳后读取终点，计算`dx、dy`及`hypot(dx,dy)`。这个值是参考平面中的起终点直线位移估计，转弯时不等于沿途路程，也不是目标移动量。

`atan2(dy,dx)`描述位移相对里程计参考x轴的方向；yaw描述机身朝向。位移过小时不解释方向角，显示条件0.05米不是传感器精度声明。L4在致意后读终点，因此其中也可能包含致意引起的位置变化。IMU采样峰值只表示记录到的角速度，可能漏掉两次读取之间的变化。

## 4. 真机验证次序

### 4.1 共同准备

记录机器人编号、软件/SDK版本、Notebook和生成器版本、目标、阈值、头部角度、站姿、光照及场地。保持与L2相同的目标和拍摄条件，固定头部。先验证静态分支，再短距离、低速、单目标运动；机器人不自动后退、不识别人身份、不避障。

`FORWARD_SPEED=0.10 m/s`、`MAX_YAW=0.20 rad/s`、`PULSE_SECONDS=0.20`、中心范围20像素、只转向范围80像素及读取上限1秒均是待真机核对的课堂初值。小速度可能无法有效迈步，不应盲目降低或增大参数。先参考L2/L1记录，逐项修改并保留结果。

| 项目 | 需要实际确认 |
| --- | --- |
| 检测框检查 | 本机`bbox.width/height/center_x/center_y`可用；无目标、多目标、非有限数、边缘截断时拒用 |
| 方向 | 目标右偏时负yaw、左偏时正yaw；头部固定，不用转头抵消偏差 |
| 阈值 | 达到框高占比后不再前进；换人、侧身或遮挡时是否破坏对应关系 |
| 数据读取 | 取图/检测耗时、get_imu/get_odom耗时，是否使短步显著超长 |
| 停止 | 正常、目标无效和可处理异常退出时能否发出零速度，机身是否实际停稳 |

### 4.2 L3逐步验证

| STEP / 代码格 | 测什么 | 应看到什么 |
| --- | --- | --- |
| 01 / 第5格 | 首次连接、person模型 | 机型/编号/模式正确，未发运动指令 |
| 02 / 第7格 | L2实测停止占比与说明 | 0～1之间的有效占比，参数及拍摄条件有记录 |
| 03、04 / 第9、11格 | 定义与静态决定 | 远且对准时跟进；偏差大时原地对准；达到阈值后vx=0；无效目标不计算运动 |
| 05 / 第13格 | IMU/odom字段 | x/y为米、yaw和角速度分别为rad与rad/s；不触发运动或诊断 |
| 06、07 / 第15、17格 | 模式与人工确认 | prepare后经人工站稳确认再walk；保持标定时头部姿态 |
| 08 / 第19格 | 先静止目标接近，再缓慢远离—停留、小幅侧移 | 输出跟进、已近、先对准；已近后不结束观察，目标远离可再次跟进 |
| 09 / 第21格 | 停稳后的终点 | 有效起终点、dx/dy、直线位移及方向、机身朝向、IMU采样记录 |
| 10 / 第23格 | 收尾与重复运行 | 先零速度再prepare；按既定人工支撑/阻尼流程扶坐，下一轮重新布置并批准 |

目标站定时先核对靠近后能停止前进；然后再增加移动。目标丢失等分支可先用静态观察验证，不为制造失败让人突然穿入行走路线。波动导致频繁启停时，记录框高与决定，再评估阈值、短步和速度；不能仅凭一轮视觉效果宣称跟随稳定。

### 4.3 L4逐步验证

| STEP / 代码格 | 测什么 | 应看到什么 |
| --- | --- | --- |
| 01、02 / 第5、7格 | 动作列表、停止占比与ID | ID及类型来自本机；`greet_task`仅首次初始化，重复测试保留原句柄 |
| 03、04 / 第9、11格 | 视觉函数与静态分支 | 与L3相同，额外打印本次是否满足到位条件；不直接致意 |
| 05、06 / 第13、15格 | 模式准备 | 分格prepare和walk，人工确认与姿态相符 |
| 07 / 第17格 | 有限等待 | 无目标继续有限等待，多目标或其他无效原因结束；不发运动指令 |
| 08 / 第19格 | 跟随函数 | 定义不运动；运行时未满足到位会清零计数，连续满足才返回“到位” |
| 09 / 第21格 | 致意交接 | 输入确认后重新取图，条件变差时不调用动作；有限等待后状态如实返回 |
| 10 / 第23格 | 完整一次接待 | 等待→跟随→到位→人工确认/新观测→致意；未到位跳过致意，不按预计里程触发 |
| 11 / 第25格 | 动作退出 | 任务仍运行时取消并再等，保留状态；未结束不开始下一轮 |
| 12 / 第27格 | 停稳终点与运动记录 | 直线位移、方向、机身朝向与实际路线相符，注明终点包含可能的致意移动 |
| 13 / 第29格 | 收尾 | 旧动作结束后才能切prepare，不能用零速度代替结束动作 |

重点安排一次来宾移动后短暂停留、一次未出现来宾、一次静态条件变化后的拒用验证。确认致意期间目标应留在指定区域；不在动作过程中人为靠近制造异常。若实际动作播完但句柄未成功，记录现场表现和最终`CANCELLED`等状态，先审定本机具体动作的交接约定，不修改成虚假成功。
