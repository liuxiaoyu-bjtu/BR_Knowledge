# U7-L1 能力选择与初步方案修订

日期：2026-10-30。按用户对U7能力链的说明修订L1。主Notebook为21格，其中13格Markdown、8格代码；原有六格代码及执行信息保留，新增两格静止取数对比代码，生成器同步。仍为P1修订稿，确认①②待完成；没有连接机器人或登记新增真机结论。

## 1. 本轮纠正的教学顺序

前稿把“三路状态观察”直接作为既定任务，第一个目标就要求学生选择订阅方式。这样省略了“从真实问题中识别需要的信息、选择机器人基本能力”的学习环节。学生即使能照抄订阅，也未必能解释相机、IMU和里程计分别为何加入方案。

按用户提出的能力链，U7应从选择能力进入，再组织这些能力并逐步实现。L1重点是任务分解、能力选择和初步技术方案；取数实验用于检验方案中的一部分。

修订后顺序是：

`读接待需求 → 拆分信息与行为 → 选择能力并说明理由 → 画技术路线、安排更新 → 实验对比取数方式 → 用记录修订方案`

课程目标相应改为：

1. 能分解一个接待任务，选择所需的感知单元和机器人基本能力，说明每项选择的用途与理由。
2. 能画出初步技术方案，说明各路信息怎样支持判断、语音与动作怎样配合，以及数据需要在什么时候更新。
3. 能通过一次读取与持续订阅的对比及多路取数实验，检查方案中的取数方式，并根据记录修改方案。

## 2. 课堂任务与选型依据

采用移动接待及运行复盘需求：发现来宾、调整朝向和跟进、在约定间距附近停下、介绍与致意，结束后查看起终点位置变化和过程转动读数。它接续U4、U5、U6已学能力，不要求L1实现整套行为。

先给问题和待填选择表，只示范“发现来宾”一行；学生完成选择后再看参考。参考把相机取图与目标检测区分，把语音与动作列为输出能力，说明里程计与IMU对本题复盘的用途。还设置缩减任务的追问：如果改为原地接待，哪些能力可以不选？没有听取提问的要求时，是否要启用麦克风或持续chat？

因此三路观测是一种有需求依据的样例，不是所有多模态任务的固定配置。IMU的z轴角速度不能代表完整姿态安全；起终点位移不是总路程或与来宾的间距；图像中心像素也不是人物检测结果。

## 3. 学习活动与实验的对应

| 环节 | 学生操作 | 记录与评价依据 |
| --- | --- | --- |
| 活动A | 分解任务，先选能力，再对照参考修订 | 每项能力对应哪条需求，限制是什么；至少说明一项不选的理由 |
| 活动B | 画初步技术路线，写判断、更新时机和不可用处理 | 信息如何支持判断，视觉、语音、动作如何交接；待验证项明确 |
| STEP 01A | 一次读取后保存时间戳/角速度，过两秒再显示，再重新读取 | 原值为何不自动更新，新调用实际取得什么；静止值相近如实记录 |
| STEP 01B | IMU持续订阅三秒，每秒显示回调次数和最近记录 | 更新来自回调，退出后保留最后值；次数不等于传感器全部采样 |
| STEP 02 | 同一轮显示图像、IMU、里程计最近记录 | 数据与方案用途对应，缺失和时间含义明确，不称同步采样 |
| STEP 03 | 查看源时间戳原值、核查依据 | 单位和基准未核实时不做跨路换算 |
| 活动C | 把实验记录写回能力选择与取数方案 | 至少一项保留/修改决定有依据，未实现部分不写成已经完成 |

一次读取、循环轮询和持续订阅分别说明，避免形成“要多次取数就只能订阅”的误解。轮询也可持续读取，需检查其他工作对循环节奏的影响。

跨路源时刻换算和慢队列实验降为选做，基础完成标准不再强制要求这两项。原队列代码保留供拓展，不挤占前置能力探究。

## 4. 课时与单元分工

45分钟可按需求理解5分钟、能力选择8分钟、初步方案7分钟、读取/订阅对比7分钟、多路取数与时间记录10分钟、方案修订5分钟、检查收尾3分钟安排。熟悉已有概念的班级可以调整；时间不足时先缩减拓展，不省略方案修订。

L1不增加足球标定、工作线程、完整模块开发或展演分工。L2继续学习足球坐标与自动踢球，L3解决检测与播报的等待，L4验证局部交接。U8仍承担完整项目的需求验收、模块接口与分工、整合、彩排复测及答辩。本轮未改其余七课Notebook或Python附件。

## 5. 审阅与验证入口

L1现在首先检查选择是否有任务依据、方案如何使用各项信息，再核查取数实验能支持何种判断。不能仅以代码无报错判断本课学习目标已达成。

新增两格代码只用既有`get_imu()`、`subscribe_imu()`和本地等待，不发运动指令。离线核查包括Notebook格式、代码语法、元数据及旧代码保留、生成器重建一致性、其他31课字节哈希，以及新增读取/订阅格的替身执行与退出检查。它不能替代SDK实机输出验证。

当前逐格测试见[U7真机测试指导](U7_逐课真机测试指导.md)。重点补看学生能否在参考出现前作出初步选择，能否解释不选的能力，以及实验后是否真正修改或确认了方案中的取数安排。方案完整性和真机验证仍由用户确认。
