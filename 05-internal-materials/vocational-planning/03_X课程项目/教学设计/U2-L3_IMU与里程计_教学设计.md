# U2-L3 教学设计（教师用）

## 一、课时目标

1. 能说明加速度计与陀螺仪各测什么，姿态估计为什么可结合两者的读数。
2. 能说明里程计的位置如何估计、长期运行为什么可能偏离实际位置。
3. 能用 `get_imu()`、`get_odom()`、`reset_odom()` 读数并连续采样，完成一次直线行走，比较指令距离、里程计读数与卷尺实测。
4. 能把目标的里程坐标换算为机器人前方、左侧的距离，并解释非零 yaw 时结果的方向和正负。

姿态观察与行走分段进行。坐标差异用假设位姿验证，不增加真机转身。

## 二、重难点

| 类型 | 内容 | 教学建议 |
| --- | --- | --- |
| 重点 | 加速度、角速度与姿态角 | 学生能区分测量含义和单位；本课分别从 imu 与 odom.rpy 读取 |
| 重点 | 姿态融合的互补作用 | 加速度可辅助判断重力方向，角速度反映转动变化；重力方向不能确定绝对航向 |
| 重点 | 里程计估计与漂移 | 说明位置由运动信息估计；清零只重设参考，不提高精度 |
| 重点 | 三个距离的含义 | 区分指令理论值、位置估计和卷尺测量；记录测量参考点 |
| 难点 | 非零航向角的换算 | 先画朝向、预测，再运行 yaw=90°、180° 的假设例子，解释负号 |
| 难点 | 单次差值不等于漂移增长 | 能指出测量误差、参考点差异等可能因素；不凭一次结果判断长期变化 |
| 难点 | 观察与行走的安全边界 | 姿态观察不进行走模式（WALK）；行走前按准备模式（PREP）、人工拉起、行走模式（WALK）的顺序确认 |

## 四、教学环节详解

### 环节 1·导入（0–3 分钟）

- 【提问】：“加速度的单位是 m/s²，角速度是 rad/s。哪一个可以直接当作身体倾斜角？”
- 【话术】：“它们都与姿态有关，但都不是姿态角本身。先读静止基准，再观察侧倾；后半段再比较机器人估计的位置与实际测量。”
- 【安全红线】：前半段不进入行走模式（WALK）、不提离支撑面；后半段只有教师确认后才行走。

### 环节 2·姿态知识与基准（3–9 分钟）

- 【投影】：§一的元件表与 RPY 表。
- 【核心概念】：加速度计在静止或缓慢运动时可辅助判断重力方向，运动加速度会干扰；陀螺仪测角速度，累加可估计角度变化，但偏差可能累积。融合利用二者互补信息，不要求学生学习算法。
- 【话术】：“手机可根据重力方向判断横屏或竖屏。不过知道哪边朝下，还不能知道面朝正北还是正东；yaw 的估计仍可能漂移。”
- 【步骤】：运行 §四连接格和静止读取格。加速度、角速度取自 get_imu；RPY 从 odom.rpy 读取，弧度用 math.degrees 换成度。
- 【注意】：IMU 结构中的 orientation、rpy 可能为空。本课读取选择不表示已经核实 K1 的内部融合算法，也不将 imu 数据一概称为未经处理的原始量。
- 【活动】：记录静止姿势、RPY、加速度和角速度。加速度合成大小通常接近 9.8，但不保证某个轴恰好为 9.8；坐姿、趴姿角度不要求接近 0。

### 环节 3·连续姿态观察（9–16 分钟）

- 【演示】：教师检查支撑面和操作空间后，示范两人配合：一人扶稳躯干，一人缓慢左侧倾、停住、扶正，再右侧倾、扶正。不提离支撑面。
- 【安全红线】：按示范范围操作，幅度不超过 20°，全程扶稳；20°是课堂操作上限，不是设备摔倒阈值。姿态或支撑不适合操作时由教师统一演示，其他组观察记录。
- 【步骤】：运行 §四 4.3 的 10 轮采样，同时配合动作，比较 roll 相对基准的变化，记录加速度分量和扶正后的结果。
- 【核心概念】：读数后 sleep(1) 使间隔略长于 1 秒；该 Python 循环用于理解定时采集，没有创建 ROS2 定时器。
- 【提问】：“两侧倾斜是否都必须让 roll 跨过 0？扶正后没回到原值，能否立即认定漂移？”
- 【FAQ】：不一定跨过 0，应比较相对基准的增减。先确认是否回到同一姿势，再考虑噪声、估计误差等因素。yaw 变化也不能凭单次观察指定原因。
- 【注意】：若本轮动作和采样没有配合上，可在教师确认后重采一次，不补造数据。

### 环节 4·位置估计与坐标（16–21 分钟）

- 【核心概念】：编码器测关节角，结合结构、接触与惯性等信息可估计身体运动；运动变化累积得到相对位置。这是一般原理，不能断言 K1 只按编码器转角折算步长。
- 【板书】：位置估计可能受偏差、打滑、接触判断等影响而漂移；误差也可能部分抵消，不保证单调增大。reset_odom 仅重设参考起点。
- 【投影】：§三两套坐标系和换算公式。odom 的方向相对起点保持固定，机器人坐标系随当前朝向转动；只平移时两者仍可对齐。
- 【步骤】：用手指或纸面箭头标出 yaw=0° 与 90° 的朝向；说明 forward 为负表示后方，left 为负表示右侧。
- 【注意】：公式可查表使用，达标要求是能代入和解释结果，不要求背诵三角公式。

### 环节 5·目标方位换算（21–29 分钟）

- 【步骤】：先切换到准备模式（PREP），人工拉起并确认直立，再进入行走模式（WALK）。场地清空、教师确认模式后运行 §五 5.1 清零，检查位姿接近 0。
- 【步骤】：运行 5.2 实际位姿的换算格，记录机器人位姿、目标坐标、forward 与 left；指出该格仅计算，不向目标运动。
- 【活动】：在纸上画机器人位于 (0,0)、目标为 (1,0)、yaw=90° 的情景，先预测，再运行假设数据格。应得到前方约 0、左侧 -1，即右侧 1 m。
- 【步骤】：学生将 demo_yaw 改为 math.radians(180)，先预测后运行，应得到前方 -1、左侧约 0，即后方 1 m；填入观察表。
- 【提问】：“为什么目标的 odom 坐标没有变，机器人看它的方向却变了？”
- 【注意】：假设变量不代表设备实测值，不追加真机转身。弧度与角度要区分，极小浮点数按近似 0 解释。

### 环节 6·行走与测量（29–36 分钟）

- 【安全红线】：确认处于行走模式（WALK）、3 米以上平整直线空间、无障碍、教师在场；运行前明确现场停止手段及分工。Notebook 中断可能跳过零速度指令，不能把中断按钮当作完成停止。
- 【步骤】：记录出发参考点，再运行 5.3 的第二次清零格和行走格：set_velocity(0.2,0,0)、等待 2 秒、set_velocity(0,0,0)。理论指令距离为 0.40 m。
- 【步骤】：停下后运行 5.4，读 x、y、yaw；按同一参考点（如躯干中心地面投影）用卷尺量沿起始 x 方向的位移，记录读数精度。不混用脚尖与脚跟，不把位移当作路径总长。
- 【活动】：填三个距离，计算“里程计 x－卷尺实测”，结合轨迹回答思考题 2。
- 【注意】：不因结果不同而重复跑到接近样例；样例 0.40、0.776、0.78 m 保留供分析，各组使用自己的读数。

### 环节 7·收尾与距离解释（36–40 分钟）

- 【步骤】：确认速度归零，运行 5.5 切回准备模式（PREP）；人工扶坐，坐稳后进入阻尼模式（DAMP）。严禁从行走模式（WALK）直接切换到阻尼模式（DAMP）。
- 【核心概念】：指令距离是设定值乘时间；odom 是位置估计；卷尺测量也有误差。样例中估计与实测约差 -0.004 m，可说本次较接近，不能据此证明长期无漂移。
- 【提问】：“指令理论值与实测差得较多，是否说明速度不能测量？”
- 【话术】：“速度可以测量。这里说明速度设定与实际运动有差异，还要检查控制响应、起停过程、地面等因素。一次实验不足以确定原因。”
- 【注意】：y 非零可来自实际偏移或估计误差，应结合轨迹判断。扩展阅读提供定位补充信息，下一课实际学习电池、摔倒状态与综合判断，不继续讲定位算法。

### 环节 8·检查与评价（40–45 分钟）

- 【活动】：检查记录和 7.1，独立完成 7.3 的 3 题；第 3 题同时核查数值、方向和负号解释。
- 【注意】：课后完成其余思考题和扩展阅读，无需为答题更换地面或追加行走。

## 五、板书设计

**读数与含义**

- get_imu：加速度 m/s²、角速度 rad/s。
- get_odom().rpy：roll、pitch、yaw，rad；分别绕前后、左右、上下轴。
- 加速度辅助判断重力方向；角速度反映转动变化；融合利用互补信息。

**坐标换算**

```
dx = tx - x; dy = ty - y
forward = dx*cos(yaw) + dy*sin(yaw)
left = -dx*sin(yaw) + dy*cos(yaw)
```

机器人 (0,0)、目标 (1,0)：yaw=90° → (0,-1)，右侧；yaw=180° → (-1,0)，后方。

**距离对照**

`指令理论值 ≠ 位置估计 ≠ 卷尺测量`；单次差值不能独立证明漂移增长。

## 六、学习评价

> 题目与实训手册 §7.3 一致。

1. 一次里程计 x 与卷尺读数之差，可以全部解释为里程计漂移。（判断）  
   **答案：×。** 还含测量与参考点等误差；单次结果不能说明随时间的变化。
2. 加速度计与陀螺仪分别测量 ______ 与 ______；本课读取姿态角使用 get_odom 返回值的 ______ 属性。  
   **答案：加速度；角速度；rpy。**
3. 机器人在 odom 的 (0,0)，yaw=90°，目标在 (1,0)。目标在机器人前方约 ______ m、左侧约 ______ m；说明方向。若 yaw 改为 180°，方向又是什么？  
   **答案：0；-1；右侧 1 m。180° 时前方 -1、左侧约 0，即后方 1 m。** 数值与方向解释均正确才达标。

课堂操作另查静止基准、侧倾变化、实际坐标换算和三个距离记录；不以某组的距离作为统一标准答案。

## 七、教学资源与附件

- K1、Jupyter、boosteros Linux 环境、同一网络、卷尺、起点标记；可用方格纸画坐标。
- 课前检查姿态数据可用、行走电量足够；平整场地留出 3 米以上直线空间。
- 课前统一卷尺参考点与读数方式，确认教师能够照看各组；无法同时操作时分批进行。

## 八、安全与设备准备

- 已完成 U1-L2、U2-L2。姿态观察不进入行走模式（WALK），坐姿或趴姿有支撑、扶稳、不离地；不适合侧倾时由教师演示。
- 行走按准备模式（PREP）、人工拉起确认、行走模式（WALK）的顺序准备。保持已验证的 0.2 m/s、2 秒，不增加转身或重复试跑。
- 若程序中断，立即按已明确的停止流程处理，确认速度归零；不能直接切换到阻尼模式（DAMP）。
- 正常收尾：零速度 → 准备模式（PREP）→ 人工扶坐 → 坐稳后阻尼模式（DAMP）。
