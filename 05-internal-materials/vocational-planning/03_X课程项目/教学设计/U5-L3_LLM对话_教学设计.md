## 一、课时目标

1. 能说明大语言模型怎样利用训练所得和当前上下文生成回答，并指出流畅的回答仍可能有事实错误。
2. 能区分模型与角色提示词：换提示词可以影响回答的身份、语气、长度和范围，不能凭空增加实时信息或工具。
3. 能按身份、语气、知识范围、不能做什么编写提示词，用同一个问题比较不同设定的表现。
4. 能启动持续语音对话，用wait()等待会话，并在中断后请求取消、检查任务是否结束。

> 教学提示：以“听到问题以后怎样组织回答”承接前两课。逐步生成只作入门解释，不展开网络结构、模型训练或检索实现。用同一句问题和相同音色、音量比较人设；同时记录语音转写误差与生成的不确定性。wait等待整个会话，学生要练习主动中断并核查结束，再切换设定，不用固定sleep猜一句话的时长。

## 二、重难点

| 类型 | 内容 | 教学建议 |
|---|---|---|
| 重点 | 训练所得、上下文和生成结果的关系 | 用接续短句解释逐步生成；用学校开放时间说明本地资料需要提供 |
| 重点 | 人设四个部分与同题对照 | 根据实际回答指出语气、长度、范围是否符合要求 |
| 难点 | 提示词改变要求，不等于更新模型或增加工具 | 区分给定资料与实时查询，拒绝用天气例子推断已有查询能力 |
| 难点 | 打断当前回答与终止持续会话 | 口头打断后再问；实验结束按中断按钮，取消并检查done |

## 四、教学环节详解

### 环节1·回答生成与知识来源（0–6min）

【活动】接续“欢迎来到实训室，请先……”，比较多种合理续写。阅读§2.1，说明模型根据前文、当前问题及训练所得逐步生成，单位token可能是字、词或词的一部分。

【活动】区分已知公开知识与本校最新开放时间。阅读§2.2奥运例子，指出主办城市早已公布与赛后结果才产生的区别；不据此推断本机服务的训练截止日。

【核心概念】流畅与事实准确是不同判断。信息不足或错误前提可能影响生成；核对人名、时间、数字要找可靠资料。本课以人工对照已给资料检查回答。

【投影】拟展示：语音转写→回答生成→语音合成的功能关系、上下文逐步增加示意、知识来源与事实核对例；依据：Notebook第2～7格；PPT定位待P5-B回填。

【提问】“在提示词写‘你知道今天开放时间’，它就有了学校的最新通知吗？说得肯定能否作为正确的依据？”

### 环节2·持续对话初体验（6–13min）

【步骤】运行STEP 01连接，核对音量。阅读STEP 02，再运行对话格，问简单问题，用“停一下”等词尝试打断当前回答，再问一次，观察会话是否继续。

【步骤】体验结束按Notebook中断按钮或Ctrl+C，观察进入KeyboardInterrupt分支，请求cancel、等待最多5秒并核对done。若未终态，保留task继续处理，不覆盖句柄。

【核心概念】chat返回TaskHandle[None]，表示整个持续会话；本课不从其result取某轮回答。wait等会话结束，答完一句后代码格仍运行是可能的正常现象。

【投影】拟展示：会话内多轮问答与口头打断、外层中断→cancel→wait→done的两层时间线；依据：Notebook第7～11格；PPT定位待P5-B回填。

【提问】“口头说‘停一下’以后还能继续问，说明结束的是哪一部分？”

【安全红线】机器人保持固定、合理音量；不让多人同时提问。异常时先中断并处理原任务，不连续创建新会话。

### 环节3·配置与人设（13–20min）

【演示】按STEP 03设置给定资料的实训室讲解员，指出ChatConfig中的volume、voice、welcome_msg、system_prompt分别改变什么。完成短问答后中断、取消并核查终态。

【活动】阅读§3.1可选参数，识别interrupt_speech_duration单位ms、interrupt_keywords、enable_face_tracking、enable_subtitle_log的用途；只解释现有字段，不为演示新增跟踪动作。

【活动】按§3.3四部分分析示例，找出身份、语气、知识范围、不能做什么。对照§3.4“过短、冲突、无范围约定”的写法，给出一处具体修改。

【核心概念】角色提示词、历史和新提问共同影响回答。换人设不重新训练模型，也不会自动取得天气、数据库等工具；要求可能不被完全遵守，仍需测试。

【投影】拟展示：配置字段及作用、人设四部分、三种写法问题与修订；依据：Notebook第12～20格；PPT定位待P5-B回填。

【提问】“要求一句话介绍五个展项，哪里可能冲突？给了资料以后，怎样判断回答有没有超出资料？”

### 环节4·固定问句、检查转写（20–25min）

【步骤】STEP 04先用同一句QUESTION练习正常发声。观察文字回调，必要时重复运行，核对语速、音量及环境影响。6秒仅是观察窗口，最近文字不保证最终整句。

【步骤】取消识别后有限等待并确认done，再进入chat；识别未终止时不能开始下一项任务。

【活动】各组抄下统一问题，确认后续各人设测试不临时换问句。若听错，记录该次输入问题，重新运行有效一组，不能直接把差异归因于人设。

【投影】拟展示：QUESTION、观察窗口内的回调更新、识别结束后再对话的顺序；依据：Notebook第21～24格；PPT定位待P5-B回填。

### 环节5·默认与三种人设对照（25–35min）

【步骤】STEP 05先记录默认表现，结束并确认终态。STEP 06每次只选一个name，保持QUESTION、音色和音量相同，分别体验解说员、迎宾员和科普老师。

【活动】各组分担指定人设，记录回答中的具体一句话或特征，再汇总三种人设。填写§5.1前四行：语气、长短、是否离题及满意度。未亲自操作的行标“课堂汇总观察”，缺失结果标待补，不能编造。

【核心概念】同题比较减少输入差异，生成仍有不确定性。出现一次符合要求的回答不等于提示词始终有效；出现偏离也不自动说明代码报错。

【投影】拟展示：三段人设、固定条件、四行空白记录及实际回答摘录；依据：Notebook第25～28格、§5.1；PPT定位待P5-B回填。

【提问】“哪一句体现了身份？哪一处超出长度或知识范围？如果重复一次表现不同，原结论要怎样写？”

【注意】每次结束靠人工中断及终态核查，不设置固定回答时长，不将字幕日志当作可供程序读取的单轮返回值。

### 环节6·编写自己的人设（35–40min）

【活动】按四部分写一段，互查是否有有效资料、冲突要求和未说明的范围。可在STEP 07示例上修改，不要求从空白编写整段会话代码。

【步骤】代表运行自写版本，仍问QUESTION；结束后核对done。记录§5.1最后一行和§5.2四部分，提出一处依据实际回答的改法。未轮到的组保留稿件，在教师安排下补做测试，不把未运行写成成功。

【投影】拟展示：四部分填写框、示例中的已知展项、实际回答与一处修改；依据：Notebook第29～31格；PPT定位待P5-B回填。

### 环节7·检查、思考与收尾（40–45min）

【活动】按§5.3四项检查点汇报：模型与设定区别、一次偏离、修改依据和会话收尾。讨论§5.4两问，不以“满意”代替事实与范围核对。

【活动】阅读§六四种处理方法的小标题，课后结合本组资料写一条核查办法；不要求实现检索或工具调用。保存提示词、回答摘录和待补操作项。

【步骤】确认原语音任务已终态，再结束实训。未终态保留句柄继续处理，不直接重跑。

【投影】拟展示：检查点、两道思考题及资料核查清单；依据：Notebook第31～32格；PPT定位待P5-B回填。

## 五、板书设计

```text
训练所得 + 当前资料/角色要求 + 对话历史 + 新问题 → 逐步生成回答
提示词：身份 / 语气 / 知识范围 / 不能做什么
固定：问题、音色、音量；改变：角色提示词
口头打断当前回答 ≠ 结束整个会话
wait等会话；中断 → cancel → wait(有限) → done → 再开
```

## 六、学习评价

对应Notebook§5.1～5.2记录、§5.3四项检查点和§5.4两道思考题。参考要点只给教师；学生课件不显示答案，P6学生PDF删除参考答案。

1. 模型与设定分别影响什么？流畅回答为什么仍需核查？

   **参考要点：** 模型训练形成能力与知识，当前提示、资料和历史影响这次生成；提示词不等于训练更新或新增工具。模型可能在资料不足或错误判断时生成事实错误。
2. 指出一次回答偏离，说明人设哪一部分含糊，怎样改？

   **参考要点：** 引用实际记录，按身份、语气、知识范围、不能做什么定位；补资料、消除冲突或约定未知信息处理，再用同题测试。无实际记录不能判为达成。
3. 打断一句与结束整个会话有何区别？怎样安全切换设定？

   **参考要点：** 口头打断后会话可能继续；wait等待整个任务。人工中断后请求cancel、有限等待并检查done，未终态不覆盖原句柄。
4. §5.4：同题回答不稳定，进入考试场景还缺什么？为什么要写“不能做什么”？

   **参考要点：** 需要明确评价依据、可核对资料、统一条件、重复检验和人工复核等，不能凭一次流畅回答评分；范围约定能减少无依据或越权回答，但不能保证绝不偏离。

## 七、常见问题FAQ

**机器人说完了，为什么代码格还在运行？**

wait等整个会话结束，单轮结束后仍可能继续接收问题。体验完按中断按钮，观察取消和终态核查输出。

**说了stop就可以直接切换人设吗？**

先看旧任务是否结束。打断关键词针对当前回答，不能代替取消整个会话。

**提示词写了“可以查天气”，为什么结果不可靠？**

文字要求不会自动提供实时资料或工具。本课用明确给定的实训室资料检查回答，不将模型语气当作查询成功的证据。
