# vocational-planning 目录说明

本目录按内容性质分为三类，便于长期维护与查找。

## 01_官方文件
既有、来自官方/既有工作的文稿（2026-05 至 2026-07），非本项目共创产物，作为背景与依据留存。
- 产教融合专业建设方案、职业院校课程体系、会议纪要、专业研讨会、标准方案、调研报告等。

## 02_共创规则与上下文
你与我协作过程中沉淀的**规则、上下文传递与审查类**文件（非直接授课内容，供开发过程参考）。
- `_高职课程设计上下文传递.md`：跨会话的关键上下文与决策索引。
- `notebook开发规则.md`：课程实验 notebook 的开发规则总文件（动态维护）。
- `课时评估-应用开发模块深度审查.md`、`课时评估-四个确认问题的答复.md`：大纲深度审查与确认答复。
