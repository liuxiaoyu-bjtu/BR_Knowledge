# 职业院校具身智能课程体系\-应用开发方向

## 一、课程整体定位

本课程面向职业院校机器人、人工智能、自动化、智能制造等相关专业，以人形机器人为教学载体，围绕“具身智能系统认知、机器人基础操作、结构理解、动作控制、应用开发与项目实践”构建课程内容。

课程采用“通识基础 \+ 应用开发”的两段式结构。通识基础部分面向所有学生，重点培养学生对人形机器人平台、机器人系统组成、仿真操作、真机连接、运动控制、动作编排、通信调试、关节结构和动作映射的基础认知。应用开发部分面向具身智能应用方向学生，重点培养学生基于视觉感知、目标判断、行为控制和任务流程完成机器人场景应用开发的能力。

本课程强调工程实践导向，避免过早进入复杂数学推导和模型训练环节，重点训练学生对机器人系统的操作、观察、调用、调试、分析和项目实现能力，使学生能够从“认识机器人、操作机器人”逐步过渡到“理解机器人系统、完成机器人应用任务”。

|课程部分|课程定位|核心任务|学习成果|
|---|---|---|---|
|第一部分：通识基础|面向全体学生的人形机器人基础课程|建立具身智能与人形机器人系统认知，掌握仿真操作、基础运动、动作调用、真机连接、通信调试、关节结构和动作映射基础|能够完成机器人基础操作、状态观察、结构识别、动作编排与动作复现|
|第二部分：应用开发|面向具身智能应用方向的项目化开发课程|围绕视觉感知、目标检测、位置判断、目标驱动控制、任务流程和场景交互开展项目实践|能够完成视觉踢球、迎宾介绍等综合应用项目|

课程整体遵循由浅入深、由单项技能到综合项目的递进逻辑：具身智能认知→ 仿真操作→ 基础运动→ 动作调用→ 真机连接→ 通信调试→ 结构与关节理解→ 动作映射与复现→ 视觉感知→ 目标判断→ 行为控制→ 场景应用项目

其中，通识基础部分为后续应用开发方向和装配维修方向共同奠定基础。应用开发方向学生能够在此基础上继续开展机器人应用项目开发；装配维修方向学生也能够通过该部分学习理解机器人结构、状态、关节、通信和动作执行之间的关系。

# 第一部分：人形机器人通识基础

## 课程目标

通识基础部分面向所有学生，目标是帮助学生建立对具身智能人形机器人的基础认知，掌握机器人仿真操作、真机连接、基础运动控制、动作库调用、运行状态观察、通信调试、关节结构理解、URDF结构模型认知和人体动作到机器人动作映射的基本方法。

完成本部分学习后，学生应能够：

|目标类型|具体目标|
|---|---|
|知识目标|理解具身智能的基本含义；认识人形机器人的组成结构；理解机器人感知、控制、执行之间的基本关系；了解 ROS2 Topic、URDF、关节映射和动作数据的基本概念|
|能力目标|能够使用仿真环境完成基础运动和动作调用；能够连接真机并观察机器人运行状态；能够查看基础通信数据和日志；能够识别主要关节结构；能够完成简单动作编排与动作复现|
|素养目标|建立机器人系统观、工程调试意识、安全操作意识和项目表达能力|

## 通识基础部分项目安排

通识基础部分采用“知识主题 \+ 小型任务 \+ 综合项目”的组织方式。前期通过仿真环境完成基础操作和动作调用，降低真机操作风险；中期通过真机连接和通信调试建立系统运行认知；后期通过关节结构、URDF 可视化和动作映射理解机器人动作形成机制，最终完成动作设计与复现项目。

## 通识综合项目：机器人动作设计与复现

### 项目目标

学生围绕一个简单动作或表演片段，完成动作拆解、关节分析、动作参数设计、仿真验证和真机演示，理解机器人动作从“动作意图”到“关节执行”的基本过程。

### 项目内容

```Plain Text
动作选择
→ 动作阶段拆分
→ 参与关节分析
→ 关节映射关系设计
→ 动作参数设置
→ 仿真验证
→ 真机演示
→ 调试记录与展示说明
```

### 可选动作主题

```Plain Text
挥手
点头
鞠躬
欢迎动作
左右摆臂
简单舞蹈片段
自我介绍动作
```

### 项目成果

|**成果类型**|**具体要求**|
|---|---|
|动作展示|完成 10–20 秒机器人动作展示|
|动作流程图|说明动作由哪些阶段组成|
|关节映射表|说明动作涉及哪些机器人关节|
|参数设计表|记录角度、速度、持续时间等参数|
|调试记录|记录仿真和真机运行中的问题及调整方法|
|项目汇报|能够说明动作设计思路、执行效果和改进方向|

## 通识基础部分教学建议

本部分教学应坚持“先观察、再操作、后分析”的原则。前期尽量通过仿真环境开展基础操作和动作验证，避免学生一开始直接面对真机安全风险；中期通过真机状态观察和通信调试帮助学生理解真实机器人系统的运行方式；后期通过关节结构、URDF 可视化和动作映射，把机器人动作与真实结构、数据模型和控制参数联系起来。

教学中应减少纯工具介绍和概念堆叠，更多采用任务化方式组织内容。例如，在学习仿真环境时完成基础移动任务，在学习动作库时完成动作组合任务，在学习通信机制时查看具体 Topic 和状态反馈，在学习关节结构时结合真机实物和动作观察，在学习 URDF 时结合 3D 模型和实物关节对照。

通识基础部分的最终评价应重点关注学生是否能够理解机器人系统的基本组成，是否能够完成基础操作与状态观察，是否能够说明动作与关节之间的关系，是否能够通过调试完成动作设计与复现项目。

# 第二部分：具身智能应用开发

## 课程目标

应用开发部分面向具身智能应用开发方向学生，在通识基础部分已完成机器人平台认知、基础运动控制、真机连接、通信调试、关节结构认知和动作设计与复现训练的基础上，进一步围绕视觉感知、目标检测、位置判断、行为控制、任务流程、动作模仿和场景应用开展项目化学习。

本部分课程强调“能力模块递进 \+ 综合项目集成”。学生先通过相机图像获取、视觉调试、目标检测结果读取、目标方位判断、目标驱动控制和状态机任务流程等小项目，逐步建立从视觉感知到机器人行为控制的基本能力；随后通过动作模仿与动作数据迁移模块，理解外部动作数据驱动机器人动作生成的基本过程；最后完成视觉踢球、动作模仿及若干场景应用项目。

完成本部分学习后，学生应能够：

|目标类型|具体目标|
|---|---|
|知识目标|理解机器人视觉输入、目标检测结果、图像坐标、目标方位判断、任务状态机、动作数据迁移等基本概念|
|能力目标|能够获取机器人相机图像，读取目标检测结果，判断目标位置，将感知结果转化为运动控制指令，设计基础任务流程，并完成具身智能综合应用项目|
|项目目标|能够完成视觉踢球、动作模仿及自选场景应用项目，形成可演示、可调试、可汇报的项目成果|
|素养目标|建立机器人应用开发中的系统集成意识、参数调试意识、任务分解能力和工程交付意识|

## 应用开发部分课程主线

应用开发部分包含两条典型具身智能任务主线：

1. 视觉踢球：机器人根据环境感知做任务

2. 动作模仿：机器人根据外部动作数据生成/迁移动作做任务

这两类任务分别代表具身智能应用开发中的两种典型方向：

|**类型**|**核心问题**|**代表项目**|
|---|---|---|
|感知驱动任务|机器人如何根据环境做动作|视觉踢球、迎宾介绍、定点介绍|
|数据驱动动作|机器人如何根据外部动作数据生成动作|BeyondMimic 动作模仿|

因此，本部分课程不只围绕单一视觉项目展开，而是同时覆盖“视觉感知驱动行为”和“动作数据驱动行为”两类能力，使学生能够理解机器人应用开发中不同类型任务的技术路径和实现方式。

## 主线 A：视觉感知驱动行为

视觉感知驱动行为的核心是让机器人根据外部环境信息做出动作响应。其基本流程为：相机输入→ 图像显示与标注→ 目标检测结果读取→ 目标方位与远近判断→ 目标驱动运动→ 状态机任务控制→ 视觉踢球 / 迎宾介绍 / 定点介绍等应用

该主线帮助学生理解机器人如何从“看到目标”逐步过渡到“根据目标位置做出行动”。视觉踢球项目是其中的典型综合项目，能够体现从感知、判断、控制到执行的完整任务闭环。原课程体系中也将视觉踢球作为“感知 → 决策 → 执行”的典型应用任务。

---

## 主线 B：动作数据驱动行为

动作数据驱动行为的核心是让机器人根据外部动作数据生成或迁移动作。其基本流程为：外部动作数据→ 动作模型或迁移工→ 机器人关节执行→ 动作效果调试→ 动作模仿展示

该主线帮助学生理解外部动作数据、动作模型、策略输出与机器人关节执行之间的关系。动作模仿项目保留原有 BeyondMimic 技术路线，同时允许根据技术发展和教学部署效率选择同类动作迁移工具。

本模块以 BeyondMimic 或同类动作迁移工具为基础，帮助学生理解外部动作数据经过处理、训练或迁移后驱动机器人执行动作的基本过程。考虑到相关技术发展较快，实际教学中可根据工具成熟度和部署效率，选用 BeyondMimic 或其他能够更快速实现动作迁移效果的第三方平台。

应用开发部分的“动作模仿与迁移”需要与通识基础部分的“机器人动作设计与复现”区分开。

|**对比项**|**通识部分：动作设计与复现**|**应用部分：动作模仿与迁移**|
|---|---|---|
|主要目标|理解动作如何拆分、编排和执行|理解外部动作数据如何迁移到机器人|
|技术路径|动作库、关节参数、动作序列|动作数据、策略模型、迁移工具|
|是否涉及训练|不涉及训练|可使用已有训练结果或第三方迁移平台|
|学习重点|关节、动作参数、动作流程|数据、模型、迁移、效果调试|
|项目成果|简单动作编排与复现|基于外部动作数据的动作模仿演示|

通识部分重在帮助学生理解机器人动作如何由关节、参数和动作序列组成；应用部分则进一步引入外部动作数据和动作迁移工具，使学生理解动作数据如何经过处理、训练或迁移后驱动机器人执行动作。

|3|4|**目标检测结果读取与筛选**|理解目标检测输出数据，包括类别、置信度、bbox 坐标等；掌握从检测结果中筛选指定目标的方法。|读取 YOLO 或检测服务输出结果；筛选足球、人等指定目标；打印目标类别、置信度和 bbox 坐标。|目标检测结果读取器；检测结果记录表|
|4|4|**目标方位与远近判断**|理解图像坐标、目标中心点、bbox 大小与目标方位、远近之间的关系，掌握基于检测结果进行左中右、远近判断的方法。|根据目标 bbox 判断目标位于左侧、中间或右侧；根据 bbox 高度、宽度或底部位置粗略判断目标远近；输出行为建议。|目标方位判断程序；目标状态分类表|
|5|4|**目标驱动运动控制**|理解如何将视觉判断结果转化为机器人运动控制指令，建立“视觉感知—行为响应”的基础闭环。|根据目标位置控制机器人左转、右转、前进、停止；目标丢失时执行停止或搜索策略。|目标驱动运动程序；运动参数调试记录|
|6|4|**状态机与任务流程控制**|理解机器人任务不是单次动作，而是由多个状态和条件切换组成；掌握 SEARCH、ALIGN、APPROACH、STOP、ACTION 等基础状态机设计方法。|设计“寻找目标—对准目标—接近目标—停止—执行动作”的任务流程；用状态机组织机器人行为。|状态机任务程序；任务流程图|
|7|4|**动作模仿与动作数据迁移**|理解外部动作数据、动作模型、策略输出与机器人关节执行之间的关系，认识 BeyondMimic 或同类工具在动作迁移中的作用。|使用已有动作数据或模型，完成动作效果验证；观察动作迁移到机器人后的执行效果；对动作幅度、节奏和稳定性进行调试。|动作模仿演示；动作数据说明；调试记录|
|8|6|**综合项目开发与展示**|综合运用视觉感知、目标判断、运动控制、状态机、动作模仿和场景交互能力，完成综合机器人应用项目。|分组完成视觉踢球、动作模仿或其他自选场景项目；进行仿真验证、真机调试、参数优化和项目展示。|综合项目演示；项目流程图；参数记录；项目汇报材料|

**建议课时合计：32课时**

## 综合项目建议表

综合项目阶段建议采用“重点项目 \+ 自选项目”的方式组织。视觉踢球和动作模仿建议作为主要项目保留，其余场景类项目可根据学校设备条件、场地环境、教师基础和学生能力进行选择。带 **★** 的项目表示学校可自选。

|**项目类型**|**项目名称**|**项目说明**|**主要能力链路**|**建议定位**|
|---|---|---|---|---|
|重点项目|**视觉踢球项目**|机器人识别足球，判断足球位置，调整方向并完成踢球任务。|图像获取 → 足球检测 → 方位判断 → 目标驱动运动 → 踢球接口 → 成功率记录|建议保留|
|重点项目|**动作模仿项目**|基于 BeyondMimic 或同类平台，将外部动作数据迁移到机器人，完成动作模仿展示。|外部动作数据 → 动作模型/迁移工具 → 关节执行 → 动作调试 → 动作展示|建议保留|
|自选项目|**★ 迎宾互动项目**|机器人检测到人靠近后，面向来人并完成欢迎动作或介绍内容。|人体检测 → 方位/远近判断 → 面向来人 → 动作反馈 → 语音/文字介绍|学校自选|
|自选项目|**★ 定点介绍项目**|机器人在固定点位完成实训室、设备、课程或展品介绍。|固定场景 → 人体检测/指令触发 → 动作展示 → 内容介绍|学校自选|
|自选项目|**★ 二维码/视觉地标触发介绍项目**|在不同点位放置二维码、AprilTag 或视觉标志，机器人识别不同标志后播放对应介绍内容。|图像获取 → 地标识别 → 内容匹配 → 动作/语音反馈|学校自选|

## 应用开发部分教学建议

应用开发部分应采用项目化教学方式组织。每个模块都应形成一个可运行、可观察、可调试的小项目，避免只讲概念或只展示最终效果。教学过程应突出“数据从哪里来、程序如何判断、机器人为什么这样动、失败时如何排查”四个问题。

视觉类模块应重点训练学生读取和理解检测结果，而不是把教学重点放在模型训练上。动作模仿模块应重点帮助学生理解动作数据、模型或迁移工具与机器人动作之间的关系，不要求学生深入掌握复杂训练算法。综合项目阶段应鼓励学生形成完整项目文档，包括任务流程图、参数记录、调试记录、演示视频和项目汇报材料。

应用部分评价应重点关注学生是否能够完成从单项功能到综合项目的集成，是否能够说明视觉感知或动作数据如何驱动机器人执行任务，是否能够记录并分析项目运行中的问题，是否能够完成可展示的项目成果。
