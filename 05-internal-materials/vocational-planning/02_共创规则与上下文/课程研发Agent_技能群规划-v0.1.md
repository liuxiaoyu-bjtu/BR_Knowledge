# 课程研发 Agent · 技能群规划 v0.1（草案）

> **定位**：把「课程研发 Agent」的能力拆成**一份共享层 + 一组按阶段划分的、自包含的技能**，作为落地清单。
> **依据**：`课程研发流程总纲-v0.1.md` §四.8（技能兜底）+ §五（生成控制逻辑）。

---

## 一、总体结构

```
共享层（1 份规则，非技能）          技能群（6 个自包含技能 + 1 可选）
  课程研发总纲 · 贯穿约束      →     ① 定位与大纲  ② 教学设计  ③ 课件详细设计
                                    ④ 考核设计    ⑤ 课程读本  ⑥ 材料审核（横切）
                                    （可选）⑦ 教学物料
```

- **为什么是"群"不是"一个"**：技能按**描述自动触发**——群 = 命中准 + 省 context + 可独立迭代；规则一次揉进大技能会触发不准、上下文膨胀、改一处动全身。
- **为什么"共享层"而不是"大技能"**：跨阶段共用的规则（定位 / 粒度 / 验收 / 贯穿约束）只存一份，落**项目文件**；各技能只**内联自己用得到的那几行**。

| 名称 | 内容 | 载体 |
|---|---|---|
| **课程研发总纲** | 五层架构、P0–P6 主脉、**生成控制逻辑（定位 / 粒度 / 验收）**、引导式协作原则、贯穿约束 | 项目文件 `课程研发流程总纲-v0.1.md`（跟 repo 走，最可移植） |

## 三、技能群清单

| # | 技能 | 对应阶段 | 职责（一句话） | 输入 → 产出 | 现状 | 优先级 |
|---|---|---|---|---|---|---|
| ① | **课程定位与大纲设计** | P0 | 引导式采需求 → 出课程大纲（多轮） | 需求模板 + 素材库 → 大纲 | 规则在 `P0_...v0.1.md`，**技能待建** | 中 |
| ② | **教学设计（教案）** | P1 | 大纲 → 分课时教案（**含内容块层**） | 大纲 → 设计版教案 | 体例 v2 就绪（需补内容块层），**技能待建** | **高** |
| ③ | **课件详细设计** | 课件阶段 | 教案 → 《课件设计蓝图》（细颗粒度） | 教案 + 物料 → 蓝图 .md | ✅ 已有 `courseware-page-design`，**待补自包含** | **最高** |
| ④ | **考核设计** | P4 | 教案 → 试卷 / 评分量规 | 教案（对齐表）→ 考核材料 | 规则待规范化，**技能待建** | 低 |
| ⑤ | **课程读本** | P5 | 教案 + 调研 → 学生读本 | 教案（读本要点）→ 读本 | 规则待规范化，**技能待建** | 低 |
| ⑥ | **材料审核（使用教师视角）** | 横切 | 以"使用教师"视角审任何阶段产物 | 任一产物 → 验收报告 | **技能待建** | **高** |
| ⑦ | （可选）**教学物料** | P2 | 教案图示规格 → 演示物料 | 教案 → SVG / 脚本 | 课型相关，**待议** | 低 |

> **数量结论：6 个技能**（5 个阶段技能 + 1 个横切审核技能），另留 1 个可选（教学物料）。

## 四、每个技能的标准结构（自包含）

```
<skill-name>/
├── SKILL.md              # 触发词(read_when) + 工作流 + "不依赖任何专家"
├── references/
│   ├── <阶段规则>.md      # 该阶段的体例 / 契约（自包含）
│   └── <原理要点>.md      # 用得到的 L1 原理（固化，不靠专家注入）
├── templates/            # 可复制模板
└── 自检清单.md            # 含"使用教师视角"验收问（见总纲 §5.3）
```

**硬约束**：每个技能必须**脱离专家、脱离其他技能**也能独立跑出及格线产物。

---

## 五、建设顺序（成熟一个建一个）

| 序 | 技能 | 理由 |
|---|---|---|
| 1 | **③ 课件详细设计** | 样板（L1 蓝图）已在手；补：自包含 + 内容块→页 + "讲清楚"基准（不设页数上限） + 使用教师验收 |
| 2 | **② 教学设计（教案）** | 体例 v2 就绪，只需**加「内容块」层**并沉淀为技能 |
| 3 | **⑥ 材料审核** | 刚定"使用教师视角"标准，趁热固化 |
| 4 | **① 定位与大纲** | P0 规格已就绪，可复制技能骨架 |
| 5 | ④ 考核 / ⑤ 读本 | **规则尚未规范化**——等规则定完再建，否则是空壳 |
