## 一、P3 干什么

```
读教案（P1）+ 物料（P2）+ 风格规范  →  一页一动作分页  →  问题链递进  →  逐页编写  →  自检  →  确认③
```

- 核心是一套**分页节奏**：一页只承载一个教学动作；超载就拆；该动脑处用"提问 → 引导 → 解答"三页递进。
- **不产出 .pptx**；本阶段产物是供教师 / 后续工具生成成品的"设计说明书"。

## 二、入口 · 输入契约（从上游读什么）

| 来源 | 读什么 | 用在 |
|---|---|---|
| **P1 教案 §一** | 大概念与基本问题 | 首屏页 + 收束页 |
| **P1 教案 §二 对齐表** | 目标 / 验证方式 / 观察信号 / 承载环节 | **每页标注"对应目标"**；问题链设计成**目标验证提问** |
| **P1 教案 §四 逐环节** | 速览表 + 每环节块（关联目标 / 观察信号 / 话术 / 学生活动 / 设计意图） | 逐页拆分 |
| **P1 教案 §五 / §六** | 演示脚本 / 图示规格 | 演示页、配图需求 |
| **P2 演示物料** | 已产 SVG / 脚本 | 配图直引 |
| **课程 `00_PPT风格规范.md`** | 配色 / 字号 / 版式 | 全页 |
| **P0 大纲** | 呈现优先级 + 概念准入 | 案例选取与术语边界 |

> **铁律——上游缺什么，回退补，不在下游硬凑**：若 P1 教案是旧体例、没有对齐表，P3 就无法标注"对应目标"，**此时停下补 P1**，不要靠猜。

## 三、规则（渲染层）

**分页 / 配色 / 配图 / 自检** 的规则正文在技能 `courseware-page-design`（`references/分页节奏规范.md` 等），本节只列需**补强**的三条（来自《课件设计评审-学习理论视角》v2）：

1. **课件 vs 教案的职责边界**：页面只承载"**要点 + 图示 + 关键词**"，讲解**沉到演讲备注**，不搬上页面正文。（治单页过载的根因）
2. **负荷判据**（替代单纯"计数"）：这条信息是知识本身必需（留）还是装饰（删）？有没有把要讲的话整段搬上屏（冗余，删）？重点是否被视觉标出（信号）？
3. **课首"旧知检索"页型**：用 1 页、1-2 个问题唤醒上一课（问什么由 P1 教案定）。

> 这三条**尚在技能外**，需补进技能 references——列为本次 P3 规范化的第一批动作。

## 四、出口 · 说明书产出规格

每课时一份 `<Ln_课名>_PPT设计说明书.md`，含三部分：

| # | 部分 | 内容 |
|---|---|---|
| 1 | 风格规范（本节要点） | 引用课程 `00_PPT风格规范.md`，只列本节配色侧重与禁忌 |
| 2 | 逐页内容设计 | 每页 = 页面标题 / 核心内容（bullet≤4） / **对应目标** / 配图需求（四要素） / 配色 / 页脚 |
| 3 | 配图 / 配表清单 | 页 / 类型 / 来源需求 / 状态 |

> **v2 新增字段「对应目标」**：把每页挂回 P1 对齐表的编号（T1/T2…）。这是 P1→P3 的**对齐锚点**——现有 8 份说明书**均缺此字段**（回抽验证的第一个预期缺口）。

## 六、自检清单（渲染层）

- [ ] 每页能否追到目标？（"对应目标"标注齐全）
- [ ] 每页 core bullet ≤ 4、主图示 ≤ 1、新增概念 ≤ 1？
- [ ] 讲解是否已**沉入备注**，而非搬上页面正文？（职责边界）
- [ ] 配图需求四要素（主体 / 关键标注 / 回答什么问题 / 来源）齐全？
- [ ] 概念 / 缩写是否符合大纲该课的准入边界？
- [ ] 文字是否过去 AI 化？配色是否按体例（不随机换色）？
