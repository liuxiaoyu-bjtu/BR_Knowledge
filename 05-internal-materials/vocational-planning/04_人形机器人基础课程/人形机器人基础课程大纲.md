## 二、学情分析与高职课程设计原则

### 2.1 学情特征与应对

| 学情特征 | 设计应对 |
|---|---|
| 抽象理论接受度有限，偏好**看得见、摸得着** | 全程以 K1 实物/视频/投屏演示支撑，少公式、少推导 |
| 学习动机依赖"**这跟我将来干什么有关**" | 每模块设产业/岗位落点，L2 专设人才缺口与职业路径 |
| 长时段纯讲授易疲劳 | **每 45 分钟拆 5–6 个环节**，讲授 ≤12 分钟连续，穿插演示/互动 |
| 计算机/代码基础薄弱，易畏难 | **完全不写代码、不提 SDK**；代码仅作教师演示物料 |
| 信息检索与归纳能力待训练 | 调研小论文锻炼资料搜集与表达 |
| 术语堆砌易迷失 | 新概念一律配"生活化类比 + 实物对照" |

### 2.2 高职课程设计原则（本版新增，贯穿全课）

1. **够用为度，直观优先**：理论只讲"够理解的量"（如双目深度只讲"两个眼睛看远近"，不讲三角测量公式）。
2. **一课一演示**：每课时至少 1 次教师演示（实物/投屏/视频），让抽象内容落地。
3. **一课一落点**：每课时明确"这对将来干什么有用"，建立"技术—产业—就业"关联。
4. **节奏分段**：45 分钟拆为 5–6 环节，讲授段控制在 8–12 分钟，避免注意力衰减。
5. **术语三级处理**：核心术语（具身智能、自由度、闭环）必讲 + 类比；扩展术语（形态计算、世界模型）点到为止；前沿细节（模型架构、算法）不进本课。
6. **过程有产出**：每课留 1 个可当堂完成的小互动/小任务（指认、口述、投票、一句话分享），让学生"当堂有参与"。

## 三、课程目标

### 3.1 知识目标
1. 概述具身智能的多源来历，区分"会说话的 AI（LLM）"与"会行动的 AI（具身智能）"。
2. 说明人形形态的工程与认知理由，了解产业规模、政策与人才缺口现状。
3. 指认 K1 的关键身体部件与核心元器件（电机/减速器/编码器/驱动器/相机/IMU/结构件/芯片/电池）。
4. 描述"感知—认知—决策—行动—再感知"闭环，理解多模态感知的作用与局限。
5. 列举 K1 的五种工作模式及其用途，掌握基本安全常识。
6. 知道人形机器人"怎么被开发出来"（工具链分工）与当前主要技术路线（点到为止）。

### 3.2 能力目标
- 能对着实物/图片指认 K1 主要部件与自由度分布。
- 能结合感知/行动演示，口述"机器人看到目标→做出动作"的基本过程。
- 能就某一元器件、岗位或应用场景完成一次资料调研与简要汇报（小论文）。

### 3.3 素养目标
- 建立"技术—产业—就业"关联认知，形成专业认同与职业方向感。
- 建立机器人安全与伦理基本意识（模式切换风险、急停常识）。

> **明确边界**：本课程**不培养编程/调试能力**（那是 X 课程目标），只建立"认知地图 + 产业视野 + 职业方向感"。

## 四、课程结构总览（8 课时 · "总—分"对称结构）

### 4.1 结构逻辑

采用 **"总—分"两段式、四大模块对称分布**：

```
【总 · 综述 2 课时】L1 具身智能前世今生 + L2 为什么是人形·产业与就业
        ↓（回答"这是什么、为什么要学"）
【分 · 三大模块 各 2 课时】
   身体 Body       L3 认识身体结构 + L4 核心元器件与产业链
   感知 Perception L5 机器人如何"看" + L6 闭环与多模态
   行动 Action     L7 工作模式与安全 + L8 行动前沿与全课收口
```

**为什么这样排**：
- **前 2 课时综述**：高职学生最需要先解决"我为什么要学这个"。先建立概念坐标与职业动机，后续模块才有接受度。
- **后 6 课时按 身体 → 感知 → 行动 三模块各 2 课时**：直接沿用师资沙龙的课程组织框架（沙龙即按此三模块组织），保证公司内外口径一致；三模块恰好构成机器人智能的完整闭环（本体载体 → 信息获取 → 行为输出），逻辑自洽。
- **每模块 2 课时对称**：第 1 课时讲"是什么/怎么工作"，第 2 课时讲"深一层/边界与前沿"，容量均衡，避免头重脚轻。
- **闭环收口在 L8**：行动之后再回看感知，呼应"再感知"，形成教学闭环。

### 4.2 课时总表

| 课时 | 模块 | 主题 | 45 分钟主线 | 核心演示 |
|---|---|---|---|---|
| **L1** | 综述 | 智能的新形态：从"会说话"到"会行动" | 具身智能前世今生 | K1 动作视频/现场 + 里程碑图谱 |
| **L2** | 综述 | 为什么是人形？产业、就业与你的位置 | 形态理由 + 产业价值 + 人才缺口 | 产业场景图集 + 岗位能力表 |
| **L3** | **身体** | 机器人的身体：以 K1 认识人形结构 | 整机参数 → 分区 → 自由度 → 关节 | K1 实物/结构图指认 + Studio 关节状态 |
| **L4** | **身体** | 拆开一个关节：核心元器件与产业链 | 关节四件套 → 感知元件 → 关键件 → 产业链 | 关节模组爆炸图/实物特写 |
| **L5** | **感知** | 机器人如何"看"：相机、深度与视觉 | 传感器全家福 → RGB/Depth → 视觉能力 | Studio 图像组件 + 检测框脚本投屏 |
| **L6** | **感知** | 从感知到理解：闭环与多模态 | 五段闭环 → 多模态融合 → 感知局限 | "只有视觉" vs "多传感器"对比演示 |
| **L7** | **行动** | 机器人如何"动"：工作模式、步态与安全 | 多模式必要性 → 五模式 → 步态平衡 → 安全 | 模式切换投屏 + 急停演示 |
| **L8** | **行动** | 行动的前沿与全课收口 | 技术路线三条 → 三大难题 → 闭环回顾 → 学习路径 | 课程链思维导图投屏 |

### 4.3 开发生态的处理方式（回应"前置 vs 分拆"）

**采用"极短前置导入 + 各模块就地演示 + 收口内嵌"三重处理，不设独立生态课时**：

| 位置 | 形式 | 时长 | 内容 |
|---|---|---|---|
| **L1 结尾** | 极短前置导入 | 5 分钟 | 一句话工具链全景（仿真→连接→控制→部署）+ "Booster Studio 像机器人的体检仪"定位预告 |
| **L3 / L5 / L7** | 各模块就地演示 | 每处 8–12 分钟 | L3 用 Studio 看关节状态；L5 用图像组件看画面；L7 用模式切换看状态 |
| **L2 / L8** | 学习路径内嵌 | 各 5–8 分钟 | L2 布置课程链地图；L8 收口时回看完整路径 |

**理由**：生态/工具链是"手段"而非"知识本体"。高职学生对抽象工具链无感，但在具体模块中"看见老师用工具把关节/画面/模式调出来"，印象最深、最不易混淆，且天然消解了"L3 突然冒出 Studio"的突兀感。

## 五、分课时详细设计（每课时 45 分钟时间轴）

> 每课时间轴均按 **45 分钟**编排，含讲授、演示、互动三类环节，讲授连续段 ≤12 分钟。

### L1 智能的新形态：从"会说话"到"会行动"（综述）

**教学目标**：建立"具身智能"概念坐标；理解它并非凭空出现，而是多源汇流的结果。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–5′ | 情境导入 | 播放 K1 动作视频/现场演示；提问："它'聪明'在哪？它和你家扫地机器人有什么不同？" | 视频/实物 + 提问 |
| 5–15′ | 核心概念 | **"会说话的 AI" vs "会行动的 AI"**：ChatGPT 类（离身/在服务器里处理符号）vs 具身智能（有身体、在物理世界实时交互）。核心：具身 = 智能必须通过身体与环境的动态互动来塑造 | 讲授 + 类比 |
| 15–27′ | 历史溯源 | **四条河流汇流**（调研①简化版）：① 哲学/现象学（梅洛-庞蒂"身体是认知的媒介"）② 控制论（维纳"反馈让机器会自我调整"）③ AI 范式迁移（符号→连接→行为主义，布鲁克斯"世界是它自己最好的模型"）④ 机器人演进（机械臂→双足→AI 驱动） | 讲授 + 图示（四条河流汇流图） |
| 27–35′ | 里程碑图谱 | 早稻田 WABOT-1（1973，世界首个全尺寸双足）→ 本田 ASIMO（2000，外形仿真巅峰）→ 波士顿动力 Atlas（2013，动态运动标杆）→ Tesla Optimus（2022，转向量产）→ 今天的 K1 | 图集投屏 |
| 35–40′ | **生态前置导入** | 极短全景：机器人是怎么被开发出来的——**仿真 → 连接 → 控制 → 部署** 四步；"Booster Studio 就像机器人的体检仪，后面每讲一个部分，我都会当场用它给你们看" | 口述 + 界面一瞥 |
| 40–45′ | 小结与思考 | 回顾"具身 ≠ 离身"；留思考题："你觉得机器人最难的是'想'还是'做'？" | 小结 + 提问 |

**演示物料**：K1 动作视频/实物、四条河流汇流图、里程碑图集、Booster Studio 界面一瞥。
**课堂互动**：开局投票"你印象里的机器人是什么样的"；结尾思考题。
**高职落点**：全程无公式；用"扫地机器人 vs K1"的熟悉对比降低认知门槛。

---

### L2 为什么是人形？产业、就业与你的位置（综述）

**教学目标**：解释人形形态合理性；用硬数据建立产业与就业认知；锚定"学这个有何用"。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–10′ | 为什么是人形 | ① **环境适配**：人类世界绝大多数门把手、楼梯、工具都是为人设计的 ② **最自然的协作**：与人共线作业无需改造产线 ③ **情感接受度**：人形更易被信任。**形态计算**点睛：形态本身就是算法（手的长度、关节位置在帮机器人"算"怎么动） | 讲授 + 场景图 |
| 10–18′ | 技术栈五层 | 大脑（高层理解规划）· 小脑（运动控制平衡）· 肢体（本体执行）· 感知（传感器）· 续航（电池）。当前竞争焦点 = 大脑大模型 + 数据飞轮 | 讲授 + 分层图 |
| 18–26′ | 产业与政策 | 2025 年中国具身智能市场约 **9150 亿元**（+20.4%），2026 预计 **10904 亿元**；连续两年写入国务院政府工作报告；2025-12 工信部标委会成立并发布《标准体系（2026 版）》；2025 全球出货约 1.3 万台、**中国占 90%** | 讲授 + 数据图 |
| 26–36′ | 人才缺口与高职定位 | 硬数据：数字经济+智能制造高技能人才缺口**突破千万**；人形机器人供需比约 **1:5**（研发岗约 1:10）；**数据采集 +769%、AI 训练师 +2250%**（增速最猛）；全国仅 **75 所高职**备案具身智能机器人技术专业。**高职黄金切口** = 调试/运维 + 数据采集/训练 + ROS 应用；运动控制/具身算法为高阶升学目标 | 讲授 + 岗位表 |
| 36–41′ | 学习路径 + 布置考核 | 课程链地图：人形机器人基础（本课）→ 数采课程 → 具身智能应用开发（X 课程）→ Agent 综合实践；**布置调研小论文**（第八节，2 周内提交，主题三选一） | 讲授 + 地图投屏 |
| 41–45′ | 分组讨论 | "你身边哪些工作可能会有人形机器人参与？"每组 1 句话分享 | 讨论 + 分享 |

**演示物料**：产业场景图集（工厂/商超/展厅）、岗位能力模型表、课程链思维导图。
**数据口径提示**：人才需求结构若引用沙龙数据（应用开发 40%/制造运维 35%/数据采集 25%），须注明为**企业宣讲口径**；对外优先使用本节第三方硬数据。
**高职落点**：本课时是学生"专业认同"的关键一课，硬数据越具体，动机越强。

### L3 机器人的身体：以 K1 认识人形结构（身体 Body）

**教学目标**：建立机器人"身体"的具象认知，能指认关键部件。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–8′ | 整机参数与分区 | K1：身高 **0.95m**、体重 **19.5kg**；四大分区：头部（含 RGB-D 双目深度相机）、躯干、双臂、双腿 | 讲授 + 实物/图 |
| 8–18′ | 自由度 | 全身 **22 个自由度**：头 2 + 单臂 4×2 + 单腿 6×2（胸腔无主动自由度）。通俗解释："自由度 = 这个部位能往几个方向转"；当场数 K1 的"能转的地方" | 讲授 + 指认 |
| 18–30′ | 关节与传动 | 单关节核心**四件套**：电机（出力）、减速器（降速增扭）、编码器（知道转了多少）、驱动器（指挥电机）；**舵机/关节模组** = 四件套的集成形态 | 讲授 + 爆炸图 |
| 30–38′ | 就地演示 | K1 实物/高清结构图投屏，逐一指认相机、各关节位置；**Booster Studio 查看关节状态组件**（实时看到各关节角度/状态） | 演示（教师操作） |
| 38–45′ | 互动 + 小结 | "找一找 K1 的'眼睛'和'关节'"随堂指认游戏；小结：身体是感知与行动的共同载体 | 互动 + 小结 |

**演示物料**：K1 实物或高清结构/爆炸图、Booster Studio 关节状态组件投屏。
**课堂互动**：指认游戏（可请 2–3 名学生上台指）。
**高职落点**：自由度用"能转几个方向"讲，不引入 DH 参数/正逆运动学。

### L4 拆开一个关节：核心元器件与产业链（身体 Body）

**教学目标**：从"整机"下沉到"元器件"，理解技术突破与产业链位置。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–10′ | 单关节深度拆解 | 回顾四件套，深一层：**力矩电机**（大力矩/高响应）、**减速器**（谐波 vs 行星，降速增扭、精度）、**编码器**（位置反馈精度）、**驱动器**（FOC 等控制） | 讲授 + 爆炸图 |
| 10–18′ | 感知元件 | **RGB-D 双目深度相机**：彩色 + 深度，"两个眼睛看远近"，让机器人知道"离多远"；**IMU 惯性测量单元**：感知自身姿态与加速度（类比人的"前庭"） | 讲授 + 实物特写 |
| 18–26′ | 其他关键件 | **结构件**（碳纤维/铝合金，轻量化与强度）、**芯片**（主控 + 边缘 AI 算力，端侧推理）、**电池**（高倍率锂电，能源密度是瓶颈之一） | 讲授 + 实物 |
| 26–34′ | 产业链与国产化 | 上游（材料/核心零部件）→ 中游（本体制造/系统集成）→ 下游（场景应用）；关键零部件（无框力矩电机、减速器、灵巧手）已实现规模化生产、部分国产替代；**三大瓶颈**：硬件成本、可靠性（MTBF）、能源密度"不可能三角" | 讲授 + 产业链图 |
| 34–40′ | 演示 | 关节模组爆炸图/实物拆解特写；不同传感器实物对比传看 | 演示 + 传看 |
| 40–45′ | 互动 + 小结 | "如果让你造一个关节，你最需要解决哪件事？"（引向电机/减速器/成本）；小结 | 讨论 + 小结 |

**演示物料**：关节模组爆炸图/实物、传感器实物特写、产业链图。
**待补充**：国内外代表性厂家清单需结合最新市场资料补全（见第十节）；呈现元器件厂商时**以技术类别与产业规律为主**，具体厂商举例遵循第六节优先级规则。
**高职落点**：这是学生未来"调试/运维/装配"岗位最直接相关的知识，讲透"每个零件贵在哪、难在哪"。

### L5 机器人如何"看"：相机、深度与视觉（感知 Perception）

**教学目标**：理解"感知"模块——机器人靠什么获取外界信息。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–8′ | 传感器全家福 | 类比人的感官：视觉（相机）= 眼、听觉（麦克风）= 耳、力觉/触觉（力传感器/电子皮肤）= 皮肤、IMU = 前庭、编码器 = 本体感觉 | 讲授 + 类比图 |
| 8–18′ | RGB 与 Depth | **RGB**（彩色，知道"是什么"）vs **Depth**（深度，知道"离多远"）；双目深度通俗原理："两只眼睛看到的画面有差别，差得越大说明越近"（不讲三角测量公式）；深度让机器人能避障、能抓握 | 讲授 + 示意图 |
| 18–26′ | 视觉能做什么 | 识别目标（这是球/这是杯子）、判断位置与距离、跟踪移动目标；强调"看到"不等于"理解" | 讲授 + 案例图 |
| 26–38′ | **核心演示** | Booster Studio 开启**图像组件**，连接实体/虚拟 K1 投屏实时画面；教师**预先粘贴检测框绘制脚本**于图层中，运行后画面中目标被框出；教师移动目标物，让学生观察"框怎么跟着动" | 演示（教师操作） |
| 38–45′ | 互动 + 小结 | 提问："机器人'看到'球了，它现在知道该干什么吗？"（引出 L6 闭环）；小结 | 提问 + 小结 |

**演示物料规范**：本环节脚本由教师作为"演示物料"预置运行，**学生只观察现象（画面中出现框），不阅读、不编写代码**；教师需明确说"这是工程师提前写好的工具，你们将来在 X 课程会自己写"。
**高职落点**：用"两只眼睛看远近"讲深度，杜绝公式；演示是本节记忆点。

### L6 从感知到理解：闭环与多模态（感知 Perception）

**教学目标**：理解感知在整体智能闭环中的位置、多模态融合价值与当前局限。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–10′ | 五段闭环 | **感知 → 认知 → 决策 → 行动 → 再感知**；以 K1 找球并走过去为例全程走一遍；强调"再感知"——做完动作要再看结果对不对 | 讲授 + 流程图 |
| 10–20′ | 多模态融合 | 单一视觉不够：暗处看不见、透明/反光物体误判、遮挡失效。**多模态融合** = 视觉 + 力觉 + 听觉 + IMU 综合判断（类比人：看 + 摸 + 听 + 平衡感一起用） | 讲授 + 案例 |
| 20–28′ | 感知的局限与难点 | 光照变化、遮挡、动态环境、仿真与真实的"现实鸿沟"；**数据是核心竞争力**——为什么产业里数据采集岗增速最猛（+769%） | 讲授 + 案例图 |
| 28–36′ | 对比演示 | 展示"只有视觉"会失败的案例（如暗光/透明物体）vs "多传感器融合"成功的对比（录像或虚拟仿真） | 演示 |
| 36–45′ | 讨论 + 小结 | 讨论："为什么机器人不能只靠一个摄像头？"；小结：感知是闭环的起点，也是当前最大瓶颈之一 | 讨论 + 小结 |

**演示物料**：感知失败/成功对比录像、虚拟仿真片段、多模态数据示意图。
**课堂互动**：小组讨论 + 代表发言。
**高职落点**：把"数据重要"落到"数据采集师是新职业、增速最猛"，与 L2 呼应，为后续数采课程铺垫动机。

### L7 机器人如何"动"：工作模式、步态与安全（行动 Action）

**教学目标**：理解"行动"模块、机器人工作状态管理与安全规范。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–8′ | 为什么需要多模式 | 不同任务需要不同"身体状态"：搬运时要省电且可推、站立时要稳、行走时要平衡、异常时要保护。类比汽车 P/R/N/D 挡 | 讲授 + 类比 |
| 8–20′ | K1 五种模式 | `DAMP` 阻尼/可推（搬运待机）· `PREP` 准备/站立 · `WALK` 行走 · `CUSTOM` 自定义 · `PROTECT` 保护。**教学常用三模式**：DAMP / PREP / WALK | 讲授 + 模式表 |
| 20–28′ | 步态与平衡 | 双足行走为什么难（支撑面小、重心高、动态平衡）；"小脑"负责运动控制策略与平衡调节；通俗讲"机器人每一步都在摔倒边缘被救回来" | 讲授 + 慢动作视频 |
| 28–36′ | **核心演示** | Booster Studio 中切换模式投屏：DAMP（软/可推）→ PREP（站立）→ WALK（行走），观察状态变化；**急停键位置**演示（软急停/硬急停概念） | 演示（教师操作） |
| 36–41′ | 安全四条 | ① WALK 前必须先 PREP ② 运动中不抬起/搬动机器人 ③ 周围无人无障碍 ④ 异常先按急停 | 讲授 + 强调 |
| 41–45′ | 互动 + 小结 | "为什么不能直接从阻尼跳到行走？"——建立**状态顺序**安全意识；小结 | 提问 + 小结 |

**演示物料**：Booster Studio 模式切换投屏、慢动作步态视频、急停键位置实物指示。
**⚠️ 待验证**：K1"多模式"是否为人形机器人**通用做法**需先验证，确认后才作为普适知识讲授；当前以 K1 为例说明（见第十节）。
**高职落点**：安全四条必须讲透——这是学生进入 X 课程真机实操前的底线。

### L8 行动的前沿与全课收口（行动 Action）

**教学目标**：了解行动/具身智能的研究前沿（点到为止）；收口全课闭环；明确学习路径。

| 时间 | 环节 | 内容要点 | 形式 |
|---|---|---|---|
| 0–12′ | 研究前沿三条路线 | **① 分层"大脑+小脑"**（当前最易落地：大脑理解规划、小脑运动控制）**② 端到端 VLA**（视-语-动单一模型，长远方向，短程任务见长）**③ 世界模型**（行动前预测未来状态，最前沿、仍早期）。**融合趋势**：世界模型正成为 VLA 的预测内核；类脑架构探索 | 讲授 + 路线图 |
| 12–20′ | 三大难题 | 行业共识："**大脑不够聪明**（泛化不足）、**小脑不够协调**（运动控制）、**身体不够强壮**（成本/可靠性/能源密度）"；产业正从"炫技"走向"真能干活" | 讲授 + 案例 |
| 20–28′ | 全课闭环回顾 | 用一张图串起：身体（载体）→ 感知（输入）→ 行动（输出）→ 再感知（闭环）；呼应 L1 的"具身 vs 离身" | 讲授 + 闭环图 |
| 28–36′ | 学习路径与课程链 | 完整链路投屏：人形机器人基础（本课）→ 数采课程（具身智能基础）→ 具身智能应用开发（X 课程，真写代码）→ 人形机器人 Agent 综合实践；标注各阶段对应岗位 | 讲授 + 地图投屏 |
| 36–42′ | 小论文答疑 | 调研小论文**要点提示与答疑**（选题、资料来源、结构、字数）；重申 2 周内提交。**不占课时讲作业**，仅答疑 | 答疑 |
| 42–45′ | 收尾 | 每人用 1 句话说明"这门课我最大的收获" | 分享 |

**演示物料**：三条技术路线对比图、全课闭环图、课程链思维导图。
**呈现优先级**：本课时涉及研究前沿代表，严格遵循**第六节**规则。
**高职落点**：前沿只给"地图感"，明确"今天讲的路线两年后可能就变了，课程目标是让你会看技术地图，而不是背模型名字"。

## 六、研究前沿代表的呈现优先级（公司课程规范 · 新增）

作为加速进化的课程，在向学生**呈现研究前沿/里程碑代表**时，按以下优先级选取案例：

| 优先级 | 类别 | 用途 | 示例 |
|---|---|---|---|
| **1（首选）** | **高校 / 研究机构** | 学术里程碑、理论与前沿成果 | MIT（布鲁克斯包容架构）、早稻田大学（WABOT-1/加藤一郎）、斯坦福（Shakey）、CMU、北京大学、北京通用人工智能研究院（通研院）、智源研究院、中科院自动化所 |
| **2（其次）** | **国外公司** | 工程化与产品化标杆 | Boston Dynamics（Atlas）、Tesla（Optimus）、Google DeepMind（RT-2 / Gemini Robotics）、Figure（Helix）、Physical Intelligence（π0）、Skild AI、Meta（V-JEPA2） |
| **3（国内公司）** | **以加速进化自身为主** | 国内落地案例、实操载体 | **加速进化 Booster K1**（本课程唯一实操载体与主要国内案例） |

**执行要点**：
- 国内其他公司（如智元、宇树等）**仅在陈述产业客观事实**（如出货量、量产进度、产业格局）时作为背景提及，**不用于"研究前沿代表"的案例展示**。
- 本课程"国内案例"的主角始终是 **Booster K1**，以此强化公司技术身份与学生实操载体的统一。
- **调研文档（调研①②③）保持通用性与客观性，不受此规则影响**——它们是内部知识底板，非学生面呈现物。

## 七、授课与演示物料规范

1. **课堂零代码**：学生课上不操作电脑、不写/读代码；任何代码均由教师作为"演示物料"预置在 Booster Studio 中运行并投屏。
2. **演示物料清单（教师侧）**：
   - K1 实物或高清结构/爆炸图（L1/L3/L4）
   - 四条河流汇流图、里程碑图集（L1）
   - 产业场景图集、岗位能力表、课程链地图（L2/L8）
   - Booster Studio 关节状态组件（L3）
   - 关节模组爆炸图 / 传感器实物（L4）
   - Booster Studio 图像组件 + **检测框绘制脚本**（L5）
   - 感知失败/成功对比录像（L6）
   - 模式切换演示 + 急停键指示（L7）
   - 三条技术路线对比图（L8）
3. **软硬件要求**：阶梯教室投影 + 可联网演示的 Booster Studio 环境 + 1 台 K1（或虚拟仿真）供教师投屏。
4. **每课必备**：至少 1 次教师演示 + 至少 1 次学生当堂参与（指认/口述/投票/分享）。

## 八、课程考核方式

- **形式**：调研类小论文（或等价课程考察），**不采用纯笔试**。
- **布置时机**：**L2 布置**（第 2 课时即下达，学生有 2 周准备期），L8 仅答疑，不占课时。
- **主题方向（任选其一）**：
  1. 调研某一元器件（电机/减速器/深度相机/边缘 AI 芯片等）的技术现状与 1–2 家国内外代表厂商。
  2. 调研一个具身智能相关岗位（调试运维/数据采集/ROS 应用开发）的职责与能力要求。
  3. 调研人形机器人在某一场景（工厂/商超/展厅/家庭）的落地案例与价值。
- **字数**：800–1500 字（高职适配，重资料搜集与条理，轻学术深度）。
- **评分维度**：资料真实性（30%）· 结构清晰（30%）· 与课程概念关联（25%）· 表达（15%）。
- **目的**：呼应学情——以轻量调研锻炼信息检索与归纳，同时强化"技术—产业"关联认知。

## 九、与知识库 / 沙龙 / 调研的关系

- **课程链定位**：依据课程依赖图，本课程为专业核心课链最前端的 8 课时专业基础课；其后为**数采课程 → 具身智能应用开发（=X 课程）→ 人形机器人 Agent 综合实践**。
- **三大模块来源**：身体 / 感知 / 行动 框架取自师资培训沙龙-2026-09《内容摘要.md》。
- **参数与安全口径**：K1 参数（0.95m/19.5kg/22 自由度）、五模式、安全四条均引自该沙龙摘要（权威对外宣讲口径）。
- **调研回流**：调研①（多源发展史、年表）→ L1；调研③（市场/人才/专业规划硬数据）→ L2、L6；调研②（三条技术路线、融合趋势）→ L8。
- **与 X 课程边界**：X 课程（8 单元 × 4 课时）进入 BoosterOS SDK 实操；本课程不触及 SDK 与编程，二者"认知—实操"递进。
