## 二、上午：行业技术 + K1 硬件 + 实操

### 2.1 具身智能与行业（Part 01）
- 具身智能定义："会行动的 AI"（对比 LLM 是"会说话的 AI"）；三要素：有身体 / 能感知 / 会行动
- 大脑-小脑双系统架构：VLA 慢脑（规划推理）+ 快脑（高频控制、平衡、抓握）；感知→认知→执行→再感知的反馈循环
- 人形形态理由：人类世界 99% 为"人"而设计（环境适配 / 最自然协作 / 情感接受）
- 技术栈 5 层：大脑/慢脑 · 小脑/快脑 · 肢体 · 感知 · 续航；**竞争焦点 = 慢脑大模型 + 数据飞轮**
- 未来 5-10 年路径：2026 工厂 → 2027-28 商业服务/仓储 → 2029-30 家庭 C 端

### 2.2 K1 硬件架构（Part 02）
- **K1 关键参数**：身高 0.95m、体重 19.5kg、全身 **22 自由度**（头 2 + 单臂 4×2 + 单腿 6×2，胸腔无主动自由度）
- 头部：RGB-D 双目深度相机（彩色 + 深度两类输出）
- 关节模组拆解：电机（主流类型对比）+ Reducer（减速器）+ Encoder（编码器）+ Driver（驱动器）
- 单关节核心部件：电机 / 减速器 / 编码器 / 驱动器
- 视觉传感器能力对比（主流传感器）

### 2.3 K1 真机实操（Part 03）
- **五种工作模式**（PDF p40 起）：`DAMP`(阻尼/可推) · `PREP`(准备/站立) · `WALK`(行走) · `CUSTOM`(自定义) · `PROTECT`(保护)
- 教学常用三模式：**DAMP（搬运/待机）· PREP（站立预备）· WALK（任务执行）**
- **操作安全四条要点**（与知识库 `notebook开发规则.md` 一致，权威佐证）：
  1. WALK 前必须先 PREP（直接 DAMP→WALK 会摔倒）
  2. 运动中不抬起机器人（步态控制器失稳）
  3. 周围无人无障碍
  4. 搬运只接触提手
- 软急停与硬急停：异常时第一动作是按急停键，不徒手扶
- 开机流程：首次连接需蓝牙完成网络配置 → App 连接 → 关机流程

## 三、下午：软件系统 + 仿真 + 人才

### 3.1 K1 软件系统与开发环境（Part 04）
- K1 = "带行动能力的 Linux 电脑"；控制本质是两台电脑网络通信
- 关键概念：Node（节点）/ Topic（话题，异步广播）/ Service（服务，请求-应答）；课程仅需了解 ROS2 在软件栈中的位置
- Booster SDK/API：代码通过接口"告诉机器人该做什么"，不直接驱动电机
- 本地工具部署：四步；连接成功三步检查；SSH 登录后命令在 K1 上执行

### 3.2 Booster Studio 仿真（Part 05）
- "你早就用过仿真了"；仿真跨越真机调试四障碍
- 实践：创建虚拟机器人 → 用 BoosterOS 发指令 → 让机器人移动（Robot 的 Hello World：初始化 SDK → 进入行走 → 挥手 → 复位）

### 3.3 行业与人才需求（Part 06）
- 市场规模：1540 亿美元（2035），复合增长 94%（2025-2035）
- **人才需求结构**（课程定位关键依据）：
  - 应用开发方向 **40%**（仿真开发/训练师/系统集成）
  - 制造运维方向 **35%**（安装/装调/运维工程师）
  - 数据采集方向 **25%**（数据采集/质检工程师）
- 人才分层：研发型（研究型高校）→ 应用型（应用型本科/高职，应用开发/运动控制/运维）
- **能力模型**：应用开发方向 = 技术支持/应用开发/系统集成；装配维修方向 = 装调/运维维修/整机测试

### 3.4 人才培养体系（课程设计核心参考）
- **产教融合专业建设方案**：应用开发方向 + 装调运维方向
- **加速进化课程体系**：
  - **人形机器人基础课程**（K1 载体，零基础友好，4 单元）：U01 历史发展 / U02 基础认知结构 / U03 基础操作安全 / U04 动作控制入门
  - **具身智能应用开发课程**（8 单元，与知识库 X 课程高度对应）：
    - PART 1 基础感知与控制：U01 初探与运动控制 / U02 感知系统与 ROS2 通信 / U03 机器视觉与目标识别 / U04 综合实践·接待员机器人
    - PART 2 交互与集成：U05 语音交互 / U06 动作示教模仿 / U07 多模态联动 / U08 综合实践·剧场设计与展演
    - 两大综合实践主题：视觉踢球 + 智能导览
  - **装调运维综合实训课程**：组装与整机测试（T1，6 模块 SOP）/ 故障检测与维修（6 模块）
- **权威赛事体系**：以机器人足球为核心牵引，覆盖国际/国家级/高校/青少年赛事
- **实训基地**：运动控制与仿真实训室、运维调试训练区等
- **企业级教学资源**：拆解/维修作业指导书、组装调试 SOP 改编为课程资源
