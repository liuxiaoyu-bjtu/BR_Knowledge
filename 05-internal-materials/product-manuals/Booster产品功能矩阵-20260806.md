## 一、Booster Studio（核心开发平台）

### 1.1 产品定位
Booster Studio 是面向开发者的核心集成开发环境（IDE），支持机器人真机连接、虚拟机器人仿真、代码开发、Agent 部署等全流程开发能力。

### 1.2 已有功能（已上线）

#### 🔌 机器人连接与管理
- **多类型机器人连接**
  - Booster 真机机器人（K1、T1）
  - 自定义机器人
  - 虚拟机器人（Docker 容器）
- **局域网扫描连接**：自动扫描局域网中的机器人
- **SSH 远程连接**：支持 Remote-SSH 连接机器人本体
- **多板连接支持**：支持连接机器人多个计算板（运动板、感知板等）

#### 💻 开发环境
- **Notebook 组件**：Jupyter Notebook 风格的交互式代码编辑
- **代码编辑器**：完整的代码编辑、运行、调试环境
- **ROS 配置管理**：ROS configurations 管理
- **文件系统访问**：远程访问机器人文件系统
- **终端集成**：内置终端，支持命令行操作

#### 🎮 仿真能力
- **虚拟机器人创建**：基于 Docker 创建虚拟机器人
- **3D 仿真环境**：实时 3D 仿真画面
- **3V3 足球仿真赛**：3v3 机器人足球对战仿真
  - 支持多机器人协同
  - 足球比赛规则
  - 对战功能
- **仿真跟随视角**：跟随机器人视角的仿真画面

#### 🚀 Agent 开发与部署
- **Agent 框架支持**：Booster Agent Framework
- **真机部署流程**：一键将 Agent 部署到真机机器人
- **Agent 模板**：预置多种 Agent 模板（足球大师、舞林高手等）
- **Hello World 示例**：入门级 Agent 开发示例

#### 🤖 硬件支持
- **K1 机器人**：完整支持
- **T1 机器人**：完整支持
- **传感器数据读取**：图像、IMU、里程计、关节数据等
- **运动控制**：速度控制、关节控制、模式切换

#### 🌐 云桌面（本周内上线）
- **云端高性能电脑**：用加速豆租用云端性能更好的电脑
- **预装 Linux 系统**：开箱即用的开发环境
- **配置可选**：多种硬件配置可选
- **按使用量计费**：消耗加速豆

### 1.3 在研功能（开发中 / 本月上线）

#### 🔴 P0 - 本月上线（8月）
- **云端仿真**
  - 云端运行虚拟机器人
  - 低配置电脑也能流畅使用仿真
  - 降低硬件门槛
- **T2 支持**
  - 支持连接 T2 机器人
  - 支持创建 T2 虚拟机器人
  - T2 Remote-SSH、部署 Agent 兼容
- **仿真支持添加物体、场景**
  - 仿真环境中添加各种物体
  - 支持自定义场景
  - 覆盖更多教学场景
- **根据 Agent 日志自动改代码的 MCP**
  - AI 辅助调试
  - 根据运行日志自动修改代码
  - 提升开发效率
- **仿真性能记录打点**
  - 性能监控
  - 调试优化工具
- **T2 仿真**：T2 机器人的仿真支持

#### 🟡 P1 - 本月完成设计（8月）
- **支持自然语言生成物体、场景**
  - 用自然语言描述创建仿真场景
  - 降低场景创建门槛
  - AI 驱动的场景生成
- **Control Panel、仿真整体框架逻辑优化**

  - 性能提升
- **小优化集合**

  - 仿真跟随机器人视角放到仿真菜单

### 1.4 未来规划（设计中 / 预研）

  - 动作迁移技术
- **仿真语音能力**（技术调研中）
  - 仿真中支持麦克风、扬声器

- **真实场景建模**（调研中）

## 三、HiChat（语音对话 Agent）

### 3.1 产品定位
HiChat 是基于大语言模型的语音对话 Agent，让机器人具备自然语言交互能力，支持人设定制、多轮对话等功能。

### 3.2 已有功能（已上线）

#### 🗣️ 基础对话能力
- **语音交互**
  - 语音识别（ASR）
  - 语音合成（TTS）
  - 自然语言理解
- **多轮对话**
  - 上下文理解
  - 连续对话
  - 对话记忆
- **灯语反馈**
  - 蓝色闪烁：正在听（麦克风收音）
  - 黄色闪烁：正在思考（AI 处理）
  - 白色闪烁：正在说话（扬声器播放）
  - 红色持续：无网络状态

#### 🎭 人设系统
- **默认人设**
  - 预置对话风格
  - 基础问答能力
- **自定义人设**
  - 可配置角色设定
  - 个性化对话风格
  - 3 分钟创建专属 AI 角色

#### 🔊 音量控制
- **语音调节**
  - "大一点" / "小一点" 模糊调节
  - "调整到 50%" 精确调节
  - 语音指令控制

### 3.3 在研功能（v1.2 性能优化）

#### 对话体验优化
- **断句体验优化**
  - 等语义完整后再回复
  - 支持带停顿的长句
  - 多轮对话纠错
- **打断功能**
  - 默认人设支持打断
  - 自定义人设可配置打断
  - 解决自问自答问题
- **对话延时降低**：约 10% 性能提升
- **应用切换速度提升**：已上线

#### 网络优化
- **网络状态提示**
  - 网络差时主动播报 "网络不稳定，请稍后再试"
  - 3 分钟触发一次，避免频繁打扰
  - 无网络时红色灯语提示

### 3.4 未来规划
- **更多人设模板**
- **技能调用**：对话中调用机器人技能
- **视觉对话**：结合视觉能力的对话
- **多语言支持**

## 五、技能库 / 动作资源库

### 5.1 产品定位
技能库是独立于 Agent 的动作资源管理系统，实现动作的复用、共享、跨设备同步，构建动作资源生态。

### 5.2 核心概念
- **技能（Skill）**：可复用的机器人动作资源
- **专属技能**：只能在当前 Agent 中使用的技能
- **通用技能**：可以在多个 Agent 中复用的技能
- **机器人技能库**：存储在机器人本地的技能
- **云端技能库**：绑定账号的云端技能，跨设备同步

### 5.3 已有功能
- **Agent 动作面板**：Agent 内的动作管理
- **预置动作**：官方预装的动作库
- **自定义动作**：用户创建的动作

### 5.4 在研功能（8月 P0）
- **App 技能库**
  - 「机器人设置」中增加「技能库」入口
  - 两个 Tab：当前机器人 / 我的云端
  - 官方 / 自定义分组
  - 技能创建、编辑、删除
  - 复制到云端 / 从云端同步
  - 从技能库添加到 Agent
- **云端动作库**（开发中）

### 5.5 未来规划
- **Studio 支持技能库 & 技能社区**
- **Studio 支持作品编辑器**
- **技能社区**（P2）
  - UGC 技能分享
  - 点赞、评论、收藏
  - 创作者激励
- **动作与作品分离**（P1）
  - 动作：基础动作单元
  - 作品：组合动作 + 场景 + 逻辑的完整作品
  - 作品编辑器

## 十二、对课程设计的影响分析

### 12.1 近期可落地（8月后）

#### 云端仿真课程
- **基础**：云端仿真 + 云桌面
- **价值**：零配置入门，学生无需安装任何软件
- **适用**：K12 入门课、高职通识课、师资培训

#### 动作创作课
- **基础**：Motion Creator + 技能库
- **价值**：降低动作开发门槛，创意表达
- **适用**：K12 创意课、高职动捕课、社团活动

#### T2 配套课程
- **基础**：T2 全平台支持
- **价值**：新硬件平台的课程体系
- **适用**：高校实验室、高职专业建设

#### 场景化项目课
- **基础**：仿真添加物体 + 场景
- **价值**：丰富的任务场景，项目式学习
- **适用**：L3-L4 课程、综合项目课

### 12.2 中期可规划（Q4）

#### 可视化编程课程
- **基础**：应用中心 + 可视化编程
- **价值**：零基础入门，图形化编程
- **适用**：K12 低龄段、科普课、研学

#### 项目式学习体系
- **基础**：资源库 + 作品编辑器 + 技能社区
- **价值**：学习→创作→分享完整闭环
- **适用**：全学段课程体系

#### AI 辅助学习
- **基础**：AI 助手 + MCP + 文档中心 AI 问答
- **价值**：个性化学习路径，智能助教
- **适用**：自学课程、翻转课堂

### 12.3 长期生态布局

#### UGC 课程生态
- **基础**：技能社区 + 作品分享
- **价值**：用户贡献内容，生态自循环
- **适用**：社区运营、赛事活动

#### 数字孪生教学
- **基础**：真实场景建模 + 仿真语音
- **价值**：虚实结合的沉浸式教学
- **适用**：高校研究、高端培训
