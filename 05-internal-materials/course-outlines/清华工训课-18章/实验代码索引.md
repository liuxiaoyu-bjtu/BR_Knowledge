## 二、各章节实验概览

### Chapter 03｜机器人控制基础与 SDK

| 文件 | 类型 | 说明 |
|---|---|---|
| `hello_robot.py` | 脚本 | SDK 控制 K1 进入准备模式、行走模式，向前小幅移动后停止 |

**实验要点**: 基础 SDK 连接与运动控制，Hello Robot 入门。运行前确认机器人已完成开机初始化。

### Chapter 04｜ROS2 通信与控制接口

| 文件 | 类型 | 说明 |
|---|---|---|
| `topic_status_publisher.py` | 发布者 | 发布 `/k1_demo/status` 字符串状态话题 |
| `topic_status_subscriber.py` | 订阅者 | 订阅并打印状态话题 |
| `image_topic_inspector.py` | 订阅者 | 订阅头部 RGB 图像话题并打印元信息 |
| `k1_rpc_client.py` | 工具 | 封装 `/booster_rpc_service` 请求的公共工具 |
| `ros2_motion_request.py` | 脚本 | 通过 ROS2 服务控制 K1 准备、行走、前进、停止 |
| `ros2_upper_body_action.py` | 脚本 | 通过 ROS2 服务触发半身动作并停止 |
| `ros2_whole_body_dance.py` | 脚本 | 通过 ROS2 服务触发全身舞蹈 |
| `command_publisher.py` | 发布者 | 向 `/k1_demo/control_command` 发布控制命令 |
| `command_service_bridge.py` | 桥接 | 订阅控制命令 Topic 并转换为 K1 服务请求 |

**实验要点**: ROS2 话题发布/订阅、服务调用、图像话题检查。`command_service_bridge.py` 的全身舞蹈需显式 `--allow-whole-body-dance` 参数。

### Chapter 05｜示教与动作生成（上半身动作）

| 文件 | 类型 | 说明 |
|---|---|---|
| `teach.py` | 脚本 | 使用 SDK 示教接口完成上半身动作录制与回放 |

**实验要点**: 零力矩拖拽（`zt`）→ 录制（`rec`）→ 结束（`f`）→ 回放（`replay`）四步流程。进入零力矩前需扶稳机器人或放在支架上。

### Chapter 12｜空间理解与感知到控制

| 文件 | 类型 | 说明 |
|---|---|---|

|---|---|---|

### Chapter 15｜行为树：把复杂行为拆成可组合动作

| 文件 | 类型 | 说明 |
|---|---|---|
| `behavior_tree_core.py` | 内核 | 极简 BT 内核（Status、Leaf、Sequence、Selector） |
| `simple_behavior_tree_demo.py` | 演示 | 不依赖 ROS2/SDK 的最小 BT 演示 |
| `football_bt_utils.py` | 工具库 | 黑板数据、坐标读取、追球速度计算、K1 控制接口 |
| `football_bt_nodes.py` | 节点 | BT 叶子节点：BallAvailable、ArrivedAtBall、ChaseBall、HoldPosition、SearchBall |
| `bt_football_chase_node.py` | 主节点 | BT 版追球决策 |

**BT 树结构**:
```
Selector: FootballDecision
├── Sequence: HoldWhenArrived → BallAvailable + ArrivedAtBall + HoldPosition
├── Sequence: ChaseWhenVisible → BallAvailable + ChaseBall
└── SearchBall
```

**实验要点**: 先运行 `simple_behavior_tree_demo.py` 理解 BT 原理，再真机运行。BT 优先级：到位保持 > 追球 > 搜索。

### Chapter 16｜VisualKick 与视觉踢球策略控制

| 文件 | 类型 | 说明 |
|---|---|---|
| `soccer_ball_detector.py` | 节点 | 足球检测 |
| `ball_position_depth_node.py` | 节点 | 深度增强定位 |
| `behavior_tree_core.py` | 内核 | BT 内核 |
| `visual_kick_utils.py` | 工具库 | 坐标读取、追球速度、`/kick_ball` 发布、SDK 和 VisualKick 封装 |
| `visual_kick_bt_nodes.py` | 节点 | BT 叶子节点：搜索、追球、踢前对齐、VisualKick、停止 |
| `visual_kick_strategy_node.py` | 主节点 | 搜索/追球 → 对齐 → VisualKick 单次踢球 → 停止 |

**流程**: `搜索/追球 → 踢前对齐 → VisualKick 单次踢球 → 停止`

**关键参数**: `kick_version`（kV1/kV2）、`power`（<5 传球 / >5 射门）、`kick_dir`（方向）、对齐容差（yaw_tol=0.12、y_tol=0.08）。
