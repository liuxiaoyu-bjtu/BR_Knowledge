# 加速进化·少年机器人创作社

**每周末两小时，和伙伴一起，把想法做成会说、会动、能与人互动的机器人作品。**

面向初中阶段学生，欢迎零基础及有编程、机器人学习经历的孩子参加。在加速进化的真实机器人与开发环境中，学生从体验K1开始，选择自己感兴趣的主题，完成一项可以运行、展示并继续修改的作品。

喜欢舞蹈与故事，可以创作机器人剧场；喜欢足球与游戏，可以设计比赛规则和机器人行为；关心文化与生活，可以为机器人设计讲解内容与互动方式。课程以作品为主线，将科技理解、艺术表达、人文思考与合作实践放在同一个创作过程中。

## 孩子来这里做什么

机器人如何看见一颗球、听见一句话，又怎样决定接下来做什么？一段舞蹈怎样表达人物的情绪？机器人面对小朋友和长辈，应该使用怎样的语言与动作？

学生带着这些具体问题，观察机器人的表现，提出自己的设计，再用K1尝试。老师提供经过准备的工具、示例与能力模块，帮助学生逐步完成从想法到作品的过程。

**学习方式：共同体验与基础学习 → 主题探索与选题 → 小组创作与改进 → 作品展示与交流。**

| 学习阶段 | 学生的主要经历 | 留下的成果 |
|---|---|---|
| 认识机器人与AI | 体验K1的视听、动作与交互，观察它在哪些情况下会误判；认识AI与人分别负责什么 | 观察记录、体验中的发现 |
| 找到值得创作的主题 | 了解使用者或观众，讨论内容与规则，选择主题，画出作品草图 | 作品构想、故事或任务流程 |
| 让作品运行并改进 | 使用现有能力模块、AI辅助和适量编程组织行为；小组分工，测试、调整并再次尝试 | 可运行版本、修改前后的记录 |
| 把作品交给观众 | 邀请同伴试用，完成现场展示，介绍设计选择及自己的贡献 | 完整作品、演示记录、个人创作说明 |

每个项目周期围绕一项主要作品推进，阶段长短随主题与学生情况调整。后续项目可更换主题，也可在原作品上增加新的互动与表达。

## 从兴趣出发，选择创作方向

下列方向提供选题参考，开班时根据学生兴趣与现场条件选择其中的主题开展。

| 创作方向 | 可以尝试的作品 | 创作中要作出的选择 |
|---|---|---|
| **舞台与艺术** | 机器人微剧场、人与机器人的舞蹈片段、带动作与配音的故事表演 | 用什么动作表达情绪；音乐、语言与动作如何安排；观众能否理解故事 |
| **运动与游戏** | 仿真足球策略作品、K1足球挑战、由学生设计规则的互动游戏 | 规则是否公平；机器人在不同情境下怎样行动；怎样根据测试改进表现 |
| **文化与叙事** | 城市故事讲述员、节日主题互动角色、小型展览讲解应用 | 内容是否准确；哪些故事值得讲；机器人怎样回应观众的问题 |
| **生活与服务** | 校园迎新互动助手、活动主持助手、科普问答与动作互动应用 | 谁会使用它；操作是否清楚；什么情况下应提示用户或结束互动 |

学生可以组合方向。例如，足球作品可以加入解说与角色设计；文化作品可以加入动作表演和观众选择。选题从一个明确场景开始，先完成可演示的版本，再逐步丰富。

## 零基础与有经验的孩子，怎样一起学

**零基础学生从操作体验、内容设计、流程编排和模板修改进入。** 他们可以先让机器人完成一段自己设计的互动，再逐步理解其中的条件、顺序与参数。

**已有基础的学生可以深入行为规则、视觉触发、Python程序或Agent界面。** 同一主题提供不同深度的任务，学生根据实际进展继续挑战。

小组中设置内容策划、交互设计、程序实现、测试与展示等职责，并安排轮换。每位学生都要参与基础操作、行为规则讨论和作品测试，也要能说明自己负责的部分。老师通过模板、操作和AI辅助支持实现，逐步增加学生独立完成的内容。

## 家长可以看到哪些成长

| 培养方向 | 在作品与过程中可以观察到的表现 |
|---|---|
| **理解当下科技** | 能结合自己的作品解释机器人的感知、判断与行动，举例说明AI会在哪些情况下出错 |
| **与AI合作并作出判断** | 能把想法描述成明确要求，对AI给出的内容或代码进行核对，并用实际运行结果判断是否可用 |
| **创意与人文表达** | 能围绕观众和使用者选择内容、语言、动作与互动方式，说明自己的设计理由 |
| **解决问题与持续改进** | 能记录一次失败，指出修改了什么，比较修改前后的效果 |
| **合作与公众表达** | 能承担约定职责，与伙伴完成交接，向观众介绍作品并回答问题 |

老师围绕作品和个人贡献提供阶段反馈。家长可以看到孩子的构想、测试片段、修改记录与展示，了解孩子在哪些方面有兴趣、能够独立完成哪些任务，以及还需要怎样的支持。

## 最终完成怎样的作品

作品根据主题选择适合的运行方式，两种形式都可以成为完整成果。

**机器人Agent应用**

为作品取名，设计图标、操作入口与机器人响应。适配完成的作品，可通过Booster App展示和操作，让观众选择内容、触发互动或查看状态。这里的Agent是具有明确用途的机器人应用。

**电脑程序驱动的现场展演**

通过在课程环境中运行的程序，组织K1的动作、语音或视觉互动，完成一段机器人剧场、游戏挑战或主题展示。

每组保留作品工程或程序、作品说明及演示记录；每位学生留下个人贡献与改进记录。展示时，学生需要说明作品为谁设计、怎样使用、适合什么场景，以及自己如何让它变得更好。

具备分发条件的Agent，可进一步探索在Booster生态中的分享与发布。具体发布方式以平台当时的开放能力和审核规则为准。

## 每个周末的两小时

学生来到加速进化，在老师带领下完成体验讨论、创作实践、真机测试与交流回顾，中间安排休息。小组创作与机器人测试轮换进行，作品在一次次周末见面中持续完善。

课程以现场完成主要学习任务为原则，家庭拓展可自愿选择。作品展示邀请家长参与，由学生演示和介绍自己的创作。

**适合人群：初中阶段，愿意尝试创作、表达或探索科技的学生。**

**学习安排：每周末一次，每次两小时。**

**作品目标：在约定场景中可以运行和展示，学生能够说明自己的设计、贡献与改进。**
