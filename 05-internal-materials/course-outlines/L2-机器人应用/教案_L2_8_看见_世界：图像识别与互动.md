# 教案\_L2\_8"看见"世界：图像识别与互动

## 一、教学目标

### 知识与技能

- 理解视觉识别的基本原理（采集图像→特征提取→分类判断→输出结果）。

- 掌握核心视觉积木：启动视觉服务、获取视觉检测结果、获取检测对象数量、获取检测对象的属性。

- 学会通过循环持续获取视觉数据，理解实时感知的必要性。

- 能够从RGB均值中提取颜色信息，并通过条件判断控制LED灯。

- 能够利用边界框坐标计算物体中心点，控制机器人头部实现简单跟随。

### 过程与方法

- 经历“单次获取→循环感知→特征提取→位置响应”的认知进阶过程。

- 通过打印调试、阈值调整等实践，培养参数调试与问题排查能力。

- 在阶梯式任务探索中，逐步建构视觉编程的核心思维。

### 情感、态度与价值观

- 在赋予机器人“看见”能力的过程中，体验技术带来的成就感。

- 理解视觉识别的本质是模式匹配，建立对人工智能技术科学的认知。

- 培养在真实环境中调试程序的耐心与细致。

## 二、教学重难点

- **教学重点**

    1. 启动视觉服务并正确选择检测模式。

    2. 通过循环持续获取视觉数据。

    3. 从RGB均值中提取颜色信息并判断。

    4. 利用边界框坐标计算中心点并控制头部。

- **教学难点**

    1. 理解视觉识别需要循环才能持续感知。

    2. 理解RGB颜色模型与阈值判断的方法。

    3. 理解边界框坐标系与中心点计算。

## 三、认知转译策略

- **类比法**：将视觉识别比作“拍照→找特点→贴标签→打报告”；将RGB颜色模型比作“调色盘”；将死区设置比作“瞄准镜”。

- **阶梯任务**：设计四个递进任务，分别对应“看见什么”、“持续看见”、“看懂颜色”、“知道位置”四个核心问题，逐步突破重点。

- **调试实践**：通过“打印中间变量”的策略，帮助学生直观理解数据含义，掌握参数调试方法。

- **对比实验**：先运行单次程序，再运行循环程序，让学生亲身体验“循环感知”的必要性。

## 四、教学准备

- **教师准备**

    - 教学课件：包含视觉识别原理图、积木功能说明、四个任务的程序截图。

    - 演示环境：教师机软件环境正常，演示机器人电量充足。

    - 视觉道具：红色、绿色、蓝色杯子或色卡各一个，红色小球一个（用于头部跟随）。

    - 场地布置：机器人前方区域光线均匀，地面平整。

- **学生准备**

    - 知识准备：已掌握图形化编程界面的基本操作，了解“重复执行”和“如果\-那么”条件判断。

    - 学习用具：每组一台已连接机器人的电脑，红、绿、蓝色卡各一张，笔记本、笔。

- **环境准备**

    - 硬件：机房电脑、K1机器人、稳定的Wi\-Fi网络。

    - 安全：清理机器人活动区域，确保有足够空间进行演示。

## 五、教学过程详细设计（45分钟）

### 阶段一：导入与情境创设（约5分钟）

1. **快速回顾，建立连接（约2分钟）**

    - **教师活动**：提问引导学生回顾上节课内容。“上节课我们为K1机器人装上了‘耳朵’和‘嘴巴’，具体是哪两项技术？”引导学生回答出语音识别（ASR）和语音合成（TTS）。教师总结并引出“循环监听”的概念。

    - **学生活动**：回忆并回答上节课核心知识点，理解“耳朵”和“嘴巴”的比喻。

    - **关键提问**：“我们让机器人一直听，用的是哪个积木结构？”（重复执行）

2. **情境过渡，激发认知冲突（约1\.5分钟）**

    - **教师活动**：提出问题：“有了耳朵和嘴巴，机器人能和我们对话了。但如果我们对它说‘到我面前来’，它能准确走过来吗？”引导学生发现“看不见”的问题。接着展示Booster APP的摄像头画面，提问：“它能‘拍’到画面，但能‘看懂’吗？”引出核心问题：“如何让机器人‘看见’并‘理解’世界？”

    - **学生活动**：参与讨论，发现“看见”的重要性，明确本课核心。

    - **关键提问**：“摄像头能拍摄画面，但画面本身对机器人有意义吗？”（没有，需要编程理解）

3. **课题揭示，明确目标（约1\.5分钟）**

    - **教师活动**：揭示课题：“今天，我们就为K1机器人装上‘智慧之眼’，学习——视觉识别基础：让机器人‘看见’世界。”并明确本课要探索的四个核心问题：机器人看见的是什么？如何让机器人持续看见？如何让机器人“看懂”颜色？如何让机器人“知道”物体在哪里？

    - **学生活动**：记录本课学习目标，建立对本课知识框架的整体认知。

### 阶段二：新知讲解与概念建构（约12分钟）

1. **视觉识别原理通俗讲解（约5分钟）**

    - **教师活动**：以“看到红色苹果”为例，类比讲解视觉识别四步流程：**采集图像（拍照）** → **特征提取（找特点）** → **分类判断（贴标签）** → **输出结果（打报告）**。强调机器人的“看见”本质是高速的“模式匹配”，而非真正的“理解”。

    - **学生活动**：聆听并理解视觉识别的四个步骤，记录关键词：拍照、找特点、贴标签、打报告。

2. **视觉积木功能详解（约7分钟）**

    - **教师活动**：切换到编程界面，逐一讲解核心积木。

        - **服务控制积木**：`启动视觉服务`（总开关，可勾选颜色/位置/人脸检测）。强调“只开启需要的功能”以节省计算资源。配套积木`停止视觉服务`。

        - **结果获取积木**：`获取视觉检测结果`（获取完整报告，必须放在循环里）、`获取检测对象数量`（获取报告中的目标个数）。

        - **对象属性获取积木**：`获取检测对象的属性`。重点讲解本课用到的属性：**RGB均值**（颜色信息）和**边界框坐标**（位置信息）。

    - **学生活动**：跟随教师找到并尝试使用这些积木，理解其功能和区别。

### 阶段三：实践操作（约22分钟）

**过渡**：通过四个阶梯任务，引导学生一步步探索。

**任务一：机器人如何“看见”？——单次打印观察（约5分钟）**

- **核心问题**：机器人看到的东西，在程序里长什么样？

- **程序搭建**：`当程序启动` → `启动视觉服务`（勾选颜色检测）→ `等待1秒` → `获取视觉检测结果`存入变量 → `打印`该变量。

- **实践与观察**：运行程序，展示终端输出（无物体时可能为空）。拿出红色色卡，再次运行，观察终端输出的数据（对象数量、标签、RGB均值等）。

- **阶段小结**：引导学生发现，单次获取是“一次性快照”。

**任务二：如何让机器人持续看见？——循环获取（约5分钟）**

- **核心问题**：为什么需要循环？

- **程序改造**：在任务一基础上，将“获取视觉检测结果”和“打印”放入`重复执行`循环内，并添加`等待0.2秒`。

- **实践与观察**：手持色卡缓慢移动，观察终端输出不断刷新。调整等待时间，感受反应速度的变化。

- **阶段小结**：总结出公式：**持续看见 = 循环 \+ 间隔时间**。

**任务三：如何让机器人“看懂”颜色？——RGB判断与控制（约6分钟）**

- **核心问题**：颜色在计算机里是什么？如何判断？

- **概念建立**：讲解RGB颜色模型，展示常见颜色的RGB值。

- **程序编写**：

    1. 在循环内，先`获取检测对象数量`，判断是否大于0。

    2. 用`获取检测对象的属性`获取第一个对象的“RGB均值”，并提取R、G、B值。

    3. 编写判断条件（如红色：R\>200且G\<100且B\<100）。

    4. 在判断内添加`设置LED灯颜色`积木。

- **实践与调试**：用红、绿、蓝色卡测试，观察LED灯变化。引导学生用“打印”调试，根据实际数值调整阈值。

- **阶段小结**：总结出公式：**看懂颜色 = RGB特征 \+ 阈值判断**

**任务四：如何让机器人“知道”物体在哪里？——坐标提取与头部跟随（约6分钟）**

- **核心问题**：机器人如何判断物体是偏左还是偏右？

- **概念建立**：讲解机器人视野的坐标系（左上角为原点），边界框坐标 `[X1, Y1, X2, Y2]` 的含义。引导学生思考为什么用中心点而不是左边框来判断位置，并演示中心点计算方法：`中心X = (X1 + X2) / 2`。

- **程序编写**：

    1. 在循环内，获取第一个对象的“边界框坐标”。

    2. 计算中心X坐标。

    3. 编写判断逻辑（假设画面宽度640，中心320）：如果中心X \< 270，头部向左转；如果中心X \> 370，头部向右转；否则头部回正。

- **实践与调试**：用红色物体测试头部跟随效果。引导学生调整死区范围（270\-370）和转角角度，让跟随更平滑。

- **认知深化**：讲解“死区”设置的目的——防止头部在中心附近频繁抖动。

- **阶段小结**：总结出公式：**知道位置 = 坐标提取 \+ 中心点 \+ 死区控制**。

### 阶段四：展示讨论与思维提升（约4分钟）

1. **成果展示与互评（约2分钟）**

    - **教师活动**：邀请1\-2个小组展示他们的头部跟随程序。引导学生从跟随平滑度、死区设置等方面进行观察和评价。“这个小组的机器人头部跟随平滑吗？有没有抖动？”“如果让你改进，你会怎么优化？”

    - **学生活动**：展示小组分享调试心得，其他小组观察、评价、提出建议。

2. **核心提炼：知识阶梯与思维提升（约2分钟）**

    - **教师活动**：带领学生回顾四个任务构建的认知阶梯：看见（一次性快照）→ 持续看见（循环感知）→ 看懂颜色（RGB判断）→ 知道位置（坐标跟随）。进行关键追问：“如果不用循环，机器人能追踪移动的物体吗？”“如果不知道边界框坐标，机器人能转头跟随吗？”最后，点明“持续获取→提取特征→条件响应”是传感器编程的核心模式，可以迁移到其他场景（如语音识别、温度控制）。

    - **学生活动**：跟随教师回顾，回答追问，思考并分享该模式的其他应用。

### 阶段五：总结延伸与知识锚定（约2分钟）

1. **知识回顾（快速问答）（约0\.5分钟）**

    - **教师活动**：快速提问，检验学生掌握情况。“机器人‘看见’一次数据，我们用什么积木获取？”“要让机器人持续看见，必须把获取积木放在哪里？”“判断颜色时，我们看的是RGB值里的哪个属性？”“要让机器人转头跟随物体，我们需要计算什么？”

    - **学生活动**：快速回答，巩固记忆。

2. **作业布置（约1分钟）**

    - **基础作业**：完善任务三的程序，让机器人识别到红色时亮红灯并说“红色”，识别到绿色时亮绿灯并说“绿色”，识别到蓝色时亮蓝灯并跳一个舞蹈。录制30秒演示视频。

    - **拓展思考**：如果要让机器人不仅能转头，还能一边转头一边向物体走去，需要增加什么逻辑？提示：可以用深度相机的距离信息（3D位置中的Z坐标）。写出你的设计思路。

## 六、分层任务设计

- **基础层（必做）**：完成任务一、二、三。目标：掌握核心积木，完成颜色识别。

- **进阶层（选做）**：在任务三基础上增加语音反馈；在任务四基础上增加上下跟随。目标：提升程序的智能性和交互性。

- **挑战层（选做）**：完成“颜色分类员”（识别并推动不同颜色积木）、“寻找特定颜色”（原地旋转搜索）或“距离感知跟随”（保持固定距离跟随）。目标：融合多知识点，解决复杂问题。

## 七、协作与角色分工建议

建议采用两人一组或四人一组的小组协作模式。

- **两人一组**：

    - **操作员**：负责拖拽积木、运行程序、操作机器人。

    - **观察员/记录员**：负责观察输出、记录数据、检查逻辑、协助调试。

    - 每完成一个任务，两人交换角色。



- **四人一组**：

    - **程序员**：搭建和修改程序。

    - **测试员**：运行程序、出示道具、观察反应。

    - **记录员**：记录实验结果、填写调试清单。

    - **技术顾问**：检查逻辑、协助调试、解答疑问。

    - 每完成一个任务，角色顺时针轮换。

## 八、思维提升与伦理融入

- **思维提升问题链**

    - **批判性思维**：“单次获取的结果是‘真实’的画面吗？还是某一瞬间的‘切片’？”

    - **系统性思维**：“循环让机器人持续看，但等待时间设多少合适？太快会怎样？太慢会怎样？”

    - **算法思维**：“为什么我们用R\>200而不是R=255来判断红色？”

    - **设计思维**：“如果物体在画面中心附近小范围抖动，头部会怎样？怎么解决？”（引出“死区”概念）

    - **迁移思维**：“今天学的‘持续获取→提取特征→条件响应’还能用在哪些传感器上？”

- **伦理融入议题**

    - **隐私边界**：讨论如果机器人被放在公共场所一直“看见”并记录信息，有何好处和风险？引导学生思考“隐私设计”。

    - **算法偏见**：讨论如果颜色识别程序只在光线好时准确，在光线暗时失效，会导致什么问题？引导学生思考“负责任的AI”。

    - **人机关系**：讨论如果机器人能认出你并打招呼，你会觉得它是朋友吗？引导学生理解机器人的能力边界，避免情感依赖。

## 九、课后延伸与思考题

- **基础延伸**：优化颜色识别程序，增加对黄色的识别，并设置对应反应。

- **拓展延伸**：设计一个“智能垃圾分类助手”的创意应用；查阅资料了解深度相机的“深度”信息。

- **挑战延伸**：结合语音识别，设计一个“语音\+视觉”的交互程序（如语音命令“看红色”，机器人开始搜索红色物体）。

- **思考题**：如果未来机器人真的能“理解”它看到的东西，你觉得和今天的“模式匹配”有什么不同？

## 十、评价与反馈设计

- **评价维度**：程序正确性、代码规范、调试能力、协作贡献、思维表达。

- **评价方式**：

    - **过程性评价（30%）**：教师巡视，记录学生参与度、调试表现、协作情况。

    - **同伴互评（20%）**：组员互相评价角色履行情况。

    - **成果评价（30%）**：提交程序文件和演示视频。

    - **自我反思（20%）**：填写反思卡片。

## 十一、知识拓展卡（示例）

- **拓展卡一：深度相机**

    - 介绍K1机器人的深度相机，它能测量物体的距离，就像人的双眼一样，通过“立体视觉”原理工作。

- **拓展卡二：RGB颜色模型**

    - 详细介绍颜色由红\(R\)、绿\(G\)、蓝\(B\)三色光混合而成，数值范围0\-255。展示常见颜色的RGB值。

- **拓展卡三：阈值与宽容度**

    - 解释为什么用“R\>200”而不是“R=255”来判断红色，引出“阈值”和“宽容度”的概念，并举例说明。

## 十二、技术工具支持说

- **软件环境**：Mind\+ V1\.x（Windows版本），需加载K1机器人用户库，必须切换到Python模式。

- **硬件准备**：每组需K1机器人1台、电脑1台、红/绿/蓝色卡各1张、红色小球1个（可选）。

- **常见问题与解决**：

    - **连接失败**：检查IP地址，确保电脑与机器人同一网络。

    - **终端无输出**：检查是否开启了视觉服务，摄像头是否开启。

    - **颜色识别混乱**：用“打印”输出RGB值，调整阈值。

    - **头部抖动**：增大死区范围（如从±50改为±80）。

## 十三、教学反思与调整建议（教师用）

- **教学效果自评**：对视觉原理理解、积木掌握、任务完成度等维度进行自我评估。

- **成功经验**：记录效果最好的环节、学生最感兴趣的内容、效果最好的类比。

- **问题与调整建议**：记录学生理解困难的环节、时间安排是否合理、技术设备稳定性，并提出改进建议。

- **学生表现记录**：记录印象深刻的学生提问、普遍存在的错误、需要额外帮助的学生。

- **下节课调整方向**：明确需要复习的内容、可删减或新增的环节。

- **资源优化建议**：记录PPT、示例程序、教具的改进点。
