# 教案\_L3\_11\_多二维码识别与动作执行

|**基本信息**|||
|---|---|---|
|**课    题**|多二维码识别与动作执行||
|**教学目标**|||
|**知识与技能**|理解多目标选择、最大二维码优先、MARKER\_ACTIONS 配置表、current\_target\_id 锁定和 EXECUTE\_ACTION 状态。<br>掌握通过二维码 ID 触发不同机器人动作的程序结构。||
|**过程与方法**|通过运行多二维码程序，完成搜索多个 ID、选择最近目标、靠近目标、查表执行动作、回到搜索的循环。<br>通过观察配置表和状态机，理解如何扩展新的动作卡。||
|**情感态度与价值观**|认识配置驱动思想在机器人任务中的价值。<br>形成把变化内容放在数据表、把稳定流程放在程序结构中的工程意识。||
|**教学重点**|多二维码目标选择、ID 到动作的配置表映射和六状态循环状态机。||
|**教学难点**|理解多目标场景下为什么要锁定 current\_target\_id，以及 DONE 为什么回到 SEARCH。||
|**教学活动流程**|||
|**教师活动**||**学生活动**|
|环节一：【时长：5分钟】<br>回顾第10课单二维码靠近，提出问题：如果地上有三张二维码，机器人先处理谁？<br>展示本课任务：ID 0 后退、ID 1 左转、ID 2 右转。||活动一：<br>比较单目标和多目标任务差异。<br>预测多目标会带来的选择问题。|
|设计意图：从已掌握的单目标控制引出多目标选择和任务卡概念。|||
|环节二：【时长：10分钟】<br>讲解 TARGET\_IDS 和 choose\_best\_target\_marker：只在有效 ID 中选择对角线最大的二维码。<br>说明最大通常代表最近，但也有尺寸差异等局限。||活动二：<br>观察多张二维码的大小变化。<br>解释为什么“第一个检测到的”不一定适合作为当前目标。|
|设计意图：让学生理解多目标选择需要明确规则，并认识规则的适用边界。|||
|环节三：【时长：10分钟】<br>讲解 MARKER\_ACTIONS 配置表，说明 name、display、type 的作用。<br>比较把动作写死在 if 里和放入配置表的区别。||活动三：<br>阅读配置表，指出每个 ID 对应的动作。<br>说出如果新增 ID 3，需要修改哪些位置。|
|设计意图：引入配置驱动思想，帮助学生理解机器人行为可以由数据表控制。|||
|环节四：【时长：15分钟】<br>讲解六状态 FSM：SEARCH、ALIGN、STEP\_FORWARD、CHECK\_DONE、EXECUTE\_ACTION、DONE。<br>运行程序，观察到达二维码后 execute\_marker\_action 如何查表并执行动作。<br>强调 current\_target\_id 锁定和 ACTION\_PAUSE\_TIME 的意义。||活动四：<br>观察机器人处理不同二维码后的动作。<br>记录一次完整循环：搜索、对准、前进、执行动作、回到搜索。|
|设计意图：把多目标、配置表和状态机循环整合起来，让学生理解读卡做事的完整闭环。|||
|环节五：【时长：5分钟】<br>总结第11课与第10课的增量关系：目标从一个变多个，完成后从结束变循环，动作从停止变查表执行。<br>预告第12课会把二维码变成迷宫路标。||活动五：<br>复述 MARKER\_ACTIONS、current\_target\_id、EXECUTE\_ACTION 的作用。|
|设计意图：巩固多目标动作卡结构，为二维码迷宫中的路标决策做准备。|||
