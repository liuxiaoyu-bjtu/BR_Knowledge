# 教案\_L3\_06\_语音系统控制综合实践

|**基本信息**|||
|---|---|---|
|**课    题**|语音系统控制综合实践||
|**教学目标**|||
|**知识与技能**|综合理解 TTS、ASR、动作控制和关键词分发之间的关系。<br>掌握语音互动机器人小助手程序中初始化、欢迎语、主循环、动作响应和停止收尾的结构。||
|**过程与方法**|通过完整运行项目程序，体验机器人接收语音、判断关键词、语音回应、执行动作的闭环。<br>通过观察日志和机器人行为，定位语音、动作、模式切换中的常见问题。||
|**情感态度与价值观**|形成系统集成意识，认识机器人应用不是单个功能，而是多条控制链协同。<br>增强语音控制场景中的安全意识和反馈意识。||
|**教学重点**|把 TTS、ASR、动作 API 组合成一个可运行的语音互动项目。||
|**教学难点**|多个能力同时运行时，如何保持初始化顺序、主循环节奏、动作停止和程序收尾清晰。||
|**教学活动流程**|||
|**教师活动**||**学生活动**|
|环节一：【时长：5分钟】<br>回顾第3\-5课：动作 API、TTS、ASR。<br>提出本课项目：让 K1 成为语音互动小助手，能听、判、说、动、停止。||活动一：<br>说出前几课分别学过的能力。<br>根据项目名称预测程序需要哪些模块。|
|设计意图：激活前置知识，让学生知道本课是阶段综合，而不是全新孤立内容。|||
|环节二：【时长：8分钟】<br>讲解三条控制链：动作控制链、语音播报链、语音识别链。<br>用流程图说明 ASR 输入、关键词分发、TTS 反馈、动作执行之间的关系。||活动二：<br>在笔记中画出“听→判→说/动→收尾”的流程。<br>说出每条链路对应的主要客户端或函数。|
|设计意图：用系统结构图帮助学生把多个 API 组织成整体应用。|||
|环节三：【时长：12分钟】<br>分段运行初始化代码：ChannelFactory、B1LocoClient、LuiClient、ASR 订阅器、StopAsr/StopTts、StartTts/StartAsr。<br>讲解欢迎语和 Walking 模式切换的意义。||活动三：<br>观察初始化输出和欢迎语效果。<br>标注哪些代码负责动作，哪些代码负责语音。|
|设计意图：强化综合项目中的初始化顺序，减少学生把错误都归为“机器人没反应”的情况。|||
|环节四：【时长：15分钟】<br>运行主循环，演示“你好、挥手、跳舞、月球漫步、前进、停止”等指令。<br>讲解每个分支中的 TTS 确认、动作调用、sleep 和停止指令。<br>引导学生观察终端日志与机器人动作是否对应。||活动四：<br>轮流发出语音指令或观察同伴操作。<br>根据终端日志判断程序当前处理的是哪条命令，记录异常现象。|
|设计意图：通过完整项目体验多能力协同，并让日志成为理解机器人内部状态的工具。|||
|环节五：【时长：5分钟】<br>总结综合项目结构：初始化→欢迎语→主循环→关键词分发→动作/语音响应→停止退出。<br>说明第7课将进入视觉输入，机器人会从“听”扩展到“看”。||活动五：<br>复述项目主流程，说明为什么 Move 后必须停止、为什么未知指令要有默认回应。|
|设计意图：收束语音阶段学习，并自然过渡到视觉课程。|||
