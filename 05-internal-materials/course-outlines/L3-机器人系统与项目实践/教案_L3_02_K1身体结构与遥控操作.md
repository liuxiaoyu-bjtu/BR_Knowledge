# 教案\_L3\_02\_K1身体结构与遥控操作

|**基本信息**|||
|---|---|---|
|**课    题**|K1身体结构与遥控操作||
|**教学目标**|||
|**知识与技能**|认识 K1 的身体结构、关节自由度、传感器、计算单元和基础工作模式。<br>理解遥控器、App 与机器人连接的基本方式，知道 DAMP、PREP、WALK 等模式与安全控制的关系。||
|**过程与方法**|通过观察实物、图片或视频，按部位梳理 K1 的身体结构。<br>通过教师演示和分步说明，掌握开机、连接、遥控、App 操作与安全停止的基本流程。||
|**情感态度与价值观**|建立真实机器人操作中的安全意识，理解操作机器人要先确认空间、模式和连接状态。<br>形成尊重设备、按流程操作的工程习惯。||
|**教学重点**|K1 主要身体部件、基础工作模式、遥控器与 App 的连接和操控流程。||
|**教学难点**|理解机器人模式与动作能力之间的关系，避免把遥控操作理解成普通玩具遥控。||
|**教学活动流程**|||
|**教师活动**||**学生活动**|
|环节一：【时长：5分钟】<br>展示 K1 站立图片或实物，提出问题：如果要让 K1 走路、挥手、听声音，它分别需要哪些身体部件？<br>说明本课任务是先学会认识身体，再学会安全操控。||活动一：<br>观察 K1，指出头部、躯干、手臂、腿部、相机和扬声器等部件。<br>说出这些部件可能承担的作用。|
|设计意图：从可见身体结构进入技术学习，降低模式、自由度、传感器等概念的抽象感。|||
|环节二：【时长：10分钟】<br>讲解 K1 的机械结构和传感器：关节模组提供运动，相机提供视觉，麦克风提供语音输入，扬声器提供语音输出，计算单元运行程序。<br>说明自由度含义：一个自由度通常对应一个可控制的运动方向。||活动二：<br>根据教师讲解在结构示意中标注“运动部件、感知部件、表达部件、计算部件”。<br>回答为什么腿部自由度对行走重要、为什么相机对视觉任务重要。|
|设计意图：让学生把身体部件与后续课程能力建立对应关系，避免只记名称不懂用途。|||
|环节三：【时长：10分钟】<br>结合视频或现场演示讲解开机、连接遥控器、进入准备状态、切换行走状态、执行基础移动、停止和关机流程。<br>强调操作前检查地面、周围空间、电量和急停方式。||活动三：<br>观察教师操作流程，记录关键顺序：开机、连接、切模式、移动、停止。<br>识别哪些步骤属于安全检查，哪些步骤属于控制操作。|
|设计意图：把操作流程拆成可执行步骤，使教师和学生都能真实理解一台机器人从开机到可控的过程。|||
|环节四：【时长：15分钟】<br>讲解遥控器与 App 的区别：遥控器适合即时运动控制，App 适合连接、状态查看和部分功能操作。<br>演示或说明连接方式：确保网络/蓝牙或指定连接条件满足，确认机器人在线，再进行操作。<br>设置一个小任务：让 K1 完成准备、前进一小段、停止、恢复安全状态。||活动四：<br>按教师分配观察或轮流操作，注意记录每一步机器人状态变化。<br>在操作或观察中说出当前处于准备、行走、停止中的哪一种状态。|
|设计意图：让学生理解控制不是按键本身，而是连接状态、工作模式和动作指令共同作用的结果。|||
|环节五：【时长：5分钟】<br>总结 K1 身体结构与操控关系：身体决定能做什么，传感器决定能感知什么，模式决定当前允许做什么。<br>用口头提问检查：为什么移动前要确认 Walking？为什么停止指令重要？||活动五：<br>回答总结问题，整理本课安全操作要点。|
|设计意图：强化模式和安全意识，为第3课代码控制中的 ChangeMode、Move 等 API 做铺垫。|||
