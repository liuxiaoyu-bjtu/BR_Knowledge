# 教案\_L3\_09\_视觉挑战任务

|**基本信息**|||
|---|---|---|
|**课    题**|视觉挑战任务||
|**教学目标**|||
|**知识与技能**|理解 ArUco 标记、字典、ID、角点、rejected 候选框和结构化识别结果。<br>知道 ArUco 与普通二维码、AprilTag 的区别，以及角点如何用于位置分析和后续导航。||
|**过程与方法**|通过生成 ArUco 图片、订阅相机图像、检测二维码、输出 ID 与角点，完成从生成到识别的完整流程。<br>通过 analyze\_marker 计算 offset\_x 和 size\_ratio，理解二维码位置与大小如何转化为控制提示。||
|**情感态度与价值观**|认识人工视觉标记在机器人定位、导航和任务触发中的价值。<br>形成先验证感知再接入控制的工程开发意识。||
|**教学重点**|ArUco 字典、二维码生成、实时检测、ID 与角点输出，以及 offset\_x/size\_ratio 分析。||
|**教学难点**|理解 ID 只解决“是谁”，角点才解决“在哪里”和“离多近”。||
|**教学活动流程**|||
|**教师活动**||**学生活动**|
|环节一：【时长：5分钟】<br>展示普通二维码与 ArUco 标记，提出问题：为什么机器人课程不用普通二维码作为主要定位标记？<br>说明本课任务：生成、识别并读取 ArUco。||活动一：<br>观察两类二维码外观差异。<br>猜测 ArUco 中黑边和内部网格的作用。|
|设计意图：用对比导入 ArUco，使学生理解人工标记是为视觉定位而设计的。|||
|环节二：【时长：10分钟】<br>讲解 ArUco 字典、DICT\_4X4\_50、ID、黑色边框和内部编码。<br>说明同一字典下不同 ID 代表不同图案，生成和识别必须使用同一字典。||活动二：<br>记录字典和 ID 概念。<br>回答为什么随便画黑白方块不能被识别。|
|设计意图：建立 ArUco 的编码规则概念，为生成与检测代码打基础。|||
|环节三：【时长：10分钟】<br>运行 lesson\_09\_generate\_aruco\.py，讲解 get\_aruco\_dictionary、generateImageMarker、保存 PNG 的过程。<br>展示生成的 ID 0、1、2 标记。||活动三：<br>观察生成文件，确认不同 ID 图案不同。<br>说出 marker\_size 和 save\_dir 的作用。|
|设计意图：让学生看到编号如何变成可打印视觉标记，理解标记可控、低成本、可复现。|||
|环节四：【时长：15分钟】<br>运行检测程序，讲解 detectMarkers 返回 corners、ids、rejected。<br>展示终端打印 ID 和四个角点，讲解 analyze\_marker 中 offset\_x、size\_ratio 的计算。<br>说明第9课只给控制提示，不直接控制机器人。||活动四：<br>移动二维码观察 offset\_x 和 size\_ratio 的变化。<br>判断目标在左、右、近、远时输出信息如何变化。|
|设计意图：把识别结果从“看见 ID”推进到“分析位置”，为第10课视觉控制准备数据基础。|||
|环节五：【时长：5分钟】<br>总结 ArUco 的作用：ID 表示身份，角点表示位置，大小近似表示距离。<br>预告第10课会让机器人根据这些数据真正对准并接近二维码。||活动五：<br>复述 corners、ids、rejected 的含义，整理 offset\_x 和 size\_ratio 的作用。|
|设计意图：收束二维码识别知识，并明确下一课从感知到运动的过渡。|||
