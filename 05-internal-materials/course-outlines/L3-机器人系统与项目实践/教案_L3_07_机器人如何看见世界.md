# 教案\_L3\_07\_机器人如何看见世界

|**基本信息**|||
|---|---|---|
|**课    题**|机器人如何看见世界||
|**教学目标**|||
|**知识与技能**|理解机器人视觉输入、ROS2 图像话题、sensor\_msgs/Image、回调函数、cv\_bridge 和 OpenCV 的作用。<br>知道 K1 相机图像从话题进入程序后，需要转换为 OpenCV 图像才能保存和处理。||
|**过程与方法**|通过运行拍照程序，完成订阅图像、转换格式、非阻塞检测回车、保存彩色图和灰度图。<br>通过观察图像文件，比较彩色图与灰度图的差异。||
|**情感态度与价值观**|形成从数据流角度理解机器人视觉的意识，认识视觉智能首先来自稳定的数据获取。<br>建立对实时程序中非阻塞、最新帧、资源释放等工程细节的重视。||
|**教学重点**|相机话题订阅、ROS 图像到 OpenCV 图像的转换，以及图片保存流程。||
|**教学难点**|理解 ROS2 Image 消息不是普通图片，必须通过 cv\_bridge 和编码处理转成可计算图像。||
|**教学活动流程**|||
|**教师活动**||**学生活动**|
|环节一：【时长：5分钟】<br>提出问题：机器人怎样“看见”世界？它看到的是一张图片，还是连续图像流？<br>展示 K1 相机参数和 /StereoNetNode/rectified\_image 话题名称。||活动一：<br>说出人眼与相机的类比。<br>判断机器人视觉输入为什么是连续图像流。|
|设计意图：从直观问题进入视觉输入概念，建立相机话题和图像流意识。|||
|环节二：【时长：10分钟】<br>讲解 ROS2 节点、话题、消息、订阅、回调；说明相机节点发布 Image 消息，Python 节点订阅。<br>讲解 OpenCV 是图像处理库，cv\_bridge 是 ROS 图像与 OpenCV 图像之间的桥。||活动二：<br>记录节点、话题、消息、回调四个概念。<br>用箭头画出“相机节点→话题→Python 回调→OpenCV 图像”的路径。|
|设计意图：补足视觉程序的通信背景，避免学生只记住代码而不理解数据从哪里来。|||
|环节三：【时长：12分钟】<br>讲解并运行 ros\_image\_to\_bgr：处理 nv12、bgr8、rgb8、mono8 等编码。<br>说明图像是数组，BGR 与 RGB 的区别，灰度图只有一个通道。||活动三：<br>观察代码中 encoding 判断和 cv2\.cvtColor 的作用。<br>回答为什么 NV12 不能直接当作普通 BGR 图片处理。|
|设计意图：把图像格式转换讲清楚，为第8课颜色识别和形状检测打基础。|||
|环节四：【时长：13分钟】<br>讲解 check\_enter\_pressed 与 save\_images。运行程序，让学生按回车触发拍照，保存彩色图和灰度图。<br>说明为什么不用 input，为什么只保存 latest\_frame。||活动四：<br>观察终端提示，按回车或观看拍照过程。<br>打开保存目录，比较彩色图与灰度图在信息上的差别。|
|设计意图：通过真实文件输出让学生确认视觉链路已打通，同时理解非阻塞输入和最新帧策略。|||
|环节五：【时长：5分钟】<br>总结视觉输入链路：相机→ROS2 话题→回调→cv\_bridge→OpenCV→保存。<br>预告第8课将不再只是保存图片，而是识别颜色和形状。||活动五：<br>复述图像进入程序的路径，整理 OpenCV、cv\_bridge、Image Topic 等关键词。|
|设计意图：巩固视觉输入基础，为后续视觉理解任务做认知收束。|||
