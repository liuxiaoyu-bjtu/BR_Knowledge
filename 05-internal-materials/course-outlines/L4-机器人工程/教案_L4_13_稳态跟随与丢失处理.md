|**知识与技能**|1\. 理解 FSM（有限状态机）的三个核心要素 —— 状态 / 转换条件 / 动作；体会用「状态」管理行为比简单 if\-else 更稳定。<br>2\. 理解为什么状态切换要基于「丢球时长 lost\_sec」而不是单帧 detected，理解「短记忆」的工程价值。<br>3\. 掌握本课三状态的设计：TRACK（稳态跟随，复用 Lesson 12）/ FIND（六点局部扫描）/ SCAN（七点全局扫描）。<br>4\. 理解状态切换的时间阈值：lost\_to\_find\_sec=0\.5 / lost\_to\_scan\_sec=2\.0；以及对应的扫描节拍：find\_interval\_sec=0\.45 / scan\_interval\_sec=0\.65。<br>5\. 理解 FIND 与 SCAN 扫描序列的几何意义：FIND 在 yaw±0\.35 / pitch 0\.45\-0\.60 的小区域；SCAN 在 yaw±0\.75 / pitch 0\.45\-1\.00 的大范围。<br>6\. 理解节点内部的「两条并行线」：事件驱动线 on\_ball（YOLO 触发） \+ 定时驱动线 loop（20 Hz 心跳），通过 last\_seen\_time 通信。<br>7\. 理解 11 个函数的协作关系（init\_sdk / parse\_payload / on\_ball / update\_state / log\_state\_change / loop / action\_track/find/scan / rotate\_head / send\_body\_scan）。<br>8\. 知道默认 enable\_body\_scan=False 的安全考量；理解开启身体扫描的额外条件（空旷场地 \+ 教师保护）。<br>9\. 能完成 4 个实践：确认输入 → 跑 FSM → 调时间阈值（敏感型/默认/稳重型）→ 调扫描间隔（快/默认/慢）。<br>10\. 明确本课边界：只在「头部 \+ 像素」层做行为决策；坐标变换是 Lesson 14；走向 \+ 踢球是 Lesson 15。||
|**过程与方法**|1\. 通过「Lesson 12 简单回正 → 真实赛场球会消失 → 简单 if\-else 抖动 → 用时间阈值过滤」的认知递进，让学生看到 FSM 出现的必然。<br>2\. 通过 PPT P8 三状态拓扑图（圆 \+ 切换条件 \+ 回向箭头）建立 FSM 的视觉记忆。<br>3\. 通过 PPT P10/P11 的几何示意图（在头部可达扇形内画 6/7 个编号点 \+ 顺序箭头），让学生「看到」FIND vs SCAN 的范围差异。<br>4\. 通过 PPT P14 「两条并行线」图（事件线 vs 定时线 \+ last\_seen\_time 桥梁），让学生理解 FSM 的两个独立驱动源。<br>5\. 通过 4 个实践（确认 → 跑 FSM → 调时间阈值三档 → 调扫描间隔三档），让学生亲手感受参数对行为的影响。<br>6\. 通过排查表 6 行（含「头部完全不动 = SDK/模式」「身体误动 = enable\_body\_scan」）建立闭环排查方法。<br>7\. 通过 4 个挑战（A 身体扫描 / B allow\_stale / C 自定义扫描序列 / D 行为树）分层延伸，照顾不同程度的学生。||
|**情感态度与价值观**|1\. 体会工程系统中「状态」是管理复杂行为的核心抽象 —— 任何严肃机器人系统都用状态机或行为树管理决策。<br>2\. 通过「丢球不是异常，是常态」建立对工程现实的真实认知 —— 真实系统永远要处理「不完美的输入」。<br>3\. 通过 FSM 的「两条并行线」体会工程设计中的「解耦」思想 —— 不同时间尺度的逻辑用不同回调，互不阻塞。<br>4\. 通过 enable\_body\_scan 默认关闭的安全考量，建立「默认安全 → 进阶解锁」的工程审美。||
|**教学重点**|1\. FSM 三要素 \+ 三状态拓扑图（含切换条件）—— 必须用 PPT P7 \+ P8 讲透。<br>2\. 「为什么用 lost\_sec」—— 单帧 detected 抖动 vs 时间过滤的对比（PPT P5 \+ P6）。<br>3\. FIND vs SCAN 的几何范围差异（PPT P10 \+ P11 的扇形图）—— 视觉对比让学生看到「小范围找回 vs 大范围扫描」。<br>4\. on\_ball \+ loop 两条并行线 \+ last\_seen\_time 通信机制（PPT P14）。<br>5\. 时间阈值的三档对比（PPT P21）\+ 扫描间隔的三档对比（PPT P22）。||
|**教学难点**|1\. on\_ball 与 loop 是「并行运行」的两条线 —— 学生本能以为程序是单线性流程，需要用图（PPT P14）反复强调。<br>2\. 「状态」是一个软件工程概念，对学生来说较抽象 —— 用 PPT P7 交通灯类比 \+ P8 拓扑图建立直觉。<br>3\. lost\_sec 计算依赖时间戳 —— 学生容易混淆「上一帧」「上次检测」「定时器周期」三种时间概念。<br>4\. FIND 和 SCAN 扫描序列的几何含义 —— 6/7 个数字对学生晕，必须靠几何图（PPT P10/P11）解释。<br>5\. enable\_body\_scan 默认关闭的原因 —— 安全意识，要明确告诉学生「身体动 = 课堂风险」。||

  │     \<0\.5s    0\.5\~2\.0s    ≥2\.0s                       │

    pitch 0\.45\-1\.00,  yaw ±0\.75

  两条并行线:
    on\_ball  \(YOLO 触发, 异步\)  →  更新 last\_seen\_time
    loop     \(固定 20Hz, 定时\)  →  update\_state \+ action\_xxx

  关键参数:

    lost\_to\_scan\_sec  = 2\.0
    find\_interval\_sec = 0\.45
    scan\_interval\_sec = 0\.65
    enable\_body\_scan  = False  ★ 默认安全

  安全意识:
    enable\_body\_scan = False  课堂默认
