|**知识与技能**|1\. 区分 Lesson 04 的 SDK Python API 直接调用与本课的 ROS2 service 调用：前者是同进程函数调用，后者是跨进程服务调用，效果相同但工程意义不同。<br>2\. 认识 K1 的核心服务 /booster\_rpc\_service：它是 ROS2 世界里调用 Booster 底层动作能力的统一入口，类型为 booster\_interface/srv/RpcService。<br>3\. 掌握服务请求的两字段结构：api\_id（功能编号）\+ body（JSON 字符串参数），并理解 request\.msg\.xxx 的双层访问写法。<br>4\. 记住本课要用的 3 个 api\_id：2000 模式切换 / 2012 手末端控制 / 2016 舞蹈动作，以及 dance\_id=1000 这个「停止舞蹈」的特殊 body 参数。<br>5\. 掌握 rclpy 调用服务的 6 步骨架：rclpy\.init\(\) → Node → Client → wait\_for\_service → Request → call\_async → spin\_until\_future\_complete → 读 Response。<br>6\. 能用封装函数 send\_rpc\_request 简化单次调用，能用 dance\_by\_ros2 编排完整 6 步舞蹈流程。<br>7\. 能把 Lesson 04 的 say\(\) 与本课的 dance\_by\_ros2\(\) 组合，完成「说话 \+ 跳舞 \+ 说话」的综合案例。<br>8\. 知道 Notebook 反复运行 ROS2 节点时要做 cleanup（destroy\_node \+ shutdown），并配 try / except 防多次清理报错。||
|**过程与方法**|1\. 通过「Lesson 04 SDK 直接调 vs Lesson 06 ROS2 service 调」两段代码对照，建立「同事两做法」的工程认知。<br>2\. 通过先用 CLI 调用一次服务，再切到 Python rclpy 实现，体会「先理解结构再写程序」的工程思维。<br>3\. 通过「JSON 字符串 ✗ Python 字典 ✓」错误用法对比，让学生第一次踩坑就建立正确习惯。<br>4\. 通过从 send\_rpc\_request 到 dance\_by\_ros2 两层函数封装，体会「积木式编程」——单次调用做积木，函数组合做行为。<br>5\. 通过综合案例（语音 \+ 动作）建立「具身智能闭环」初步认知，为 Lesson 07 视觉接入做铺垫。||
|**情感态度与价值观**|1\. 在 Lesson 04 已经让 K1 说话与跳舞的基础上，进一步体会「同一件事可以有多种工程实现」——SDK 简单直接、ROS2 服务工程化更强，二者各有适用。<br>2\. 通过 Future 异步机制的引入，体验「机器人世界的时间不是即时的」——请求发出后要等结果，这是工程谦逊。<br>3\. 在综合案例中亲手让 K1 通过 ROS2 服务完成 30 秒展示，建立对机器人系统工程的成就感。<br>4\. 通过 cleanup 习惯的引入，建立「程序结束要善后」的工程素养。||
|**教学重点**|1\. /booster\_rpc\_service 是 K1 动作的统一 ROS2 入口，所有切模式 / 手控 / 舞蹈都走它。<br>2\. Request 的 api\_id \+ body 双字段结构，特别是 body 必须是 JSON 字符串（不是 Python 字典）。<br>3\. rclpy 调用服务的 6 步骨架——init / Node / Client / wait / call\_async / spin\_until\_future\_complete。<br>4\. send\_rpc\_request 函数封装让主流程「只关心做什么」，dance\_by\_ros2 把 6 步流程打包。||
|**教学难点**|1\. JSON 字符串外引号包内引号的写法——学生很容易写成 Python 字典或漏掉引号。<br>2\. Future 异步机制——call\_async 立即返回 future 而不是结果，需要 spin\_until\_future\_complete 才能拿到 response。<br>3\. request\.msg\.api\_id 与 request\.msg\.body 的双层访问写法（学生容易写成 request\.api\_id）。<br>4\. CLI 命令的 YAML 外壳 \+ JSON 内核嵌套结构，第一次接触很容易混淆引号。<br>5\. Notebook 反复运行带来的 rclpy 重复 init 错误——需要让学生养成结束清理的习惯。||
