# 教案\_L4\_01\_人形机器人进化史

|**基本信息**|||
|---|---|---|
|**课  题**|**人形机器人进化史: 从达·芬奇笔记到 VLA 大模型**||
|**适用学段**|高中 \(机器人特色校\) / 大学入门||
|**课时**|45 分钟  ·  1 课时||
|**教学平台**|Booster K1 教育版  ·  L4 通识开篇课  ·  PPT 投影 \+ K1 实物展示 \+ 视频||
|**教学目标**|||
|**知识与技能**|1\. 建立通识脉络: 知道从达·芬奇机械骑士到 VLA 大模型 500 年的人形机器人发展时间线。<br>2\. 掌握「3 类历史性质」分类法 —— 传说 \(偃师\) / 设计 \(达·芬奇\) / 实物 \(Karakuri\) , 学会用证据等级而非时间顺序看待历史。<br>3\. 理解人形机器人 5 阶段技术演进: 萌芽 \(1960s\-80s\) / 群星 \(1990s\-2000s\) / 竞赛 \(2011\-15\) / 风云 \(2021\-24\) / 具身智能 \(2023\-25\)。<br>4\. 知道 5 个关键技术名词的基本含义: ZMP \(零力矩点\) / 预观控制 / MPC \(模型预测控制\) / 强化学习 \+ Sim2Real / VLA \(视觉\-语言\-动作模型\)。<br>5\. 能解释「具身智能」与「会聊天 AI」的本质区别 —— 前者必须在真实物理世界中行动。<br>6\. 知道当前 6 大主流人形机器人厂商: Tesla / Boston Dynamics / Figure AI / 宇树 / 1X / Apptronik 及其代表机型。<br>7\. 理解 5 道现实难题: 续航能效 / 整机成本 / 安全责任 / 数据稀缺 / Sim2Real 差距。<br>8\. 知道 RoboCup 机器人足球比赛及其 2050 年目标 \(打败人类世界杯冠军\)。<br>9\. 知道 K1 教学平台的 3 大特征: 开发生态 / 模块化设计 / Python \+ C\+\+ 双语言。<br>10\. 明确 L4 课程 16 节课的能力地图, 以及自己将在 L11\-L15 完成的「足球任务闭环」最终产品。||
|**过程与方法**|1\. 通过 P5「核心问题」引发学生讨论 \(偃师 / 达·芬奇 / Karakuri 谁算真正的人形机器人?\), 培养史学批判思维。<br>2\. 通过 P11 「三类历史性质」对比图, 让学生建立「证据等级」思维 —— 传说 / 设计 / 实物。<br>3\. 通过 P13 五阶段地图建立全局时间感, 然后逐阶段深入 \(PART 04\-08\)。<br>4\. 通过 5 张「★ 原理图解」\(P15/P17/P21/P25/P29\), 用图示而非公式让学生理解关键技术名词。<br>5\. 通过 P22 「Tesla \+ ChatGPT 双风」让学生理解技术爆发的「2 股风同时吹」的产业现象。<br>6\. 通过 P31\-P32 6 大厂商对比表, 让学生看清当前产业格局, 不再以为「人形机器人 = Tesla」。<br>7\. 通过 P36\-P39 「机器人足球」桥接到 RoboCup \+ L4 课程, 形成期待感。<br>8\. 通过 P41 「开箱视频」营造仪式感节点, 让学生「身临其境」感受 K1。<br>9\. 通过 P42\-P43 「16 节课地图 \+ 你将完成什么」让学生明确自己的学习目标。||
|**情感态度与价值观**|1\. 培养历史叙事的批判精神 —— 不轻信「最早 / 最久」的说法, 学会用证据等级看待历史。<br>2\. 体会「人形机器人不是科幻, 而是 500 年工程实践」的认知 —— 从达·芬奇到 VLA, 是真实的人类努力。<br>3\. 理解「这不是机器像人, 而是机器进入人类世界」的核心命题 —— 培养具身智能的全局视野。<br>4\. 通过中国宇树的崛起, 建立科技自信; 通过 Tesla / Figure 的发展, 理解全球竞争格局。<br>5\. 通过 5 大现实挑战, 培养「光鲜技术背后的真实问题意识」, 避免技术乌托邦幻想。<br>6\. 通过 RoboCup 2050 目标, 体会「长期主义」的科研精神 —— 50 年的远征。<br>7\. 通过结课金句「下一个 50 年, 将由你们书写」 , 激发学生使命感。||
|**教学重点**|1\. 人形前史 3 类历史性质 \(PPT P5\-P12, 11 分钟\): 必须用 P5 引发讨论, P11 总结分类法。<br>2\. 5 张原理图解 \(P15/P17/P21/P25/P29\): 学生最容易记住、最有「技术含金量」的内容。<br>3\. 5 个关键技术名词的「直觉」: ZMP \(平衡判据\) / 预观控制 \(提前预演\) / MPC \(10 ms 重做\) / RL \(摔百万次\) / VLA \(端到端\)。||
|**教学难点**|1\. 「具身智能」与「会聊天 AI」的区别 —— 学生常以为 ChatGPT 已经是「机器人」。用「泡咖啡」的例子讲清。<br>2\. ZMP 与重心 \(CoG\) 的区别 —— 学生常混淆, 需要用 P15 图示反复强调。<br>3\. MPC「每 10 ms 重做一次」的工程含义 —— 学生不理解为什么要这么频繁地重做。用「打篮球抢断」类比。<br>4\. Sim2Real Gap —— 学生不理解「仿真和真实有什么差距」, 用「电池电量下降 / 摩擦系数变化」举例。<br>5\. VLA 「端到端」与传统「模块化」的区别 —— 用 P29 对比框讲清, 注意不要陷入神经网络细节。||
|**教学准备**|||
|**设备与环境**|1\. 教师电脑 \+ 大屏投影 \(推荐 4K, 因为 PPT 含历史图片和复杂流程图\)。<br>2\. K1 教育版实机 1 台 \(可摆在教室前方或讲台旁, 让学生「看到真机」, 增强代入感\)。<br>3\. 课前 1 天: 准备 1\-2 分钟 K1 开箱 / 行走视频 \(1920×1080 横向标准\)。<br>4\. 教师可以提前找一段 ASIMO 走路视频 \(15 秒\) \+ Atlas 跑酷视频 \(30 秒\) 备用 \(P16 / P20 处插播\)。<br>5\. 课堂气氛: 这是 L4 通识开篇课, 建议教师讲课时多互动, 鼓励学生举手提问。||
|**教学资源**|1\. 配套 PPT: Lesson 01《人形机器人进化史》<br>2\. 教师讲义: Lesson 01 教师手册 \(含 ZMP / MPC / RL / VLA 等名词深度解释 \+ 史料考据 \+ 教学策略\)。<br>3\. 课件素材: K1 开箱视频 / WABOT 历史图 / ASIMO 走路视频 / Atlas 跑酷视频 / 宇树 H1 春晚视频。<br>4\. 学生学习单 \(可选\): 列出 16 节课预告 \+ 5 个关键技术名词填空 \(用于课后复习\)。<br>5\. 课后作业纸: 4 道作业 \(200 字短文 \+ 查找一个 PPT 没提到的机器人 \+ 预习 K1 硬件\)。<br>6\. 拓展阅读清单: 见教师讲义 §10\.5 \(含 ZMP 原始论文、Sutton \& Barto RL 经典书等\)。||

**板书设计**

主板:  500 年时间线  ·  达·芬奇 \(1495\)  →  Karakuri \(1796\)  →  WABOT \(1973\)  →  ASIMO \(2000\)  →  VLA \(2025\)

副板 1:  3 类历史性质  ·  传说 / 设计 / 实物

副板 2:  5 阶段地图  ·  萌芽 \(60\-80s\) → 群星 \(90\-00s\) → 竞赛 \(11\-15\) → 风云 \(21\-24\) → 具身 \(23\-25\)

副板 3:  5 个关键名词  ·  ZMP / 预观控制 / MPC / RL\+Sim2Real / VLA

结课金句:  「下一个 50 年, 将由你们书写。」



**评价与作业**



1\. 课堂表现 \(30%\):  互动参与度  ·  P5 投票  ·  P22 提问  ·  P39 RoboCup 2050 讨论。

2\. 课后作业 1 \(30%\):  200 字短文「为什么我相信 / 不相信 2050 年人形机器人会赢得世界杯?」

3\. 课后作业 2 \(20%\):  查找一个 PPT 没提到的人形机器人, 写 100 字介绍 \(机型 / 国家 / 落地场景\)。

4\. 课后作业 3 \(10%\):  画一张「5 阶段时间线」, 标出每个阶段的代表机型和关键技术。

5\. 课后作业 4 \(10%\):  准备下节课要问关于 K1 硬件的 1 个问题。



**教学反思  \(课后填写\)**



1\. 45 页是否准确控制在 45 分钟? 哪些环节超时? 下次怎么调整?

2\. 5 张「★ 原理图解」哪几张学生反应最好? 哪几张需要换更好的类比?

3\. P5 「偃师 / 达·芬奇 / Karakuri 投票」是否激发了讨论?  如果没有, 下次怎么改进引导问题?

4\. P22 「Tesla \+ ChatGPT 双风」学生是否真的理解了「2 股风同时吹」的意义?

5\. P41 开箱视频是否营造了仪式感? 下节课开始时学生的「期待感」如何?
