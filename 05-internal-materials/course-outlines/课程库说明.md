# 知识库说明

# 一、课程定位

本课程以 K1 人形具身智能机器人为核心载体，面向中小学不同学段构建递进式机器人系统认知与工程实践课程路径。

K1 作为高度集成的人形机器人产品，包含机械结构、传感器、执行器、控制系统、计算平台、通信机制、软件接口和任务逻辑等组成部分。课程以该真实系统为对象，引导学生在观察、操作、编程、调试与项目实践中理解智能系统的构成方式与运行机制。

课程的认知路径遵循复杂系统学习规律：由外部结构认知进入任务行为组织，由可见功能体验进入内部模块理解，并进一步发展到智能闭环系统的工程化构建。

本课程强调真实设备、真实任务和真实反馈。学生在学习过程中需要处理空间、光线、声音、姿态、延迟、误差和环境变化等现实因素，从而建立面向真实世界的系统思维与工程意识。

# 二、核心能力目标

- 复杂系统理解能力：认识真实智能产品中机械、感知、计算、通信、控制与执行模块的协同关系。

- 感知行动组织能力：理解机器人如何从环境中获取信息，并将信息转化为可执行行为。

- 自主行为构建能力：基于目标、规则、状态与反馈组织机器人连续行动。

- 现实对象计算化能力：将声音、图像、位置、颜色、距离等现实对象转化为可计算、可判断、可调用的数据结构。

- 工程调试与复盘能力：围绕任务目标开展测试、排查、优化和成果表达。

# 三、课程等级结构

|**等级**|**系统认知阶段**|**核心学习对象**|**能力发展目标**|**项目成果**|
|---|---|---|---|---|
|L1|外部结构与具身表达|身体、感官、动作、语音、基础使用|从“机器人是什么”到“机器人如何通过身体表达”。|机器人情景剧|
|L2|任务分析与行为组织|场景、对象、流程、条件、变量、交互|从“控制功能”到“围绕任务组织机器人行为”。|校园智能导览员|
|L3|内部模块与系统集成|代码、语音、视觉、图像流、识别、状态机|从“机器人执行程序”到“多个系统模块协同完成自主行动”。|二维码迷宫探索|
|L4|工程研发与智能闭环|通信、节点、服务、检测、坐标、策略、调试|从“完成项目”到“像工程师一样构建可迁移的智能任务系统”。|自主追球与执行踢球动作任务|

# 四、清华工训课（大学工训层级）

本目录下的 `清华工训课-18章/` 子目录归档了清华大学基础工业训练中心基于 Booster K1 建设的**大学/工程训练层级**具身智能课程全文（18 章完整实践手册）。

- **定位**：本科/研究生工程训练，涵盖控制系统、动作生成（含 BeyondMimic）、感知系统、策略与行为、系统整合五大模块
- **与 L1-L4 的关系**：清华工训课是 L4「机器人工程」主线在大学工训层级的深化实现，可作为高职课程设计的**进阶参考素材**
- **目录摘要**：见 `清华工训课-18章/00-目录摘要.md`

> 本说明文件描述的是 K12 通识课 L1-L4 的课程定位与能力目标。清华工训课属于独立的教学层级，不纳入 L1-L4 的等级递进体系。
