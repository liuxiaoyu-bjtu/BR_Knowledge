# 98 - 临时任务记录

> 本目录用于存放尚未正式沉淀到 Core A、Core B 或共享资源层的临时任务记录、专项调研和阶段性工作稿。

## 使用边界

- 临时记录可以包含调研过程、阶段性判断、产品讨论和待确认事项。
- 经过评审并具备长期复用价值的内容，应迁移或提炼到 `01-booster-kb/`、`02-embodied-ai-edu/` 或 `04-shared/` 的对应模块。
- 本目录不替代 `99-task-contexts/`。`99-task-contexts/` 存放任务上下文、执行提示词和状态日志；本目录存放临时任务的实际记录或阶段性产出。
- 文件名建议采用 `YYYYMMDD-主题.md` 格式，便于按日期和主题检索。
