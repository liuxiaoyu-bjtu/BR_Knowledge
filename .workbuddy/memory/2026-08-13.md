# 2026-08-13 工作日志

## 1. 创建 BoosterOS SDK 视觉能力全量测试 Notebook

### 文件
- `04-shared/test_vision_capabilities.ipynb` — Jupyter Notebook 格式，59 个 cell（30 markdown + 29 code）

### 测试覆盖范围（17 项）
- **直接视觉接口（4 项）**：RGB 图像采集、Depth 图像采集、相机内参 CameraInfo、图像流订阅 subscribe_image
- **视觉检测模块（5 项）**：模型列表 list_models、检测器初始化、目标检测 detect、结果可视化 plot、模型切换 load_model
- **视觉数据类型（4 项）**：AnyImage 方法（to_numpy/to_pil/save/resize/to_bytes/size/show）、BoundingBox2D 属性、DetectionResult.to_dict()、CameraInfo 矩阵（K/D/R/P + ROI）
- **间接视觉支撑（4 项）**：set_head_angle（头部跟随）、list_frames（坐标系列表）、get_transform（相机→机器人坐标变换）、SoccerKickManager.update_ball（视觉驱动踢球）

### 设计要点
- 全程复用同一 BoosterRobot 实例（SDK 要求）
- 每个测试有独立错误处理和 SKIP 逻辑
- 包含 ImageType 枚举验证
- 最后有汇总报告 cell
