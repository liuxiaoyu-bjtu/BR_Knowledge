## 1. Booster Agent Framework 知识库录入

### 背景
- Booster Agent Framework 与 BoosterOS SDK 是两套独立体系
- SDK 是底层驱动层（`boosteros` 包），Agent Framework 是上层应用框架（`booster_agent_framework` 包）
- Agent Framework 通过 `call_booster_interface_api()` 与 SDK 通信，不直接操作机器人

### 关键发现
- Agent Framework 的 `call_booster_interface_api()` 引用的是旧版 `booster_robotics_sdk_python.LocoApiId`，而非新版 `boosteros` 包
- Agent Framework 的线程模型类似 Android：所有回调在主线程串行执行，回调中不能做耗时操作
- ComponentStatePageProxy 提供了基于机器人状态自动切换 UI 页面的能力，是复杂 Agent 界面管理的核心
